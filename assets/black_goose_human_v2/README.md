# 小黑鹅正面idle · 第二版比例重画

用户确认第一版与主角等高后修长，授权按头脸偏小/肩线偏高/躯干衣裙偏长重画。内置image_gen以主角walk_source、v1和等高对比图为输入，绘制新的头脸/颈肩/衣裙比例，保留短发侧束、紫眼、羽毛裙袖与小凉鞋。单张静态，不是动画。原生成PNG字节复制，无二次图像编辑、不拉宽/压扁，旧版保留。

idle-comparison.png由Godot脚本compare_black_goose_idle_v2.gd显示主角/v1/v2，脚底对齐、均580px可见身高，下方140px；三图各自等比最近邻显示。查看后v2眼线/肩线更接近主角，头脸占比上升，原来的直挺衣裙感减轻。仍待用户观感确认，不宣称比例逐像素相同。

manifest记录尺寸/透明/建议脚点/hash和接入边界，prompt.txt完整提示词。未接入371或其它游戏场景，未设世界高度/碰撞/投影/受光，没有侧背面或行走/眨眼/呼吸帧。常态立绘仍round3/base，喜欢的表情差分仍round3/buddy，不更改服设决定。
