# 413 C木屋资源与展示约定

用户选择assets/house412/concepts/C-attic-gable.png，要求基本正面，不把建筑旋转成设计图的微侧视角。本轮实体模型代码scripts/room/home_yard413.gd，房屋rotation.y=0，沿用411 XZ.92/Y.98变换与门点host(0,2.43)。外墙占地约12.05×7.14m，主脊局部Y8.15（世界约7.99m），双坡斜率局部.685；屋内皮偏移约.13–.15m并采用相同坡向、梁位。房屋装饰是实几何，不是整栋插画卡片。

material-atlas.png是内置image_gen生成的四象限手绘材质：左上木、右上瓦、左下灰泥、右下砂岩；source.json保存完整提示词/参考/工具。不是从C设计稿裁出整栋房子贴到模型。运行时Image载入图集，get_region取各象限的内部区域，生成ImageTexture用于StandardMaterial3D，避免3D材质不执行AtlasTexture二维UV重映射导致串色。图集不覆盖旧资源。

主屋顶198片MultiMesh厚瓦，斜梁、拱窗/窗板、花箱/花朵、石门套/石基、烟囱、门牌及藤蔓均分件跟随facade cutaway；门牌跟随真实hinged door并复用门切片shader。门扇/房屋墙与门前缓坡碰撞沿用已验证410/411，装饰无独立阻挡，屋顶当前不作为可行走碰撞表面。墙体占地而非贴图轮廓负责阻挡。

屋顶/墙/木梁/瓦片接收并投射原生光影；不追加整房假圆柱影。窗自亮材质与三个OmniLight分别配置，门灯另有真实OmniLight；沿用宿主昼夜环境及门光逻辑。室内皮关闭重复屋面投影，梁有原生影。室内只显示新的坡屋面/斜梁/墙顶横梁，旧roof402/frame399隐藏；家具、角色身形、脚点不变。外屋在室内按既有411切顶，map与room始终存在，出屋立即恢复。小院布局和200避让逻辑未调整。

这是C方向结构和第一层装修，不是逐笔复刻设计图。当前侧小山墙较浅、窗帘/藤蔓/羽毛图案偏简化，瓦片边沿/石块还可细化；二楼只有抬高屋顶的预留空间，没有楼板/楼梯/导航或可进入的二楼。未来需在统一标高中加楼板、楼梯与独立碰撞，并重新验证承托/遮挡。
