# A 稿原创小屋手绘素材

用内置 ImageGen，以用户给出的 A 稿为风格和部件参考。原始 PNG 原样拷贝，完整提示词见 prompts.json，尺寸、透明边界与哈希见 manifest.json。运行时按高于裁切阈值的边界加 8px 余量取图，保留原 alpha 和画幅比例。

灰泥贴在 3D 墙面，世界坐标投影统一比例，参与场景受光，随墙体裁切。门边盆高 1.04m，左右素材各取自盆栽原图，足锚在裁区底中，固定朝 25° 室外镜头。床边小盆借用左盆裁区，高 .26m，锚到床头柜顶并对齐 12° 室内镜头。窗箱图按照原实体槽宽缩放，底锚与托架对齐，固定朝 25° 室外镜头。藤条是竖直壁挂，翻转让茎上端落在中央窗箱右端，约 1.23m 高。

装饰使用深度测试和 alpha 裁切，受光不自亮，不额外投硬影。门边盆有贴地接触影，透明枝叶不算占地，盆身用半径 .27m 的实体圆柱。窗箱渲染用画稿，保留旧木槽体积的碰撞。床头小盆沿用柜子的占地。屋体仍为实体墙、窗、屋面、台阶与同一套现有室内。
