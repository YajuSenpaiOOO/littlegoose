# 乐器课原型声音

原创程序合成PCM，22050 Hz、16-bit mono，无外部采样。六个MIDI音高60/62/64/65/67/69，分别普通短音和Perfect清亮谐音。公版《小星星》旋律序列在music_audio235.gd，句尾留白。

普通包络：6ms淡入、指数衰减15、25ms淡出、0.20s。Perfect：同样淡入淡出，指数衰减8，0.44s；基音/二三次谐波/五度频率权重0.70/0.17/0.08/0.05。峰值11000，运行时音符-9dB；轻节拍880Hz、50ms、指数110、峰1900，-15dB。

场景最多4音符声部+1节拍声部。原型音色与时延仍待玩家实听。
