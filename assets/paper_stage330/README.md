## 玩法与判定

四段循环：重纸弹6.8秒→散射5.2秒→迫击炮6.6秒→流星8.4秒。重纸弹未处理完时延后下一段，场上最多一颗。炮口1.15秒聚纸蓄力后锁定当时玩家方向，飞行5.2米/秒，无追踪。可走位、蹲防、闪避，近身使用既有右键瞬间弹反（原生.18秒窗口），成功调用既有弹反奖励/停顿，球回砸城墙一次扣8血。长按蹲防不反弹；漏防受2伤。接触按XZ连续圆扫掠半径.83米及跳跃高度检验，图像边框不作碰撞。出膛忽略自己的炮台物理体，遇场景墙/布景会碎。回弹为可视化返还城墙，途中不再次伤主角，也不改成普通可追踪玩家子弹。

炮台打断只取消尚在蓄力的重弹，已发射的继续；打倒纸偶也能打断蓄力。重开/胜负退出清除所有新弹体。城堡仍72血、炮台仍5血，直接输出玩法保留。重弹和迫击炮共用炮口画稿挂点(625,210)，经炮台实际显示变换投到世界坐标，避免从炮台腹部发射；重弹飞行保持出膛离地高度，不在首帧突然下沉。

迫击炮三发间隔1.15秒、单发飞行1.65秒，2.8米抛物线高度。带尾翼的完整大弹体沿投影轨迹转向，升空时弹头向上、下降时尖头朝落点，替换旧.38米碎纸包旋转。落点圈及1.6米冲击半径沿用，爆炸图、声音、震动沿用328。不改流星资源或伤害。
