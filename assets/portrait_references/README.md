## 使用约定

用户说「像姐姐和主角那样的立绘」时优先读取本目录四图；不要误用sister211/idle.png、hero_pixel/walk_source.png等游戏小人作为立绘风格参考。用户若明确要求小人/战斗帧，则使用对应的游戏角色资源。

292的三张折纸妹妹候选用错了参考类型，生成的是游戏小人风格；它们保留作为历史候选，不是用户已认可的立绘。后续重画折纸妹妹须参考本目录，先定立绘，再单独设计游戏小人，不能混称。

所有 PNG 保留原文件名、原始像素和透明通道。复制前后已逐一核对 SHA-256，来源与哈希见 [manifest.json](manifest.json)。
