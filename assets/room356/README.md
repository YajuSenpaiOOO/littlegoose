# 356 家具试接

三张PNG无损复制自art/furniture/room356，原imagegen提示词与来源保留在该目录。本轮不编辑/拉伸原图；用AtlasTexture按alpha128边界裁显示，主床脚锚按两前脚底端中点校准，不把图片包围框中点当床脚中点。参数见manifest.json。

默认固定相机朝向，25°画面顶面信息由原图绘制承担，图片不重复俯压。主角192竖直/原身形与镜头均不改。床用独立绘制深度坡度，把床尾到床头的真实前后关系写入DEPTH/LIGHT_VERTEX；衣柜用正面深度平面。占地/胶囊碰撞与阴影体积独立于PNG透明矩形。原生投影由专用只投影代理承担，避免显示卡片再投一份扁影。

这是356角度试演接入，不等于每一处视角/前后遮挡已完成全局验证。先用F5在2D画稿和体积对照间切换，F4看占地、F2看昼夜，再判断床顶可见量与墙/地板消失方向是否协调。需要改画稿角度时重画，不靠非均匀缩放去掩盖。
