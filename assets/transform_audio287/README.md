# 原创变身声音 · 287

由tools/generate-transform287-audio.py离线生成，无外部录音/采样/既有旋律输入。固定随机种子287031，44100Hz单声道16bit WAV。合成方法是正弦泛音、短扫频、衰减包络与少量噪声；不是对某作品声音的重制。可运行生成器复现，manifest记录峰值/RMS/首尾幅度。所有峰值小于.65，无数字削波。

- switch.wav：短开关触发。
- burst.wav：上升扫频、低频冲击与空气噪声，挂.76秒爆发。
- bloom.wav：错开起音的明亮钟音和声，挂回光。
- hum.wav：低音量持续底音，1.5秒循环，首尾包络归零。
- pulse.wav：原创单次软脉冲，红灯由.55秒间隔逐步加快至.23秒，不用既有作品的警报采样。
- outro.wav：下降音与余响，挂退场。

Godot导入可能使用QOA，循环点按解码样本帧get_length×mix_rate计算，不能按压缩数据字节数计算。默认4个一次声播放器+1个循环播放器，资源只加载一次；未做每帧实时波形合成。普通一次声-4dB、红灯脉冲-7dB、底音约-11dB。M切换本组音效静音，不影响已有游戏音乐。

音色/神圣感/与其他战斗声音的混音仍需玩家试听，数值检查不能等同主观听感通过。
