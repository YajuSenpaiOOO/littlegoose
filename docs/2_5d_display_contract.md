# 2.5D显示与资产接入约定

新增资源的画风参考 [当前画风约定](art-direction.md)。本页继续规定视角、脚点、遮挡、光照和碰撞。

建立：2026-10-27。用户希望以朝向相机的卡片继续制作，并建立后续agent也须遵循的共用规则。本文规定新增工作的默认方向；旧地图存在多套实现，尚未全量迁移。不能把写入规范当成渲染系统、自动校验器或资产迁移已经完成。

## 1. 图片与展示平面

固定游戏镜头相对水平向下25度。新房屋、树、布偶等插画资源，参考已确认游戏截图和相同类别资源，画出最终镜头所需的顶面/侧面/体积感；不是生成纯正面图后期待倾斜摄影补出屋顶。用“25度”描述生成提示词时须同时附参考图与可见面要求，数字本身不能保证投影一致。

新独立插画摆件默认采用相机朝向的卡片展示，保留画稿比例；禁止随意追加X倾角或非均匀缩放。固定相机可以使用固定相机平面，也可以使用全billboard，但要记录选择，不能仅看节点rotation=0就判断最终竖直。图像内体积不等于真实网格体积。

地面、台阶、岩壁及必须参与行走的高低差使用真实网格。铺地织物/道路应贴地。大屋与树需要拆分时，根基、上片与挂件必须共享投影映射；不得只转其中一层。

## 2. 角色例外与原图比例

最新决定302（2026-11-03）：用户确认主角、NPC、可战斗敌人今后默认采用竖直显示平面，使用一致的前后遮挡原则；本轮先迁移301纸偶和上方纸怪至302，保留301倾斜对照。不把此决定解释为旧演员均已迁移，也不批量更改已确认房屋、树和插画摆件的展示方式。主角169/192不动。悬浮/跳跃用实际高度与地影体现，受击摆动允许暂时侧倾，但不以永久朝相机倾斜代替。转直后的比例/受光须同镜头检查；统一竖直减少平面相交，不替代遮挡与碰撞验收。悬挂纸偶保持X=0，以整体位移和Z侧摆表现惯性；挂点、绳端、受击区域与投影必须跟随实际显示变换。

最新决定198：197相机朝向试验后，用户明确要求恢复竖直主角。当前基线重新直接使用hero192，保留受光/树影能力；197保留历史对照。角色与插画摆件可以采用不同显示平面，不以统一倾角作为修复遮挡/碰撞的手段。198关闭F1/F2试验入口，摆件恢复各自原朝向。以下169/192基准重新生效。

当前主角169/192屏幕身形是既有确认基准；保留X=0、脚点、动画侧摆和缩放。受光法线可独立调整，不能为了受光改变角色几何。角色不必因为摆件朝相机便自动改为同一倾角。

已测169的单位Y/X投影比约0.91015444，全卡片倾斜-25度后约1.0，同样原图约拉长9.9%。后者更接近原图的屏幕纵横比，但不能据此称作角色唯一“正确”身形，亦不能推断用户只是习惯了“错误”版本。画稿意图、正式屏幕造型与卡片朝向应分开决定。如选择完整呈现原图，需做明确的角色视觉迁移，重新确认所有朝向/行走/冲刺/受光/脚锚点；保留可逆对照，不能混入灯光修复。

196的路灯/站台竖直对照仅是实验；不把其默认竖直状态推广为新资产标准。普通树当前多为FIXED_Y竖直，分层屋/树与旧站台也有其他实现；迁移前先审计。

## 3. 每件资产须具备的接入信息

在同目录记录来源/提示词（如生成）、参考资源、透明有效边界、图像尺寸、脚点或挂点、世界尺寸/像素密度、展示平面、所属实例/材质、遮挡策略、碰撞策略、影子策略、是否发光及灯位。记录可以是文档或结构化数据；目前尚无强制读取此清单的统一工厂。

- 像素画风靠正确的形状、色块与密度重画实现，不把高细节插画降采样当作画风匹配。
- 碰撞依据脚下占地和玩法设置。树干、灯柱、房屋等有实体阻挡；可穿过的小花草应明确无碰撞并接拨开效果。不能用整张透明图片矩形当碰撞体。
- 每个可见接地实体需明确接触影；是否需要投射较远的影子由物体大小与光源决定。复用同类适配，避免重复轮廓影加原生投影。不得给矮摆件随意套大圆柱投影体。
- 灯芯/窗户自亮与向外照明分开。发光摆件须配置真实光源，并校准朝向改变后的图像挂点；不能只画亮。附近角色与摆件须有一致受光策略；保留细节，避免自发光覆盖人物暗部。
- 卡片与角色不能靠彼此几何相交完成所有遮挡。采用统一脚点/地面占地的前后规则或经验证的深度代理；实现须整件一致，不能头、身分别翻转前后关系。当前灯穿插仍未彻底验证修复，不能声称这一规则已有通用实现。
- 199局部实现：card_depth199按脚点竖直平面写片元深度，保留屏幕轮廓，先用于8盏森林灯/吊床树/猫10张卡片，已有GPU前后胸头采样与地图截图验证；仅验证Compatibility固定镜头，不自动推广到所有旧资产。静态窄路优先做好视线布局，动态淡出作为兜底；树可见性和其独立投影须同步。
- 200用户澄清：早期整树淡出方向可保留，重点修准确及时触发；撤回199静态清场，保留树节点和碰撞，不按视线改变物理层。当前采用普通树与主题树共用角色遮挡/大面积近景叶片独立检测，不推进拆层资源方案。此条覆盖上一条中199清场的实施方向；灯/吊床深度和树影同步仍保留。
- 挂件与母体共用挂点映射，不临时手拉绳弥补画稿连接错误。树等大前景进入共用遮挡管理器；独立主题资产必须明确接入或使用专用规则。

## 4. 完成标准

复用共用材质、光源注册、树木遮挡和已有影子/碰撞工具；先核对适配范围。后续逐步实现共用资产工厂与清单校验，避免各版本重复拼装；本文不等于这些工具已全部建成。

资产交付前应检查：实机与角色同屏的比例/画风；脚点、正面和背后遮挡、两侧经过；需要阻挡的物体真实顶撞；昼夜及邻灯开关时的受光和投影；重复实例不共享错误状态；树木需连续南北移动/停步/折返检查，不以定点命中通过代替移动观感。小范围变更只跑相关验证，涉及共用显示规则再查小院、普通林地、站台、森林等代表区域。

没有碰撞/投影的装饰可以合理存在，但必须是明确的设计选择，不是漏接。未来工具和规范能降低遗漏，不保证自动杜绝所有问题。交接记录实际完成范围与残留问题，不能把结构存在检查等同于美术验收。
