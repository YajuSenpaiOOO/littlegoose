# 255 两人环境调色对齐

用户254截图：姐姐比主角更亮，脸/围裙像自亮。实际地图将两人替换为同一灰纹理后仍明显不同；独立无旧场景调色的同灰材质实验亮度一致。定位并非原图白色差异为主，也不是单纯StandardMaterial与自定义shader天生不同。

遗漏的旧路径：woodland_palette190::_update_actor在继承49/50/52/57的主角调色后，取消旧stage增益并全局乘.72。它每帧改hero.visual.modulate，仅主角有，姐姐modulate一直白。先前252/253/254称“白色基底原生受光”只移除了材质.82，没有移除这层.72及旧场景环境调色；不是完全中性的受光实验。原截图实测主角modulate约(.724,.724,.706)，姐姐(1,1,1)。之前交接对0.82来源的说明仍成立，但没有识别此第二层全局校准，现予纠正。
