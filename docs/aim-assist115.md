# 115：方向软锁定与手动开火

## 用户报告与原因

114 A每次重新选取目标，且同时受0.22弧度（12.6度）和按1000高视口58像素横向距离限制。已有目标与新目标使用相同门槛，离开贴图后很容易在下一次刷新失选，因此主观感受接近精确瞄准。

## 这次的操作

先试鼠标大致方向的软锁定：无需额外锁定键、Tab或滚轮选怪，滚轮继续缩放。鼠标决定想打的方向，小黑鹅对准辅助目标；左键按住才射击。未选中时沿鼠标方向自由射击，不会因目标圈存在自动开火。

- 以主角胸口的屏幕投影为方向原点，避免跟随鹅左右移动时选择抖动。
- 新目标可以在约32度扇区内选取，取消窄像素距离限制；10米、镜头视野与真实遮挡检查保留。
- 已有目标允许约55度的偏离，指针离开身体仍保持圈选；相邻候选约8度的切换优势门槛减少边界抖动。
- 直接指在另一只怪的可见身体上优先选它；明显转向会释放旧目标或选择新方向的目标。死亡、超出范围、离开视野、被场景遮挡都会失选。
- 鼠标靠近主角的28像素小范围（随视口缩放）时维持已有目标，不因方向矢量变短乱跳；直接指向身体仍优先，贴身怪也能选中。
- 圈选与实际射击共用同一个目标/瞄准点，沿用原来的少量移动预判。保留114手动防御停射、45秒、三只4血怪和结算规则。

数字是这一版手感试验的参数，尚不代表最终平衡。它不会像硬锁定那样无视鼠标转向一直追随一个目标。
