# 团团怪连续受击后贴图与受击体分离

2026-10-17，直接修复当前 world26 使用的 tuantuan24 脚本；无需切换启动器。

## 根因

`_render_legacy()` 在受击姿态中通过 `visual.position += kick` 增加临时抖动，而 `_pose()` 之前只覆盖 `visual.position.y`。水平 X/Z 位移会跨帧、跨受击累积。碰撞体始终跟随真实 CharacterBody3D 根节点，贴图则漂离根节点，导致调试胶囊看似落到怪物的右下方。

固定方向 12 次受击、每次绘制 8 个姿态帧，修复前重现水平偏移 5.7126 米，并在恢复待机后继续保留。修复后同一序列只有当前一帧的 0.00913 米短暂抖动，待机时归零。

## 修复

`tuantuan24._pose()` 每帧先从根节点重建 `Vector3(0,lift,0)`，再叠加当前帧受击偏移。保留跳跃高度、击退、受击动画、贴图翻转与攻击参数。

本次修复解决累计水平漂移；原设计中贴片视觉起跳、受击胶囊留地的差别仍存在，但不会随受击次数越偏越远。

## 验证

- `alignment27_probe.gd`：10 项通过，覆盖原始 12 次受击序列、恢复待机、四方向各 180 帧移动与跳跃中的偏移上限、落地归零。
- `combat26_probe.gd`：11 项 GPU 回归检查通过，覆盖鼠标射线与原生受击体、实际子弹命中、角色投影、弹道地影及模式切换。

原始日志分别为 `alignment27-before.log`、`alignment27-after.log` 和 `combat26-alignment27.log`。
