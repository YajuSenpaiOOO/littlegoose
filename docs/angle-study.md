# A 路线：纯 2D 斜俯视白模

2026-10-15。用户反馈手绘样板存在物件浮起、倾角与主角画风不一致。暂停扩产手绘资产，先验证纯 2D 固定斜俯视。

入口：工作目录 `preview_world_angle.cmd`；场景 `scenes/sandbox/angle_study.tscn`。旧手绘样板仍可单独运行。

## 比较内容

- 1：25°，观察方向更接近侧面，地面纵深更压缩。
- 2：35°，默认折中档。
- 3：45°，地面纵深更展开。
- 角度以水平地面为 0°、垂直俯视为 90°。

所有地面与建筑顶点共同使用：screen_x = x，screen_y = ground_y × sin(angle) − height × cos(angle)。房屋、地面网格、圆形地标与几何投影同步重算。角色保持屏幕直立、大小固定，使用已有行走图和绘制脚点。

该小样全部由 Node2D / Polygon2D / 2D 精灵构成，没有 Camera3D、3D 网格或新生成的画面素材。几何颜色和树冠圆形只用于读清空间，不是最终画风。图形显示角度可以实时改变；正式绘制的 2D 资产必须按选定角度重新制作，不能承诺之后随意改角仍一致。

移动在二维地面坐标中计算，屏幕纵向位移随视角压缩。用地面矩形占位范围阻挡，用脚点的屏幕 y 排序。本场景的最小移动/阻挡演示不等于正式 CharacterBody2D、战斗判定及镜头迁移完成。

几何阴影为固定太阳下的体块占位，不使用上一版整张 alpha 压平的物件投影。角色保留窄脚底接触影。阴影美术与角色方向影仍需在固定视角后细化。

## 检查与下一步

独立 headless 启动无脚本错误，实际 OpenGL 渲染三档角度，截图保存在 `docs/captures/angle_25.png`、`angle_35.png`、`angle_45.png`，已检查默认 35° 画面。
