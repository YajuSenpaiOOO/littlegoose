# 新世界制作顺序

## 已确认与待验证

- 布局：采用 A 的主要空间关系，下方小屋、西侧林地、东侧湖岸与桥、上方车站和外缘铁路。全景图里的距离、高差、窄路不直接作为碰撞规格。
- 画风：经手绘实机试验后，当前改为出发站已验证的像素素材体系，基础植被/图集与定制特色摆件混用。B 保留为历史探索参考，暂停扩产；连续植被构图仍采用。
- 表现：保留用户喜欢的“小人像立牌站在场景里”的感觉。用明确的脚点、合适的接触阴影、统一比例与前后遮挡，使角色立在地面上。
- 待验证：像素素材版小屋入口的空间围合、昼夜光影及角色适配。全景图的地理关系作为规划，素材实际视角以实机为准。
- 旧免费素材按新风格逐项决定是否使用，不必先全删。已有代码和资产的许可要求随迁移保留。

## 阶段 1：一屏美术样板

范围控制在一屏：简单草地与土路、小屋局部、一棵树、一块石头；现有主角和一个敌人。先锁定实际游戏镜头和角色高度，再制作同视角的环境素材。

绘制次序：大色块地面 → 土路与边缘 → 树/房屋的主要体块 → 放入角色 → 基础接触与投影 → 少量地表细节。

本阶段只处理少量代表性物件，先看一屏静态效果，再迁入最小移动、排序与光影链路。记录迁入代码和依赖，避免直接搬入旧 main 的全部剧情耦合。

通过条件：主角尺寸自然；脚下不悬空；前后绕树不穿帮；角色和敌人从地表中清晰可辨；同一物体在中性白天与暮色下都成立。通过后才扩产资产。

## 阶段 2：全世界地形与道路白盒

按 A 的布局确定区域轮廓、道路、岸线、桥、站台标高与铁路位置。使用简易颜色块和占位物，实走确认距离；各战区放入真实敌人测试活动空间。

先解决移动路线、战场大小、镜头和回家捷径。用标记预留对话、Boss、刷怪和出口位置，不绑定旧坐标与整套演出。

## 阶段 3：正式地表

先画基础地皮和大范围色彩变化，再画土路/石路、水体、岸线与不同材质的过渡，最后补稀疏草纹、落叶、碎石。

不把整张大世界生成成唯一一张最终贴图。按区域制作可衔接的地表块或地表层，在接缝处使用过渡形状；复用纹理时检查重复图案。地表中不画树冠、房屋、棚子及它们的长方向影，以便排序、移动与昼夜变化。

## 阶段 4：环境大体块与独立物件

每区先搭围合：房屋、树群、水岸岩体、站台和棚子，再加主树、灯、长椅、路牌、栅栏等独立摆件。树群组合允许用于不可进入的远侧边界；玩家能绕行的树干和摆件按独立脚点排序，不按相邻像素自动并成一组。

先做小屋与连接路作为视觉基准，随后林地、湖岸、车站依次展开；已有车站小样作为布局与功能参考。

每项资产需要记录：文件及版本、画面尺寸、世界显示比例、脚点、碰撞脚印、排序方式、阴影方式与虚拟高度；发光物额外记录光源位置和范围。临时图不能混进正式资产目录。

物件自身的手绘明暗尽量柔和，不画死强烈方向日照。方向长影由运行系统生成；材质暗部和环境遮蔽可以保留。生成或绘制透明物件时确保完整轮廓和足够边距，检查树脚、石头脚及 alpha 裁边。

## 阶段 5：细节与光照

大体块和道路确认后，才补边缘厚度、灌木、草丛、花与生活痕迹。先按连续组合安排疏密，再挑少量散件补点，避免平均撒满全图。

最后统一白天、暮色、夜晚的色调与光源；沿用已验证的太阳投影、接触阴影和局部灯光思路。首先保住战斗中心可读性，再增加外围细节。烘焙的手绘材质明暗无法仅靠动态投影自动转向，需要由美术样板确认接受程度。

## 阶段 6：完整战斗与剧情迁移

战斗逻辑在白盒期先迁最小可用部分，正式摆件稳定后确定刷怪、封场和 Boss 活动范围，并检查性能。随后用户结合剧情重排触发器、走位与镜头，沿用有价值的事件语义和依赖，不保留旧地理坐标约束。

每次迁移记录来源文件、必要依赖、当前验证状态、以后在哪一份维护。新工程能独立运行后，旧工程继续作为历史参考。

## 每轮交付

每次只推进一个明确区域或一组资产：说明本轮目标 → 制作少量候选 → 选定版本 → 以正式角色和镜头验证 → 整理进正式目录并更新清单。先通过可玩与画风检查，再扩大制作规模。
