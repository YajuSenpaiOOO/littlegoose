# 当前画风约定

2026-11-20。接下来按**手绘童话 2.5D** 推进。432 的小屋和现行林地作场景参考，已接入的人形小黑鹅作同场角色参考。用实际游戏截图和已采用的素材作为生成与验收参考。概念图用于形状与布置。

## 新资源

- **角色**保留 Q 版头身和清楚的剪影。用手绘色块组织亮面、暗面和褶皱，轮廓有粗细变化。小黑鹅是同场游戏小人的参考。主角改稿时沿用她自己的发型、粉夹、服装和比例，立绘仍按立绘规范。
- **环境与摆件**沿用小屋的实体家具与手绘纹理、林地成组的叶团与地表色块。木纹、织物、石材保留能在游戏镜头读到的粗细和明暗。近看允许有笔触，远看保留清楚的体块。
- **同框验收**先用正常行走镜头看角色是否读得清，再看近景里的体积、接触和边缘。需要时补一张夜景检查局部灯色。在同一机位对比材质粗细、轮廓锐度与阴影软硬。像素化、统一模糊和全局滤镜都不能代替同框校色。技术接入见 [2.5D 显示约定](2_5d_display_contract.md)。

## 主角过渡

当前版本保留主角像素资源，优先推进玩法与流程。维护现有动作时允许沿用当前角色的图层和画面比例，新增通用美术按上面的手绘方向制作。主角重画安排单独一轮，先做一个站姿和一个代表性动作，与小黑鹅在同一镜头对照；确认轮廓、色彩、比例和脚点，再展开方向、动作、表情和睡姿。主角现有动作与旧版保留作对照。
