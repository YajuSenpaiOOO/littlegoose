# 153：公园买的气球剑

2026-10-24。默认场景切至world153。`preview_balloon_sword153.cmd`直接进入团团试演，`play.cmd`仍从日常世界进入。152独立场景与启动器保留。

## 本轮行为

- 蓝色弹性液滴是剑身的材料设定。透明像素剑沿用掉落物的青蓝胶质、深蓝描边、奶油色高光与黄色小星星。内置image_gen生成，原始提示词与清理说明在`assets/balloon_sword153/PROVENANCE.md`。
- 气球剑替换普通弹丸的外观与命中附加效果，伤害为同组合的75%。直接射击、射速、分裂、蓄力、纸飞机与课堂笔记均可组合。纸飞机默认保留辅助六连投，六剑平分载荷伤害预算，不是六倍伤害。
- 命中存活敌人后剑尖黏在可见身体附近，跟随受击中心移动；剑身弹晃，多把挂剑轻微扇开。宽松受击胶囊上缘不再让剑尖悬在立绘上方。
- 每剑减常规移动速度8%，最多5层/40%，各自持续3秒。满层后新剑替换最旧一剑，不刷新其他剑。到期逐根瘪下、淡出并恢复对应速度。
- 减速接在团团普通追踪跳步、纸怪水平飘移/避弹位移上，不改变攻击前摇、冷却、跳步计时、竖直浮动、已发动的扑击/阵风冲锋及外力击退；没有新定身或硬直。
- 蓄力剑保留蓄力伤害与较大的视觉，但作为黏附物停在第一个命中表面，不再贯穿演员。分裂弹继续是气球剑且不重复扣除25%伤害。
- 命中地形/摆件后短暂倒插残留、摆动、瘪下淡出；没有持续伤害或碰撞。残留总量有160把的视觉预算，不限制在空飞机数量；单敌控制层数始终最多5。
- 笔记本免费开放一份占1格的试装；配方页说明胶质原料。正式材料消耗尚未定价；153使用独立存档，读取146/119内容迁移，不覆盖旧文件。当前不与手电筒水柱同装，避免把连续光束解释为黏附剑。

## 试玩操作

- F4纸怪、F5原生团团；保留所选组合。F8保留随机九发/辅助六发对照。
- 1直射气球剑，2飞机剑雨，3射速剑，4射速剑雨，5分裂剑，6分裂剑雨，7蓄力剑，8普通直射对照，9普通飞机对照。F9轮换。
