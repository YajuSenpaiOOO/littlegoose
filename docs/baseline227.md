# 227姐姐战自动站桩基准 · 2026-10-30

19套组合、38段首测＋9段复测/诊断，共47段；两次运行均0失败，日志无脚本错误。未修改战斗数值。

## 核心结论

1. 已复现一窗击倒蝙蝠：多鹅＋眼约4.3秒，手电＋眼约5.3秒；6槽手电＋多鹅＋眼约3.0秒。舞台＋多鹅＋眼准备好主动时约1.7秒。不是凭印象才觉得短。
2. 暂未发现普通射击路径的异常倍率：眼约×1.5，多鹅约×1.8，叠加约×2.7；手电满血输出也符合其现有每段伤害与发射间隔。正常叠加已经跨过32血/6秒门槛。
3. 飞机的问题主要出现在短窗：首击约1.7—1.9秒，双蝙蝠分摊伤害；对静止肥猫的4—12秒稳定DPS基本能追上相同直射组合。不能据此把所有飞机伤害全局上调。
4. 手电低血增益同时乘每段伤害和发射频率。7/14血时单项×1.3，合计约×1.69；手电＋眼复测猫6.18→10.45 DPS，蝙蝠6秒36.56→62.31。此为当前代码行为，是否保留这种增幅是设计选择，不直接判定为bug。
5. 同6槽的手电/弹弓/飞机剑/舞台短窗差距显著，不能只把蝙蝠血量加到强组合打不动；那会进一步拖垮飞机。先统一飞机集中目标的能力，再看爆发与蝙蝠血量。

## 条件和口径

- 真实227脚本继承链、Compatibility渲染、原生武器/碰撞/自动瞄准。无玩家移动、无猪、无猫追滚、无支援，玩家14血（低血诊断7血）。原树木、碰撞和遮挡保留。
- 同一空地，玩家脚点到主目标XZ约3m，射线确认无遮挡；保留鹅队原生跟随和出手原点，不让附加鹅与本体重叠来抬高命中。主角实测位移为0。
- 靶子HP临时抬至100000，避免目标早死截断样本。100猫/32蝙蝠的时间是伤害首次累计到门槛的时刻；6秒潜力可超过32，不是正常战斗实际损血/结算。
- 猫测12秒冷启动与4—12秒稳定段；蝙蝠测6秒冷启动，两只同时暴露。阶段之间清弹丸、飞机、附着、主动与蓄力，不能把提前蓄力或在途伤害混入短窗。
- 弹弓脚本蓄满松手并走原生冷却；舞台在本段开始施放，每段都视为主动已准备。猫与蝙蝠是独立段，不代表一场实战可在两段连续各开一次舞台。
- 游戏时间计DPS，另留墙钟/帧数/大于50ms帧。真实顿帧和原生动画保留。武器/碎片RNG重置；飞机独立随机流和帧时序有波动，不称全系统固定随机。
- 三套关键组合复测：多鹅眼/手电眼DPS差约0—1.6%；飞机剑对猫差约0.2%，蝙蝠总伤害复测约低10%，仍未改变排序。短窗结果不是精确到小数的最终平衡常数。
- 命中事件不当命中率。没有测试走位损耗、掩体价值、控制收益、所有距离/方向及未列装备。
