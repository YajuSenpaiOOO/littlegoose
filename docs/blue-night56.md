# 56 清冷蓝夜、暖灯与变化的日影

用户反馈55夜间太黑、像恐怖游戏，目标是略暗的蓝色童话森林与温馨暖灯对比。默认场景改为world56，仍从根目录play.cmd进入；时间/睡觉规则和快捷键沿用55，地形不动。

## 夜景

提高夜间环境光并去掉55的多重压暗，加强蓝色分色，降低对比，最暗处加入少量蓝色填充。近景舞台压暗降至白天的48%，日间空间林荫场夜间仍减弱。树、屋顶、道路在没有灯的地方也能辨认，不依靠大面积黑色表达夜晚。

玻璃继续自发光；新增一盏无阴影的小屋门前暖溢光，位置靠近立面，范围5.8m。原木路灯夜间范围扩大到5m、能量2.4，暖色照到地面和灯杆。后处理根据光照后的暖色响应减弱蓝色分级，保留暖光照亮的表面。尘屑仍96槽，光束仍复用5个网格；没有新增阴影贴图或体积雾。灯光开关继续生效。

## 日影

太阳高度和方位与同一时间轴插值：06点28°/-65°，08点35°/-55°，正午68°/-5°，16点40°/40°，18点26°/65°。因此早晚影子长、正午短，朝向也随时间改变。用26°左右的傍晚高度限制过长投影，这是美术控制，不是经纬度/季节天文模拟。

树、房屋及深度拟合的摆件原本就使用原生太阳阴影，更新太阳方向即可；人物轮廓投影原本缓存方向，现在由时间控制器同步。人物旧脚底椭圆仍不启用。投射光束在顶点阶段按同一方向偏移，防止晨光与日影方向不一致。树根与墙脚的环境遮蔽保持固定，不把接触暗部当成日影旋转。

夜间使用较高的艺术化月光方向，原生投影不透明度降至约0.28，人物轮廓影降至白天40%，避免蓝夜中留下正午式黑影。卡牌、选卡、受伤红闪、深夜停留、睡觉跨日继续保留。

## 验证

`day_cycle56_probe.gd`的34项检查通过，覆盖55时间/暂停/跨日规则，晨晚方向相反、傍晚投影长度大于正午3倍、人物与原生投影方向一致、夜间影子减淡、暖溢光/路灯、晨午暮夜实际渲染、林路光束、材质缓存与战斗兼容。实际18点投影长度/高度为2.05，正午为0.404，约5.1倍。
