# 248 团团Boss：急眼连砸 / 弹反反向加弹

2026-10-31。用户实玩247反馈体型小、三次弹跳无力，要求先原地急跳/急眼、再蓄力多次快速砸地，逐渐衰减；弹反要有顿帧、慢镜头、推进，反方向弹飞而非直接结束，并加一两跳。本版按该反馈实现，仍为免奖励试演。

统一tools/launch-game.ps1 latest→world248；菜单39/boss247保留三连跳对照，38/relay246保留姐姐战与接力旗。继承247独立林地试演；未将246完整碎片系统搬到此场景，普通/弹弓/分裂/追踪/气球剑仍为1—5。F4自动/鼠标瞄准，F6暂停，F7重开，F2结束，F3回院。

体型1.65→2.15（较247线性增加约30%）；90血/18落地伤害/玩家100生命试验参数不变，正式数值待统一。普通短扑仍与连砸交替。

## 连砸

原地三次急跳共.60s、高.32m（不产生攻击伤害）→压扁蓄力.65s→7次砸地→摊平2.1s。正常空中时长从.43s渐增至.76s，跳高2.35逐步减至1.09m，水平速度9.8降至4.7m/s；起跳间隔也逐次增长。每跳起跳时锁定目标位置，空中不追踪。沿用实际地形、原生move_and_slide及安全落点检查。独立落地范围半径1.55m加玩家.3m，金圈同步，沿用闪避/防御接口。

## 弹反不是中断连招

连砸落地弹反：消耗当前落地次数，反转刚才的入射方向，短受力挤压后继续剩余连砸。此后不再向玩家转弯追踪；落点圈转浅青色。后续两跳高2.6m、时长.40s、速度11m/s，之后回落到自然衰减曲线。遇实体边界缩短当前路线，下一跳空间不足时反向，不删除碰撞/树。

每次有效弹反给整段+2砸，7→9→11，上限11，不无限加跳。达到上限仍反向，但最后一砸完成就正常进入摊平。短扑弹反仍直接摊平，区别于招牌连续弹跳。保留原生弹反成功、消耗、连击与伤害链，未削弱弹反本身伤害；新增的势能补跳是路线/节奏变化，不额外增加落地伤害。

反馈使用原生实时impact_clock：.11s顿帧，接.30s/.28倍率慢镜头；punch≥1.05触发镜头推进，沿既有FOV公式回弹，不改相机朝向或主角几何。延迟事件归boss248组，暂停/结束/重开/退出清理，避免慢镜头串场。旧版公共弹反反馈不全局调整。
