# 257 团团Boss：命中修正 / 初始决心 / 等级控制台

用户256实玩反馈：视觉有效，实际命中/杀伤弱，询问混普通团团或增加招式；明确第一Boss应初始12决心、4槽，控制台可调决心等级，每升一级上限和槽位各+1。本轮先修本体漏判和追击，不添加杂兵或新攻击招式。257继承256→251→246最新战斗基线，255主角观感/254暖灯继续保留。

## 命中修正

256只在落地瞬间检查距离，低跳从玩家身上掠过可无伤；后段完整惯性行程加35度转向会冲过目标后连续绕弯。257保留七跳高度/密度、急眼准备和2.65秒弹瘪，空中落点仍锁定。

- 后段每两跳重新瞄准，其余跳转向上限1.05rad；水平行程按预判目标距离裁短，减少越过玩家后空转。预判系数.8、最多1.6m；原短扑也加起跳预判、最远5.6m，未改成空中追踪。
- 第4跳起低跳（可见身体离地<=.65m）检查实际上一位置到当前位置的扫掠段，半径1.6m含玩家体宽，地形高差必须<.8m。短扑下降后半段同样检查。高跳前三次仍只在落地伤害，不因地面根点经过玩家就空中撞人。
- 重砸3决心，低跳/短扑身体擦撞2，余震球仍1。每一跳身体与落地共用attack_connected，只能结算一次；原受伤无敌帧、蹲防、闪避和枕头屋吸收照常工作，不缩短无敌帧凑杀伤。
- 身体接触和落地均可沿原生弹反触发单次反向/+2最多11及冲击反馈；撞墙奖励沿256。伤害记录来源区分tuantuan_sweep/tuantuan_slam。

## 决心与装配

等级按1起算：L1=12决心/4槽，L2=13/5，L3=14/6；通式上限11+L，槽位3+L。测试控件暂提供1—20级，非正式成长封顶。新257独立boss_balance257.cfg和tuantuan_boss257_preview.cfg，旧256/251/246测试配置不迁移、不修改。首次无257配置时等级1、空装配。

C右栏加入决心等级SpinBox，修改仅草稿、容量立即预览；取消不生效。原地应用保留当前HP（降最大值则截到新上限），不补血、不重置Boss阶段；重开/开始记录应用等级并回满。新等级和装配一同验证、一同保存，超槽拒绝且不改旧配置/当前状态。降级后超槽草稿可以逐份卸下；初始预设改为合法4槽组合，高等级可继续使用旧6槽组合或手动加装。

HUD实际宝石数量随决心上限变化，非仅替换文本；状态说明、容量、C统计和记录快照同步等级/最大值/槽数。balance_profile245.error仅增加可选capacity参数，默认仍6，旧246等调用保持原行为。正式背包/关卡成长/首胜奖励尚未迁移，本轮设置为独立Boss试演配置。
