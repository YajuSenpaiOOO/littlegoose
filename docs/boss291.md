# 291 · 团团Boss身体轮廓与表情

用户认可290外形，要求补旧小团团原有跳跃/受击轮廓并丰富表情。本版继承290及288完整玩法，新增六张关键帧，静止沿用289 A。不是把单图缩放称为新动画，也未重画所有过渡帧。

## 资源

assets/tuantuan_boss291/{charge,airborne,landing,hit,dizzy,sleep}.png均为内置image_gen独立编辑，未程序修绘、重采样、抠图或合成。Image1统一引用A_glass身份/像素风/材质，Image2仅引用相应旧动作轮廓。完整提示词在同目录PROMPTS.md；layout.json记录原尺寸、alpha128边界、脚点、有效跨度和SHA256。原图真正带alpha，保留原始输出。玻璃和彩色内芯仍是绘画效果，无实时折射、发光或独立内芯图层。

脚点取alpha128底线与有效边界水平中心，逐帧记录而非套同一画布中心。身体已手绘变形；代码先拟合旧姿态的世界包围跨度，再沿既有节奏叠加程序回弹，不按新图的画布尺寸改变Boss体型。受击仍有原凹陷反馈/短闪色/后坐，不能视作完整逐帧手绘动画。

## 状态映射

- 急眼三小跳、蓄力、扑击准备：charge，聚瞳与小抿嘴，压低鼓边。
- 飞行/扑击：airborne，收底拉长、白毛上扬、小张嘴。
- 反跳间隙、落地前0.12秒：landing，展开底部和白毛。
- 整轮结束0.12–2.15秒与撞墙：dizzy，歪瞳、耷拉白毛、小张嘴；后段恢复idle。
- 命中短硬直和刚弹反的deflected状态：hit，侧凹与白毛拖偏；普通命中不会因此改AI或增加眩晕时长。
- 败退最初hit后dizzy，保留旧败退消散流程，不退回旧种族贴图。
- 断层软垫休息：sleep，全闭眼、眼皮盖住粉红眼白；醒来回idle。

旧通用tuantuan33会在recover状态临时清掉hopping，从而不选airborne。291只为Boss按实际phase247选择画稿，不修改通用敌人AI/通用脚本。原有短命中表情仍优先于飞行帧。
