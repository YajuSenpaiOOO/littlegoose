# 59 三版桥与湖水，以及更宽更淡的暖聚光

当前主场景world59，根目录play.cmd统一进入，默认到桥中央；试战入口仍按--combat保留试战，不强制传送到桥。Ctrl+F6回桥，F3回家，Ctrl+F4林路。保持25°镜头和原21.67m×4.33m的桥跨度。

## 三版选择

| 快捷键 | 桥 | 湖水 |
| --- | --- | --- |
| Alt+5 | A 手绘绳栏木桥：绘制木板、绳栏和侧梁，分层放置 | A 绘本池水：手绘色块、稀疏慢水纹 |
| Alt+6 | B 立体交叉栏木桥：真实桥板厚度、立柱、交叉栏与帽盖 | B 清透浅水：浅深色过渡、破碎反光和岸边树影色带 |
| Alt+7 | C 石砌混合桥：绘制铺石、矮墙与拱券，配立体压顶 | C 静谧蓝湖：低对比蓝绿色、较少的长波纹 |

Alt+W只换水面，可将任意桥与任意水面交叉搭配。Alt+1/2/3/4看晨/午/暮/夜，时间、睡觉、灯组、萤火虫、远景空气等规则继续沿用58。

桥可以用画的。A并不是把完整桥画贴在屏幕前：桥面映射到既有三维通行面，前后栏杆按真实深度分开，使角色能走在桥面、位于前栏后方。B给出真实体积与投影的对照，静态木桥部件合并成3个绘制网格。C把绘制风格与立体压顶组合。三版共用旧桥通行、栏杆碰撞，不通过改变地形或抬高桥面来制造外观区别。

原桥面和22件栏杆/柱视觉隐藏，碰撞保留；新视觉独立替换。桥面标高注意保持在人物轮廓影下方，避免吞掉脚下投影。这里并未重做全地图地势。

## 湖水和岸线

三版共用一张手绘水纹和768×512的岸边距离数据。绘本版更重画笔色块，清透版更重浅深梯度与稀疏反光，静湖版更安静、偏蓝。水纹在世界空间缓慢移动，与昼夜色温联动。

“清透”是本轮的视觉方向，不是物理折射；树影色带也是简化的程序近似，不是实时平面倒影或SSR。没有增加水面反射相机、实时反射贴图或体积雾。

岸边增加薄层泥石过渡与斜坡视觉，盖住原来的部分粗网格绿墙，并以浅水色衔接；不改变阻水碰撞。距离图由tools/bake_lakeshore59.py一次生成，运行时采样，不按帧扫描地形。岸线仍沿旧地图多边形，拐角、桥头衔接、立绘重复和拱券水线关系属于选型后的细修项，不作为已完成的最终岸景。

## 聚光

灯锥角从21°放宽至30°，光束扩散系数0.57735、包围半径3.8m。空气光浓度从0.28降至0.13，实际灯能量5降到4、范围10升到11m；柔和偏暖。人物分级响应降至原来的70%。默认仍是纯聚光，随身补光关闭；Alt+B继续三灯组对照。

bridge59_performance_probe.gd每档在同一桥中央、正午记录180帧，结果bridge59-performance.json。只用于当前机器的短时比较，不据此声称解决偶发卡顿。

本轮本机中位帧耗时A/B/C分别13.00/13.17/13.28ms，540帧无超过33.3ms的帧，最大20.25ms。绘制调用A669、B615、C657；B的真实立体部件经过合并，并不因为是3D就必然比绘制卡片有更多调用。时间差处于本次短测的波动范围，不能据此给所有设备作速度排序。
