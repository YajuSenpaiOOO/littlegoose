# 335 缺口纸环 / 城堡炮台辅助瞄准

入口89/boss314 → woodland_world335，paper_stage335继承334；耐久与修建、落地伤害/炸起不改，无新增位图。

普通纸幕轮换增加第4种缺口环：24个等角位置省略中央与两侧共3槽，21片普通纸屑同轮发射。开火前.5秒用淡金色边界标出安全开口（两侧±30度），开口方向基于固定舞台地标而非玩家，后续轮次以.3弧度逐步转动并循环。普通弹速/伤害/防御与场景阻挡沿用；背向城墙的弹会被原场景阻挡。打瘫炮台取消其尚未发射的整环与提示；退出/重开清除提示和环次。

可攻击结构增加独立屏幕四角框，沿用既有金色手动/青色自动配色，不改CharacterBody3D敌人目标字段类型。鼠标命中城堡实际受击墙段或炮台时选择，并在边缘约14像素内轻辅助；按当前CollisionShape3D的真实Box投影计算框。城堡底部物理墙命中映射到当前墙段，非巨大透明贴图矩形。地形与布景继续遮挡射线。目标结构会同步到aim114和实际射击目标，自动模式瞄准结构时能发射，不是仅装饰框。

炮台HP为0时立即拒绝获取（不等deferred碰撞层切换），搬运/修建期间无攻击框；归位且恢复受击层后可重选。开场落地前、暂停、胜利/退出不显示结构框。框只显示当前选择的墙段/炮台，避免全场多个巨大框；原敌人辅助框继续保留，选择结构时清除旧敌人选择。
