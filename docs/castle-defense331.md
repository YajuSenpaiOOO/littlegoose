# 331 防空扫射与可压制炮台

入口89/boss314，场景world314绑定woodland_world331，stage331继承330，330原流程脚本保留对照。无新增位图，复用330迫击炮原画作小型纸弹，显示宽.30米；按屏幕投影中的实际飞行方向转动，固定相机平面（X=-25°），不改主角或NPC几何。材质、深度遮挡和不投影策略沿用330。新增扫射箭头/边界为代码绘制的低透明贴地提示，无碰撞/灯光/投影，不是新增实体摆件。

## 扫射节拍

五段循环：重纸弹6.8秒→防空扫射8秒→交替散射5.2秒→迫击炮6.6秒→流星8.4秒。扫射每轮只用一个炮台，提前.8秒用淡扇形边界与移动箭头提示；锁定当时玩家方向作为扇区中心，开火后不追踪。

24发连续小纸弹，间隔.16秒，弹速6米/秒，55度扇区单向匀速扫过。下次反向并换另一门炮；不会同时双炮夹射。前后保留余弹离场/换招空隙，不追加随机散射或迫击炮。弹体XZ连续扫圆半径.42米（包含角色接触余量），地面高度检查/跳跃、原生弹反/蹲防/完美闪避沿用；每发1伤，普通无敌期防连吃，判定不取图像透明矩形。自己的炮台实体排除，地形/布景仍挡弹。

## 炮台压制

炮台各5点结构值，打空后瘫痪7秒，取消该炮的扫射/散射、排队炮火及重弹蓄力，给予至少1.4秒换位/输出空档。已经出膛的重纸弹/抛物弹继续飞。炮台本体占地不移除，伤害Area关闭，不能在瘫痪期反复刷新控制。

前6秒用已有破炮帧和暗色显示；最后1秒恢复完整帧并缩放/颤动，表示重新折起，但仍不能开火。7秒到时恢复5结构值与受击Area，至少.9秒发射准备时间。城堡仍72血；首次打瘫每座炮扣城堡3血，后续打瘫只给停火，不重复刷城堡伤害。可直接打城堡，也可先压一门炮换取输出位置。

城堡胜利时取消全部恢复计时与弹幕，在既有城堡坍塌1.12秒节点让两门炮一起折坏，产生纸屑/小BOOM，保留破炮残骸；失败退出隐藏炮台。重开清除瘫痪/首次奖励/扫射方向/残骸状态。
