# 82：中置候车厅、全宽站台与落地雨棚

2026-10-19。用户澄清：站区前短阶应匹配广场/站台，下面岔路侧阶保留苔石；81左右错列的厅/棚看着分散，棚有浮空感，车轮与轨道关系不清楚。

## 布局选择

本轮采用候车厅居中，后方一条接近广场全宽的站台。厅前是到达广场，两侧可以绕到后方站台。优点是入口主轴、前后关系和站区整体性更清楚；局限是25度镜头下候车厅会遮住中间的站台，因此雨棚分成左右两段露出，挡住主角时沿用整件隐去。先不扩大地图，不增加新的地形台。

站台宽40m，包括两端各1.5m斜坡，平顶37m，纵深5.2m；顶面比广场高0.39m。厅宽14m，两侧通路保持，列车停在后方轨道偏右约4m，长20m。铁路仍到地图边界，轨距和地面高度不动。

## 落地修正

81雨棚是带前后柱脚的一整张斜贴图，贴图上的柱脚/碰撞并非同一套空间结构。本轮用原雨棚图的屋瓦和木纹作为纹理，配真实双坡屋面、木梁、8根木柱、柱底石座及对应碰撞。两段棚各12.8×3.7m，柱高2.7m，全部柱底在站台顶上。材质保留绘图纹理，无新增AI图像；不把屋棚整体再抬高掩盖落点问题。屋面遮挡主角时整片渐隐，柱梁保留。

车厢原PNG是侧立面：81将其倾斜25度，且轮底放在轨道中心线，纵向关系不准确。本轮车厢侧图改成直立，放到近侧钢轨z=轨道中心+0.85m；轮底像素锚点y=轨道基准+0.25m，对应原钢轨0.18m中心+0.07m半厚。碰撞的近侧也与贴图侧面对应，补轮组下接触影。当前仍是一节静态侧面贴图，没有另一侧立面、驶动或上下车。

前短阶与外侧砖缘仍用广场同款砖石；下方岔路侧阶、挡墙及其石缘恢复79手绘苔石，80封闭挤出结构和物理斜坡保持。

## 先补用途，再决定细节密度

保留中央到达通道，把原两张长椅挪成左右座位区；补左侧出发告示牌、右侧行李车/包裹、两组花箱。道具都有局部接触影和独立阻挡，避开两侧去站台的路线。告示牌/行李车/木箱沿用旧项目自有素材，复制进assets/station82；花箱沿用godot_world既有资源，没有修改旧项目。

如果体量确认后仍显空，后续先用低花坛/疏灌木和短栏杆收广场边缘，再补少量站名/时刻表、灯杆、等车角色与小幅生活动效。不要把候车主轴和站台通道填满。当前未实施NPC、时刻表交互或全圈围墙。
