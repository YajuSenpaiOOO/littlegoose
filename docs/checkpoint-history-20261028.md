- F5 保留本局 buff，F8 清空。区域旅行保留 buff，退出应用后不保存；**没有实现跨应用存档**。

| 工作 | 需要新画图吗 | 后续验收方式 |

**不能生图的 agent 若仍能读截图，就能承担大多数迁移与适配；如果也不能看图，先做数据、规则和测试，最终视觉对齐留给我们检查。**不要把所有空间表现都当成纯数值算术，也不必把所有 buff 都当成必须新画素材。

### 当前视觉方向与边界

- 温馨、可爱，又有光影和材质的厚重感；避免过糊、土色斑点过多、空旷远景、重复贴图和互相不搭的草/树/人/房。
- 用户较认可带像素细节的环境与直立人物形成的立牌观感，不宜未经对照就整张改回极简卡通地皮。
- 现有 3D 地表 + 短草/高草混合、可穿行拨动、有逻辑的地势与草路衔接、林缘遮挡方向已经有可复用基础。不要退回整张地皮上画满“立着的草”的方案。
- 房屋主视角是**正面，水平左右旋转 0°**；25°指相机俯视角，不是房屋向侧面转 25°。新资产要与当前透视截图和物理标尺核对。
- 新贴图保留/记录脚底锚点、可见范围、世界尺寸和高度；树根、房子底边、斜摆件支点和影子的适配不能靠更换 PNG 后猜。视觉体积真的变化时再明确调整碰撞。
- `godot_world/docs/asset-view-contract.md` 的正文是早期二维/正交试验，不能拿其中线性公式当成当前透视相机的完整生成规范。

建议先做一个**小院门前 + 接入林路的一小段**作为完整视觉单元：优先光色、林缘层次和少量有主题的花草摆件，保持同一机位截图前后对照；确认后再推广到全地图。不必同时改整张地图、角色画风、地形布局和战斗平衡。

换图、布景时保留当前玩法入口和物理标尺；只要脚点、尺寸、受击体、地面高度与遮挡关系没有被随意改变，美术先做不会迫使以后重写 buff。
