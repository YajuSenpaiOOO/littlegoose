# 91：净草地与独立岩面

2026-10-20。针对用户反馈修订90：树下棕色碎斑脏且突兀，岩面与草顶混合后像贴上去的花纹。当前默认91；`play.cmd` 或 `preview_stone91.cmd` 启动。Ctrl+7西侧、Ctrl+8后林，Ctrl+Alt+K在同一机位/时间切换90原效果与91效果。Ctrl+Alt+J仍是89颜料/景深对照。

## 修订

撤掉89的树下棕色叶屑颗粒、土色覆盖，以及空地磨损层的棕色混合。树下延续同一草地，依靠原有树根和接触影接地；没有给整块草地换一层新的暗色污斑。原树图中的木质根部仍保留。

岩面不再与草顶共用一张大范围渐变混合的材质。直接对90真实地形网格按坡面法线/高度提取交界线，在线上裁切相交的三角形；草面与岩面共用完全相同的交点，因此边界明确，没有另贴覆盖片或抬高层。初版逐三角形整块分类有锯齿，最终改成插值轮廓裁切。

岩面独立成一个MeshInstance3D，使用几何面法线和新灰岩裂面材质，粗糙度.96、镜面.12；灰岩纹理沿世界三轴投射，不使用图里画好的成排苔石砌块作为整个山壁。草顶保留原草纹理直至接缝。新材质为内置image_gen生成，完整prompt与来源记录见 `assets/stone91/GENERATION.md`。

这次没有改变90的标高、道路、树位、碰撞或战斗面；原物理网格原样保留。源地形509184个三角形，裁切后岩面9020个三角形，其余仍为草地/原地面。分割前后总表面积差约0.00000227平方米，来自浮点插值。重建材质和原/新切换也保持分面。

## 为什么不要求Blender

项目已能在Godot生成网格，独立材质、几何切分和法线可以直接完成。本轮明确先修材质划分、岩石颜料和接缝。Blender不是这两处问题的前置条件。

后续若要手工雕出突出的岩鼻、悬挑、洞口、特殊轮廓，或制作成套可复用岩块，再借助Blender会更便于美术控制。现有高度场仍然表达单值高度，本轮没有加入悬挑或洞穴，也不能仅凭材质宣称获得了这些形体。

官方相关说明：<https://docs.godotengine.org/en/stable/tutorials/3d/procedural_geometry/surfacetool.html>。
