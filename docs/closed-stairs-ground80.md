# 80：连续封闭石阶与清洁地表对照

2026-10-19，接续79，待视觉体验。用户指出泥地显脏，以及站区两段石阶之间透出泥土/草；同时讨论转向候车厅、站台棚和列车。

## 石阶修正

79不是单纯材质不好：踏面为独立薄板，真正承载角色的连续斜坡穿过部分踏面，板间真缝也露出斜坡。80用阶梯剖面整体挤出，踏面、立面、两侧、背面和底面闭合，7级/3.4m前阶与9级/5.2m侧阶仍在原位，宽度4.5m/2.3m不变。原平滑物理坡面继续承载角色，不改成逐级碰撞导致走路颠簸。外侧旧石缘保留。

只隐藏两段楼梯占地矩形内的地形渲染和前阶下原铺装的渲染，不删碰撞、不挖掉实际地形；楼梯完整实体覆盖该范围。两段既有草禁刷区继续生效。材质沿用79手绘石面。rail_station80.flight80使用同一剖面生成，后续可调整总长、宽度、阶数与锚点复用。

## 三种地表处理

默认撤销暗褐泥色和实土核心去草，恢复短草。仍沿用原8个软边区域、土径和独立花茎，不更换小屋图。

1. 苔草过渡（默认）：保留原地表笔触，仅有轻微暖黄绿变化，花地底色也减弱。
2. 浅色细砾：偏暖灰米色、细小颗粒和零星浅石，避免大块湿泥色。
3. 薄落叶地：草基底上稀疏浅褐叶色，仅作林缘过渡，不压成深褐斑块。

Ctrl+Alt+1/2/3切换同一位置的材质处理，1回小屋、5看前阶、0看侧阶。此轮是已有地皮和程序材质的对照，没有新生成三张绘画纹理。若后续选定某类，再针对该类制作专用贴图。
