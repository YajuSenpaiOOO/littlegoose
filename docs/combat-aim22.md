# 战斗瞄准22：保留25°透视，先修正指向和判定

## 诊断与责任边界

用户满意画面，但战斗瞄准别扭。21版测试覆盖了直接指定世界坐标发弹后是否发生碰撞，没有充分覆盖鼠标指向到最终弹道的转换，不能据此断言手感成立。

可复现问题：21版先射线取地面，再把该点Y抬高0.65m，抬高后重新投影并不位于原鼠标处。`aim22_diagnose.gd` 实测41.0449逻辑像素偏移（1600×1000画布，实际显示还需乘窗口缩放）。此外受击球随0.38m视觉跳跃升降，22m/s子弹在约8m距离要0.36秒才能到，容易同时受到透视指向、视觉跳跃和横向移动影响。

这次先保持同一镜头、地形、怪物速度和原伤害数值，用可切换版本验证瞄准。修正投影和碰撞不等于主观手感已经完成，后续仍需玩家试玩决定辅助强度、弹速、顿挫和节奏。

## 改动

- 默认平面自由瞄准：鼠标射线与发射高度平面相交，发射点与目标点等高。射线投影回屏幕穿过鼠标，避免先取地面再抬高导致的指向偏差。
- 怪物使用XZ平面连续扫圆判定，半径0.65m（含弹宽容错），视觉跳跃不改变命中难度；实际树干/房屋/地面仍用三维碰撞射线，与怪物命中的先后距离比较，保持挡弹。限定子弹高度位于怪物脚下-0.1m至+1.7m，避免任意跨高度层命中。未来高地战斗需继续明确跨层规则。
- 轻辅助仅在鼠标覆盖怪物当前贴图的不透明像素时生效；重叠优先近处怪物，最多0.14秒的横向预判。发射后不追踪，不自动搜索屏幕附近目标，也不绕过树干挡弹。
- 默认弹速38m/s，短胶囊拖尾形状更容易辨认方向。原射速0.18秒、伤害4、怪物12血不变。
- 每次命中补短闪、横向挤压、仅该怪物55ms停顿、屏幕火花与准星命中标记。镜头保持原跟随，无全局震屏/停时。
- 复用旧版合成音效 `sfx.gd` 的柔和射击与团团怪命中/倒下配方，本项目独立副本 `combat_sfx22.gd`，音量降低；旧工程不变。
- 发射点与目标极近时跳过创建弹丸，不递增计数或访问空弹丸数组。

## 对照操作

默认入口 `preview_world_combat.cmd`。F8在新平面瞄准与21版原三维瞄准/22m/s弹速之间切换，切换清除现有弹丸；两边均保留新反馈，便于比较瞄准。F9单独切换轻辅助。F5重开，F7暂停怪物/弹丸；鼠标左键连射、WASD/Shift、滚轮保持。

21版独立入口 `preview_world_combat21.cmd`。高台、专用美术与精英/Boss移植继续暂存。

## 验证

- `aim22-validation.json`：32项通过。12/18/28三个缩放距离投影回鼠标，最大误差0.000137逻辑像素；六种贴图姿态的不透明像素选择、轻辅助、扫圆命中；长帧不穿透；近发射点保护；F8/F9切换。
- `combat22-validation.json`：沿用25项战斗物理回归并运行22版场景。包含实际输入到达林地、实际子弹击退/死亡、树干挡弹、绕树追逐、接触伤害/无敌、玩家击退、重开和暂停。
- `combat22_capture.gd`：3项实际OpenGL验证。窗口鼠标经拉伸映射到目标、按下鼠标左键经正常物理循环发弹命中、火花与命中标记在GPU图像中产生可见差异。截图 `docs/captures/world_restart/combat22_impact.png`。
