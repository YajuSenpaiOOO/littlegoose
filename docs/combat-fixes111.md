# 111：光束稳定、昼夜弹幕、重开清卡与碰撞预筛选

2026-10-22。对应用户反馈：手电筒忽粗忽细；夜间弹丸／特效保持白昼亮度；多Buff后个位数帧；重新开始没有清卡。

## 光束与调色

110把整条水柱宽度绑在最老一颗粒子的透视比例上。最老粒子走远、过期或撞墙时，这个比例会突然切换。111用主角附近的稳定投影比例统一宽度，折点使用有1.2倍上限的共享接缝，整条带一次提交三角形数组，省去逐段重复三角形绘制命令；不创建逐帧临时网格资源。

战斗Canvas加入独立CanvasModulate，读取场景实际生效的昼夜调色与曝光参数：黄昏偏暖，夜间降低亮度并偏蓝。覆盖弹丸、音符、光束、拖尾和该Canvas内的受击粒子；HUD在自己的Canvas里保持可读。发光攻击仍可看见，不再保留白昼原亮度。不是新加全屏滤镜，不会把背景重复调色。

鼠标指向无有效世界落点时拦截无穷坐标，避免水柱创建无效方向、退化线段和重复告警；已有弹丸继续完成飞行。

## 重新开始

F5、结算界面的重开与新一场演练清空本局记忆卡、额外鹅、弹丸／分裂、持续水柱、蓄力和防御状态。F5在选卡界面也可使用。幕间推进不经过重开入口，因此前一幕选的卡正常保留。F8新局保留兼容；F11改演练档也是新一场。

## 性能实现

**发布版默认保留Godot原生弹丸碰撞。** 额外脚本空格预筛选经过正确性验证，但高压样本的额外字典／遍历开销未带来稳定收益，因此 use_grid111 默认关闭。以下格缓存为实验保留代码，不把它列为已部署的帧率收益。原有敌人邻域格（群聚／汗滴／冲刺等）照常使用。

- 按旧版 goose_bullet.gd 恢复首代6向、二代4向分裂、0.06秒只飞不打／不追踪的出生缓冲、母弹速度／穿透继承及剩余寿命减半（最低0.35秒）。110二代6向与缺少缓冲会放大密集怪群中的碎片峰值。
- 弹影采用主弹优先预算，最多24个、约30Hz更新；碎片保留本体与伤害，不再每颗做贴地弹影。角色、怪物和场景影子保持。
- 保留110数据池与60Hz飞行／命中。追踪转向改30Hz累计时间更新，不降低碰撞频率；未删减实际弹丸、逐发伤害或穿透目标。
- 每个物理帧重建敌人胶囊包围格，含仍可鞭尸的碰撞体。每格记录敌人位掩码，按弹丸已经命中／应忽略的RID排除；超过30个同时可命中目标时回退原生查询。
- 固定场景空格缓存仅用于证明飞行段没有物体。格子内只要可能存在目标、墙、地面或移动秋千，就继续原生射线。未知格每物理帧最多新查8格，超过预算直接走原生，缓存超过4096格重建。
- 凹面地形从背面做体积重叠可能漏报，因此另由实际碰撞网格的四顶点保守最大高度生成地形格上界；低于该上界一律原生查询。范围外、移动摆件附近也直接回退。新静态碰撞体、地形重建和场景调试切换会使缓存失效。
- 空格预筛选先用原生物理结果对照验证，因性能收益不足未在发布版启用；不能用少算碰撞或故意漏伤害换帧率。

## 验证与结果

专项脚本 combat111_visual_probe.gd 覆盖F5／结算／选卡重开、幕间保卡、昼夜调色、最远粒子变化时宽度不跳，以及6000条随机原生射线对照。另复用原47项完整战斗检查。

高Buff性能另用 woodland111_profile.gd 实际移动／开火和七只高血量普通／精英／大王AI压测，2560×1494。最终发布版同场景对照见 combat111-comparison.json（combat111_compare.gd），额外格预筛选实验见 combat111-profile.json；不以重开清卡后的低负载帧率冒充高Buff已解决。

旧110保留；默认入口已改为111。关掉旧游戏窗口后运行 play.cmd 或 preview_woodland111.cmd，标题应为111。

## 最终实测

发布版额外脚本格筛选关闭，保留原生碰撞。combat111_compare.gd 在同一分辨率2560×1494、末幕七只高血量真实AI、移动持续开火、每项600显示帧比较；没有直接删掉伤害弹丸。选择视野内目标，避免无效瞄准影响计数。

63项专项／战斗回归和6000条原生对照均通过，包含487条实际撞击、3038条可剔除空段且0漏判（格筛选实验结果）；最终默认入口另做原生启动检查。

最终发布版通过16项专项、47项完整战斗和默认入口带 --combat 的原生启动检查，最终日志无错误／警告。直接开战请求延后到111场景和导航就绪，避免加载期间访问空导航网格；最终缓存启动29.10秒。汇总见 combat111-final-validation.json。
