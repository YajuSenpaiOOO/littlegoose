# 小黑鹅、世界准星与三维受击体23

保留现有25°透视、美术、平地林地、伤害与射速。默认试玩 `preview_world_combat.cmd`，22版独立入口 `preview_world_combat22.cmd`。

## 回答本轮设计疑问

贴图只是呈现方式，不限制受击判定必须二维。23版默认用真正的 CapsuleShape3D（半径0.52m、高1.6m、中心离地0.8m），由连续三维弹道射线与 Area3D 相交确定命中。它是对身体的宽容近似，覆盖一般蹦跳范围，保持脚下位置稳定；不是逐像素碰撞，也不把整张含透明边的图片矩形当成身体。真正从胶囊上方飞过会空，前方树干/房屋能挡弹。

屏幕准星可以正确映射到三维世界，本身不是错误；世界准星和地影增加了高度、远近与接地线索。用户是否觉得更直觉，需用对照模式试玩决定。

小黑鹅补回明确的发射来源、鼠标方向环绕、弹簧与后坐力，改善读方向的条件；不据此断言主观手感已经解决。

## 小黑鹅基础适配

- 复用旧 black_goose_v2 的 hover_gentle/flap_mid/flap_down 三张贴图、锚点与0.12s振翅节拍。
- 与旧版同样以主角的相对偏移为弹簧状态，stiff26/damp6.5。主角平移时不积累跟随滞后，鼠标改变方向时产生弹性跟随。
- 环绕距离0.45～1.05m，最高允许弹簧过冲1.35m；身体离主角脚下0.43m，嘴部发射锚点随振翅略微上下移动。
- 子弹从实际鹅嘴锚点创建，射击给偏移弹簧约0.97m/s反冲。跟随主角传送时同步重置插值。
- 当前只移植基础单只使魔，不包括升级卡、多使魔编队、特殊弹幕；使魔沿用旧版无自身碰撞的跟随方式。

## 世界准星

- 鼠标射线与“地面上方0.85m的高度面”求交；通过18次二分采样地形高度求解，避免先取地面再抬高导致投影错位。
- 默认保留22版可见轮廓轻辅助。辅助开启时，世界标识显示辅助后的实际目标与短预判位置；F9可关闭以单独评价自由瞄准。
- 世界目标上有随透视缩放的四向标记，脚下同XZ位置绘制暗环、柔影和短虚线。头部标记保持可读，地影与地形正常遮挡。
- 从实际鹅嘴到目标被真实地面/树干/房屋遮挡时，悬浮标识变橙色。此提示不绕开障碍，弹道仍会碰撞。
- 显示点与发弹点统一调用同一个目标解算；没有另取一个独立地面鼠标点冒充目标影子。

## 对照按键

- Q：世界悬浮标记＋地影 / 屏幕准星。
- F10：显示/隐藏实际受击胶囊，可直观看贴图与判定关系。
- F11：原生三维胶囊命中 / 22版平面容错命中（默认三维）。
- F9：轻辅助。F5重开，F7暂停怪物与弹丸，移动/连射/滚轮保持。
- F8保留旧瞄准映射调试切换；若需完整旧版对照，使用独立22或21入口。
