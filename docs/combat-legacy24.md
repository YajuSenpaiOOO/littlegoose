# 普通攻击与受击基础链24

## 本轮范围

用户希望先用老项目攻击/受击逻辑判断新视角战斗手感。本轮移植旧版基础普通攻击、普通团团怪受击、击退、死亡/尸体与命中节奏，保留23版的地图、25°透视、使魔、世界准星及三维受击模型。

不是整个旧游戏系统的完成迁移：闪避/弹反、精英/Boss、升级卡、特殊弹幕、剧情幕序和决心经济尚未接入。玩家生命仍显示100，旧普通怪接触2点按×10映射为20；尸体每5次受击回决心等经济奖励暂不结算。

入口：`preview_world_combat.cmd`。F12重开并切换旧基础攻击链/23试验链；F5重开，F7暂停，Q准星、F9辅助、F10胶囊、F11三维/平面判定仍可用。独立23版 `preview_world_combat23.cmd`。

## 复用的美术与渲染

复制并适配 `scripts/combat/legacy/candy_bullet_art.gd`、`hit_material_fx.gd`，复用原珍珠、枪口/命中三帧、星糖碎片和汁液素材；两份绘制脚本只增加局部坐标适配开关，使旧2D粒子运动在三维世界投影锚点中工作，避免旧global→local转换把效果画到屏幕原点。原工程文件不修改。

子弹逻辑仍在三维世界，图像用世界锚点投影到Canvas层，随远近缩放；每颗子弹有真正贴地的阴影。装饰锚点总量限制144，不改变碰撞/伤害。F12回到23链时清理所有旧装饰与弹丸。
