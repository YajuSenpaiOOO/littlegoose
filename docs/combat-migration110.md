# 110：团团怪战斗移植与持续蹲防

2026-10-22。基于 world108 林地场景；旧 godot_yard 和编号场景保留。

## 本轮范围

用户选择：先完成战斗，成长和剧情下一步接。因此移植童年战斗与完整的单次六幕流程；年龄／决心上限成长、硬撑、战后剧情和15岁以后的卡池不混进本轮。

- 默认演练第一至六幕，普通怪、精英与末幕团团大王共34只；每幕结束三选一，最后选卡后进入战果，再继续探索。
- 旧版13行幕配置保留。F11切换起始演练档（1–8），独立检查后期敌人配置；每次仍是六幕，不伪造年龄成长。F5重试，F8清空卡牌开始新局。
- 精英：远冲或双跳接连续三次落地砸击；低血缩短攻击间隔。大王：前倾蓄力直冲、跳跃砸地、向外扩散的可弹反／完美闪避冲击波。
- 地形与墙体使用原生3D碰撞；大体型刷怪增加胶囊净空检查，出生点仍要求与主角连通。
- 14张童年卡：弹弓、手电筒、纸赛车、眼保健操、森林冰火人、三人小游戏、乐器课、流动红旗、暑假作业、课间操、小零食、开小差、纸杯电话、东南西北。卡名、描述、互斥及上限沿用旧表。
- 多鹅、多弹道、追踪、音符、逐级分裂、接触伤害、汗滴、冲刺伤害及随机发卡接入实际敌人。水柱由有飞行时间的连续穿透粒子构成；弹弓组合保留蓄力松手后约1.1秒可挥扫水柱。

## 右键规则

按下右键启动原0.18秒完美弹反窗口。按住期间持续四向抱头蹲防、不能走路或冲刺；窗口结束后不重新触发完美弹反，普通命中造成原伤害60%，仍可能死亡。受力仍会小幅推移；射击保留。

冷却等待松开才启动：未成功弹反为原1秒，成功弹反沿用原0.06秒短间隔。暂停、选卡、切场、失焦、死亡会清理持续防御状态。40%减伤是本轮初始手感参数，未引入耐力条。

## 性能实现与边界

弹丸使用复用的 RefCounted 位置／美术／字典数据，不再每粒建立Mesh、单独影子与Node2D。位置保留物理插值；每次回收清除穿透、音符、分裂、伤害、追踪目标等状态。闲置池上限1024，活动弹丸和实际命中不因预算被丢弃。

单Canvas集中画弹丸与水柱。最多128颗分裂弹绘制、64个友方弹影；其余分裂弹继续移动、命中和结算伤害。水柱每条带采样最多20点；主弹保留尾迹，分裂弹省去重复尾迹、枪口声和后坐。命中反馈每显示帧最多2次完整普通受击、每敌人最多一次；致死反馈照常，墙面撞击最多一组。所有逐发伤害、连击和冲量照常结算。

追踪每0.08秒重选目标，转向仍每物理帧计算。敌人空间格供群聚、汗滴和冲刺邻域查询使用，0.1秒刷新。弹丸每物理帧沿飞行段做原生碰撞查询，穿透记录每个已命中的RID，墙体继续阻挡；没有用降低物理频率或删弹冒充性能优化。

完整压力测试记录见 combat110-profile.json。2560×1494、七只包含精英和大王的真实AI、移动持续开火；为便于持续采样，测试敌人生命提高到100万。普通战斗与极端卡组分别记录，不能混为一个帧率承诺。全叠满构筑仍未稳60帧，后续战斗打磨需要继续压成本。
