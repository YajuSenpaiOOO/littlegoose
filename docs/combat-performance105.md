# world105 战斗性能：真实开火、多敌人与高射速压力

2026-10-21。用户确认104实玩仍低于30帧。本版先解决战斗运算开销，保留104美术、原高差与交互。

## 更正104测试的适用范围

104 A/B 样本用 Sample104，把 fire_input_held() 固定为 false，主要覆盖敌人追逐/扑击，不能代表连续开火和命中反馈的实玩帧率。105改为真实持续开火、四只活动敌人、玩家移动、完整界面和声音，并增加追踪/高射速/碎片叠加的测试。

## 已落地的改动

1. 跳过隐藏的旧椭圆影子和旧准星地面圆环的地形/法线计算。旧版演员、鹅与主角阴影虽已被新投影替换，旧计算原来仍在跑。新版本不删除近景阴影、碰撞或命中。
2. 角色仍使用九点贴地轮廓投影，但复用 ArrayMesh 顶点缓冲，每个渲染帧更新一次，替代每个物理步新建 SurfaceTool 网格。使用插值后的角色姿态。
3. 子弹投影只在渲染帧更新；子弹位移、连续射线碰撞、伤害、追踪和蓄力穿透仍走原物理循环。
4. 按精确坐标复用地面高度，最多两代各8192项；不对坐标取整、不近似高度。地面网格缓存重建与105就绪时清空记忆缓存。
5. 果冻与碎糖实例合并为单次上传；已落地残留物复用静态变换。沿用原贴图、实例数上限、运动/反弹和音效。
6. 子弹画面集中到一个 Canvas 绘制器。保留原画面纹理、锚点、脉动、追踪方向和蓄力尺寸；轻量句柄继续兼容原蓄力逻辑，并在清场时回收。不再为随后立即隐藏的弹丸创建 SphereMesh/CapsuleMesh。物理弹丸没有设数量上限。
7. 最外层调试状态文字节流为5Hz，避免父层已节流而后代仍逐帧拼接。战斗血条/瞄准独立更新。
8. 显式选用内置 Jolt Physics。实测单敌人物理步约0.8–0.9ms→约0.15ms，主角约0.7–0.8ms→约0.16ms。改动需要完整通行与交互回归；没有更改60Hz物理频率。官方说明：[Using Jolt Physics](https://docs.godotengine.org/en/4.7/tutorials/physics/using_jolt_physics.html)。

试验过只合并完全水平的碰撞三角形（509184→217184），未发现明显帧率收益，未接入最终版本，地形碰撞网格保持原样。

## 如何复现

Godot console：--path godot_world --script res://scripts/world/woodland105_final_stress.gd。
2560×1494、Compatibility、RTX5060 Laptop、关闭垂直同步；完整界面和声音，四只敌人持续活动，主角沿草地移动。每个阶段900个渲染帧，连续执行普通射击、二级追踪、射速倍率8再叠二级追踪、以及同射速加每0.1秒额外果冻/碎糖。临时把测试攻击伤害调低以避免测试提前清场，主角受伤反馈照常触发并恢复生命；实际游戏伤害没有改变。记录真实发射数、命中数、物理步数、峰值弹丸/碎片/果冻/画面锚点，而不是只数画面物体。

早期拆分报告：woodland105-real-profile.json、woodland105-components*.json、woodland105-jolt.json。它们带细粒度计时，只用于定位，不能把其中最好的一段作为最终游戏帧率。
最终压力报告：woodland105-final-stress.json 与相应日志。最终回归：woodland105-validation.json、woodland105-validation.log。

这次压力测试仍不是未来上千弹幕的保证。当前每个物理弹丸仍保有独立位置对象；若继续增加弹幕数，需要继续建设数据池、空间分区和显示预算，并用明确的同屏弹数/射速/特效数作为验收条件。


## 最终结果

每项900帧，四只敌人，全界面/声音，持续移动。以下为帧耗时中位数与P95；FPS仅由中位数折算，不是最低帧率。

|负载|中位耗时|P95|折算FPS|实测射速|
|---|---:|---:|---:|---:|
|普通持续开火|15.37ms|20.45ms|65.0|6.5发/秒|
|二级追踪增益|16.97ms|22.89ms|58.9|11.2发/秒|
|倍率8再叠二级追踪|28.62ms|35.04ms|34.9|59.8发/秒|
|同上，额外碎片/果冻|29.85ms|38.39ms|33.5|58.6发/秒|

极压实际峰值83弹丸、64碎片、34果冻；最重一组最长50.21ms，900帧中210帧超过33.33ms。普通开火最长38.49ms、4/900帧超过33.33ms；二级追踪最长27.73ms。当前正常战斗有明显改善，极压依旧不是稳定60帧。不能承诺未来高密度弹幕和重特效直接增加后仍稳定60帧。

79项回归全部通过，最终回归、压力测试及默认入口启动日志均无错误/警告。默认入口启动51.4秒（本次源文件变化触发草缓存重建）。覆盖原高差、三种台阶、秋千/松果/落叶、三波战斗、普通弹真实命中、蓄力穿透两只敌人、清场句柄回收及暂停阻止开火。512个缓存对照点逐位一致；新旧轮廓投影冻结帧明显像素差率0；合并特效上传后的实例变换/颜色/图集编号与原实现一致。

105默认入口帧率面板增加当前弹丸、碎片、果冻与存活敌人数，便于后续实玩截图对应具体负载。物理后端是项目级设置；若要连同物理行为完整回退，除切回104场景外需将 physics/3d/physics_engine 恢复 DEFAULT。
