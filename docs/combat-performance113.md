# 113：战斗更新优化与慢速开局

2026-10-22。默认 world113，关闭旧窗口后运行 `play.cmd`，或直接 `preview_woodland113.cmd`。标题确认113。Ctrl+Alt+F11在慢速/原射速间切换，同时重开清卡；F5保留所选节奏并重开清卡。

## 开局节奏

基础间隔从0.14秒改为0.34秒（约7.14→2.94发/秒/鹅）。普通怪血量乘1/3，首幕12→4，即4发无Buff基础弹击败。精英/大王血量乘0.14/0.34，保持基础火力下相近的击杀时间。独立计时的蓄力/水柱伤害同幅调整，避免降低普通射速后这两项相对过强；分裂继承调整后的母弹伤害。射速卡、多鹅和其他卡牌倍率保留。本次为手感原型，尚需实际游玩调整，不声称精确复刻以撒。

## 代码优化

- HUD直接算最终六幕/持续蹲防文案，避免父子实现每帧来回覆盖文本并反复排字；位置/尺寸未变不再写入。
- 主角和敌人的贴地轮廓投影在GPU计算，使用真实自适应地形顶点与石阶支撑面高度；边界区域回退旧CPU路径。保留九点投影、轮廓纹理与接地高度。
- 地面查询缓存桥端与石阶的边界/变换，保持原三角形插值和支撑面判断，实际地形碰撞没有更换。
- 五类果冻/糖块/贴地影特效批量提交MultiMesh缓冲，保持贴图、变换、色值、数量预算与物理积分。
- Windows x86_64弹丸热循环使用本地GDExtension；原生Jolt段碰撞、即时伤害回调、数据池、30Hz追踪/60Hz飞行、6/4分裂保留。不限制有效弹丸数量，不降低场景画质。构建与许可见 `native/combat113/README.md`。

## 性能测量

RTX5060 Laptop，GL Compatibility/Jolt，2560×1494，关闭垂直同步与帧率上限。每档600渲染帧，移动/瞄准/持续实射，七个真实活动敌人（含精英/大王），敌人测试血量加大防止中途清场。六卡为多鹅、三人、两级追踪和两级分裂；极端再加两级多弹道、三级音符。旧基线为111战斗实现（112只加气泡），新旧各自完整启动。

**仍未稳定60或120帧。** P95和最大帧耗时仍偏高，后续需继续分析弹丸数据访问、碰撞/反馈和主线程更新；不能归因于美术画质或只靠降低初始射速解决。慢起步六卡中位约48FPS，极端约36FPS，均存在低于这些数值的瞬时帧率。
