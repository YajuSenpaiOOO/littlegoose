# 114：45秒战斗操作对照

2026-10-22。默认启动场景改为 world114；`play.cmd` 或 `preview_combat114.cmd` 打开模式选择。原完整六幕/选卡演练仍可由 `preview_woodland113.cmd` 体验。

## 这次要验证什么

在保留当前林地画面与原生战斗反馈的情况下，减轻瞄准负担后，走位、闪避和弹反是否值得反复玩。实现和自动测试只能确认规则、命中与状态切换正常，不能证明已经好玩。

- A：鼠标决定方向，左键射击。指向可见身体时对准实际碰撞中心；附近同方向有轻度辅助（约12.6度，横向上限按视口高度缩放）。空地向枪口高度的平面射击，减少地面位置/高度映射造成的歧义。金色地圈和身体侧括号提示目标。
- B：自动选择10米内、视野中且没有实际场景遮挡的近处敌人，自动射击。保留当前目标的小幅距离迟滞，减少在相邻目标间来回跳；小幅移动预判上限0.35米。青绿色标记提示目标。WASD、闪避和右键防御仍由玩家控制，蹲防时不射击。
- 两档均为0.34秒基础射击、每只4血、普通怪速度1、接触伤害15、同时至多3只，仅一只可同时启动扑击。清完稍歇0.9秒再补三只，不选卡，不召多鹅，不叠弹幕。不对两档使用不同敌人规则。
- 每轮最多45秒有效游戏时间；暂停停止计时，倒下或Esc会提前结束。末尾保留A/B最近一轮的用时、击败数、弹丸命中/发射数、受击和弹反供参考。它们不等同于乐趣评分。
- F2切换模式并从头开始，F5重试当前模式，F7暂停。可以从结算菜单直接选另一种模式。每次开始恢复满血、清空弹丸、卡牌、敌人和本轮计数。

初始化先显示选择菜单，不自动开打。隐藏旧版长帮助、重复准星和性能面板；Ctrl+F9仍可查看帧率，F1显示本试验帮助。

## 实现

`woodland_world114.gd`独立继承113：复用场景、数据池/Jolt命中、果冻反馈与防御，不改113六幕行为。专用HUD、模式选择/结果面板和目标标记分别在 `hud114.gd` / `trial_ui114.gd`，帮助在 `woodland_time114.gd`。首次进入缓存26个通过导航连通和真实碰撞检查的出生点，补怪时只在缓存中筛选安全距离与间距；无合适点才回退旧查找。

## 验证

19项专项通过：初始菜单、A/B真实按钮、相同基础规则、偏离身体的轻辅助/上半身选择、拒绝反方向目标、自动忽略鼠标位置、蹲防停止射击、真实遮挡、四发实际弹丸击败、清怪无选卡、补怪不重置统计、暂停计时、45秒结算、两档结果保留、切换清卡及倒下收尾。脚本 `combat114_probe.gd`，报告 `combat114-validation.json`。菜单/两种模式/结算截图在 `docs/captures/world_restart/trial114_*.png`，已查看。

额外真实AI移动射击测试3项通过（`combat114_live_probe.gd`）：自动档正常连续命中/击败，补到第五批，倒下后回到对照菜单，全程没有选卡。本次脚本只执行简单循环移动，不做闪避/弹反，23.59秒时倒下；58次命中/61发、14次击败。用于验证功能衔接，不能代表玩家的胜率或A/B乐趣差异。

## 性能限制

本轮小场景1600×1000，自动档样本中位10.35ms、P95 17.18ms，补怪方法最大13.31ms；但仍有单次583.96ms长帧，来源尚未确认，不能声称卡顿或性能问题已解决。首次样本也出现436.56ms长帧，保存在 `combat114-live-before-spawn-cache.json`。出生点缓存避免重复全网格查找，但当前证据不足以把原长帧归因于它。该小场景结果不可与113高分辨率七敌多卡压测直接比较。

默认入口启动检查通过：`WOODLAND114_READY sites=26`，约30.91秒完成初始化，选择界面保持等待，无脚本/原生/着色器错误。日志 `startup114.log`。
