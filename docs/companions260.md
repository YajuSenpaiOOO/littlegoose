# 260 团团Boss：弹飞小团团 / 专属实战记录

用户认可259当前难度与节奏，授权继续“少量普通团团＋Boss落地弹飞它们”并补记录。本版继承259，保留用户认可的分组锁点、90默认Boss血、3/2/1伤害、12决心4槽与C等级设置、258弹反安全返回/短保护、原余震球和反击窗口。与257—259共用用户试演配置，不改正式成长/奖励或重置配装。

## 同伴进场

第一轮完整连跳和弹瘪窗口都无小怪。Boss第一次弹瘪结束时排队2只，.35秒后第一只、再隔.60秒第二只；每只.85秒可见小跳进场，无攻击/目标碰撞，随后使用既有128普通团团AI。后续每次完整连跳的弹瘪结束，再补最多2只，存活上限3；候选边缘点找不到离玩家3.2m以上的安全位置则不硬塞。

每只6血、普通扑击1决心，用原种族贴图/动作/比例（body_scale=1，相对Boss2.15）。普通小怪共用1.3秒攻击门槛，且至多一只处于准备/扑击，不改变Boss攻击调度。Boss弹瘪或撞扁时，小怪取消当前攻击并停手，让玩家可用反击窗口。没有新增Boss技能、加血或恢复258强追踪。

## 落地弹飞

Boss真实落地（含反向跳）检查2.3m内、同一地面高度的小团团，向落点外侧弹开约3.2m；可见离地抛物线高.95m、.62秒，随后.90秒晕眩/摇晃。飞行期间停止攻击、身体碰撞推挤与受击；从原生敌人/锁定列表暂时移出，避免手电/自动瞄准/弹反扇弹追空中目标。仍保留世界实体与环境碰撞，普通地形限制沿safe_goal；不是穿墙飞行。晕眩落地重新可攻击，恢复后再继续原AI。

被弹飞的小团团本身不伤玩家，也不伤Boss；Boss的既有落地伤害不因此取消。玩家可引Boss打散包围，弹反仍沿原先单次反向/+2最多11/撞墙5伤规则。重复砸到还在空中的小怪不重复发射；落地晕眩的小怪可以再次被砸飞。

资产接入：无新PNG，复用tuantuan128的原作者姿态/锚点/朝向/软体材质；离地仅作用于显示层、地面根节点走真实碰撞。调用共用_add_actor_shadow，使用现存日夜轮廓影并隐藏旧椭圆；碰撞与受击单独按状态开关，不从图片轮廓推断物理体积。小怪死亡不触发Boss胜利或正式掉落，Boss结束时清理进场/空中/地面小怪与投影；F7重开、F3返回、结束均清理。

## 专属JSON与C统计

原记录的cat_damage/encounter_dps继续只指Boss，避免加入小怪后误以为Boss输出变高；新增独立tuantuan260块：

- boss：实收伤害/命中事件、真实连跳轮数和落地次数、撞墙次数、按来源weapon/parry_fan/wall及Boss阶段的伤害。
- minions：进场/退场/弹飞次数、玩家对小怪伤害与命中事件、来源、结束前存活数。Boss砸飞不扣小怪HP，不混入玩家伤害。
- parries：Boss、小团团、其它来源（本版主要余震球）的实际成功次数；独立于乐器Perfect。
- inputs：弹反尝试/空振、闪避、完美闪避；能处理C打开时hero输入计数归零，避免整场尝试次数倒退。
- phase_seconds：准备、连跳、短扑准备/短扑、弹瘪、撞扁和休息的非暂停物理游戏秒；boss.damage_by_phase对应同一阶段。
- rounds：从急眼准备到弹瘪结束的每轮时长、Boss/小怪伤害、弹瘪窗口伤害、弹反/闪避/受伤/落地/弹飞次数。原地改装在中间开始时标partial，不伪装成完整轮次。
- events：最多400条关键事件，不逐帧/逐颗弹记录，防持续手电的高频命中生成过大文件。来源parry_fan指明确标记的原生弹反扇弹；没有把乐器Perfect或所有衍生载荷猜成弹反伤害。

C右侧追加弹反分类、撞墙、弹瘪输出、小怪伤害和弹飞数。开始记录/原地改装按既有流程新建统计片段，结束JSON冻结，后续等待不改旧结果。文件仍保存到原boss_records目录，新版与旧字段兼容，旧记录不改写。clock为非暂停、受游戏速度影响的物理秒，不是未经定义的真实墙钟FPS。
