# 19：回到连续大地图

当前默认主场景为 `scenes/world/world19.tscn`。根目录 `preview_world_continuous.cmd` 或 `preview_world_3d_map.cmd` 打开新的三维连续地图。小样仍从 `preview_front_cottages.cmd` 打开18版；旧二维布局从 `preview_world_layout_2d.cmd` 打开。没有删除旧地图、改写旧布局JSON，也未改动 `godot_yard`。

## 根据旧图的什么重搭

读取 `docs/world-restart-layout.json`，保留小院、中央岔路、西侧林地、北侧车站、东侧湖岸的相对方位，五条路的转折顺序，以及湖面、岛岸、桥位和各场地预留范围。不是逐个放大或替换旧摆件。

旧布局的 `spacing_scale=1.3` 只用于地理间距，按每源像素 `1.3/24` 米转换；原小样的门口参考 `(1110,1172)` 对齐 `(-4.7,-4.8)`。树、1号青灰房、角色、草叶和摆件保留已验证的可见尺寸；路宽按各路线相对宽度转换，保持小样约1.5米级的步道。具体状态见 `world19-stage.json`。

## 本轮完成与仍需设计

重点完成“小院—林路—中央岔路”的可玩接入，沿用18版的草皮、浅路肩、土色斑和临时脚印，17版的坡面树根与斜摆件投影，以及已选中的1号房。小院与岔路额外留出镜头方向的观察空间：只排除树干不足以防止巨大近景树冠盖住整个画面，因此前景边缘与背景包围分别安排。岔路设置可辨认的方向牌。

五条旧路线都能连续行走，去湖岸的木桥有实际桥面碰撞，桥外湖面阻挡角色；各处不再受小样的 `x±16/z-36` 隐形边界限制。桥暂为原生木质几何/材质，水暂为基础水面；它们验证空间和通行，不代表正式桥岸美术。

车站目前只有正确位置、广场铺地参考和两张已校准的长椅，没有把旧车站图片硬塞进来。铺地引用 departure 的原有生成资源，贴着当前地形，不刷草穿过铺地。西林地、东湖岸和码头支路保留可达空间，区域辨识、石岸、站房、铁路、生活摆件和花草尚未完成。码头预留仍是旧支路端点，后续应按实际岸线延伸，不能视为已做好的临水码头。

## 控制

- WASD行走，Shift快走，滚轮缩放；仍是固定朝向的25°透视跟随。
- Tab展开/收起路线图，显示角色位置与共享坐标的区域/道路。
- 1小院，2中央岔路，3西林地，4东湖岸，5车站预留，6码头预留；F2岔路/F3小院，R回小院。
- U浅路肩、I土色斑、F4临时脚印、V接地/投影、P摆件对照；F1隐藏说明。数字键在大地图中用于导航，不再切房屋设计。

## 从小样迁移时处理的限制

全地图地形分成63个16米地形块，每个地形块只传入附近的道路段，当前最多24段，未将整张地图的100余段路线放进每一个地面像素。着色器容量64段，构建时断言防止静默截断。森林阴影场也改为整张地图的世界范围，解除小样 `[-32,32]` 的范围限制。

草按12米块存放，当前77批，原生距离剔除；共用同一套短高草材质与拨动参数。没有在角色每跨一个网格时重建整片草。树的显示距离有限，根部过渡与主立牌一起处理。远离角色的摆件拟合影子和独立脚点也受距离限制，避免远物的透视脚点跑到近景。

林路实景还发现原有逐像素屏门淡出在多层近景树冠叠加时形成大片彩色噪点。19版仅将当前遮挡角色的树切换到带深度预通道的连续透明，接地条与树干同步过渡，其他树仍走不透明裁切流程；另用独立、恒定不透明度的同轮廓阴影卡投向地面，角色走入树冠后不会让整片树影跟着消失。18及更早小样保持原样。默认地图不再用满屏随机点来表示近树淡出。在同一林路视点、本机1152×720检查中，全部树使用透明流程约63FPS，仅遮挡树透明后约125FPS；这是本机静态观察的基线，非全屏/全地图帧率保证。

脚印仍为48条世界坐标记录，在地形块之间同步；不按走过的地图面积增加贴花对象。浅路肩、地形、碰撞与树根使用同一地理数据，U对照会重建实际地形。地形网格构建已缓存。本轮只是扩展后的性能基线，尚无战斗与大量动态对象压力测试。

## 验证

`scripts/world/world19_probe.gd` 使用实际WASD输入走过五条路线，检查旧边界移除、过桥、湖面阻挡、各区域落地、材质分块、树干避路、脚印同步及路线图。详细结果与实际测量保存在 `world19-validation.json`。

通行检查25项；`scripts/world/world19_render_probe.gd` 另在真实多层树冠遮挡的林路中段检查连续透明的可见变化/恢复、独立地面树影的可见变化/恢复，结果5项。渲染检查同时保存最新林路截图，避免只验证区域跳转落点而漏看实际沿路的画面。
