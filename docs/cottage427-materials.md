# 427 小屋外观资产接入

外墙把 house414 的灰泥区与 wall77/painted_moss_stone77.png 用世界投影混合。露石集中在墙脚，阴湿色沿石基过渡。石基仍有立体厚度，靠同一张手绘图画出大小石头、灰缝和少量青苔。台阶接触面和 426 抬脚逻辑沿用。花盆用有盆口、胎壁颜色及真实占地的网格，纹理复用旧石材区并调暖陶色。

盆栽和窗花复用 atmosphere41/daisy_sprig.png，原尺寸 1374×1145，透明有效边界 (25,21)–(1362,1145)。根锚为画幅底部，世界高度约 .32–.57m。地面小丛取 decor42/flowers.png (1536×1024) 左上裁区 (7,22,745,471)，根锚为区底，高 .38–.62m。固定朝室外 25° 镜头的卡面，受环境光和实景阴影，地面小丛有局部接触影，卡片不另投长影、不新增占地碰撞。花盆有本体碰撞。

三个正面窗采用实体拱框、窗柱和半透明薄玻璃，窗洞真实挖空。无自发光，延用屋内暖光，玻璃不投硬影。前墙裁切同步收掉玻璃和窗花；两侧低窗原来防角色跨过窗台的实体保持。中央高窗透视可能看到一楼家具，内部保持挑空。
