# 院子地表材质与立体花丛修订

2026-10-16。用户指出第一版的石板、土路与参考图差距大，花朵应是可以穿过的立体植株。

## 地表

第一版代码生成的圆角石板与随机小颗粒撤下。用内置 imagegen 参照院子概念图生成一张双面板的地表材质，保存在 `assets/courtyard_v1/ground_materials_v2.png`；完整提示词见 `art/source/courtyard-ground-v2-prompt.md`。左半是大小不一、紧密嵌合的旧石板与苔缝，右半是带颗粒、碎石和斑驳色块的土面。生成图保持原样；两半在 Godot 着色器中采样，没有使用图像工具二次裁切或重绘。

道路仍读取原 JSON 中心线，地形轮廓独立。材质依世界坐标采样并镜像延续，避免随镜头滑动；边缘做侵蚀和草地渐入，下段铺装局部露草。它是地面材质，不包含房屋、树、花丛和长方向影，仍可继续调整地形与摆件。

当前铺装与土径已采用真正的像素材质，但形状、石块密度、色彩和边缘仍需实机评审，不宣称与概念图逐像素相同。

## 花丛

选用已有 Craftpix 灌木素材包里的粉色花穗、蓝花和橙花植株，复制到 courtyard_v1，并保留 flower-license.txt 来源文件；本轮没有新生成花丛图片。

每棵花都是 WorldProp 独立节点，与角色同处启用 Y 排序的 world 下。图像以植株根部为锚点向上生长，z_index 与角色一致；角色在后时花遮腿，走到前面时角色遮花。碰撞 footprint 为零，可以穿过。保留很短的根部接触暗部；不为每一朵小花增加独立太阳投影和点光影，避免无必要的投影数量增长。

原地表层不再画花朵，只放低矮草纹。J 对照与 V 植被开关都包含新花丛；H 可见淡紫色的花丛脚点。
