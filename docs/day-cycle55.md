# 55 连续晨昏与第二种时间方案

统一入口：根目录 `play.cmd`，窗口标题「晨昏55」。原 `preview_world_garden.cmd` 指向相同入口。54的原地形、完整楼梯、25°镜头、Compatibility与40的每波选卡保留，53眺望口继续撤回。

## 试玩

- Alt+1 / 2 / 3 / 4：清晨08:00、正午12:00、落日18:00、夜晚22:00，约两秒穿过中间时段后停表预览。
- Alt+T：120倍连续流动／恢复正常速度；不需要等待一整天。到深夜会停留，可用Alt+1回到早上再看。
- Alt+0：从当前时间恢复正常流动；Alt+P：暂停／继续。
- Ctrl+F4：林路，F3：小屋。站在门前附近按Enter休息，淡出后进入下一天06:30，恢复生命，保留已选卡牌。
- Ctrl+J / U：尘屑／人物暖补光，Ctrl+6：微光强弱，F1隐藏说明。

时间不再由战斗波次推进，首局07:30开始。06:00至24:00对应现实24分钟，可在共享资源中修改。24:00不自动跨日，也不中断战斗，回屋睡觉才增加天数。选卡、结算、游戏暂停、对话标志、失去焦点、倒下、睡觉时停表。睡觉仅限小屋附近且没有战斗／奖励菜单，不跳过未领取奖励。

这是会话内原型，退出重进会回到第1天07:30；尚未接入正式存档、疲劳、每日事件、商店刷新或日夜敌人变化。

## 美术区分与过渡

四个主时段之外，用黎明、午后、暮蓝作插值节点：

| 时间 | 视觉方向 |
| --- | --- |
| 06:00 | 微暖直射、偏冷环境、尚未完全熄去的暖灯 |
| 08:00 | 树隙柔光束、较显眼的阳光尘屑、清透冷影 |
| 12:00 | 更强且更接近白色的日光、明亮地表，光束和尘屑减弱 |
| 16:00 | 渐暖的午后，亮度开始回落 |
| 18:00 | 金橙色受光面与较冷阴影，偏暖而逐渐安静 |
| 19:30 | 暮蓝，日光退去，窗灯接过画面亮点 |
| 22:00—24:00 | 清冷蓝色环境，保留道路可读性与暖窗灯 |

同一小时同时采样日光颜色/能量、环境颜色/能量、远雾颜色、暗部/高光分色、饱和度、曝光、局部柔光、空间林荫强度、尘屑可见度与光束强度。每段使用smoothstep权重，节点处值与一阶变化连续；不在整点切换四张滤镜。保留长距离雾，避免恢复被拒绝的近距离灰雾。

夜间降低日间阳光开口的强度，避免林地仍有白天的暖亮斑。窗户只在既有三个玻璃范围内增加自发光，木梁、楼梯不增加夜间发光。后处理的蓝色分级对这些玻璃和木灯玻璃减弱，保留冷环境与暖光的对比。人物暖补光夜间设保底，受伤红闪继续有效。

晨光复用51已烘焙的独立开口，另含小院开口；五个既有柔光束网格复用到附近开口，远距离渐淡，无体积雾、无新增阴影灯。尘屑仍为96槽。其它区域共用时间资源，不需要给每棵树分别设置早晚。

## 调整与边界

`assets/lighting55/woodland_day.tres`使用`day_palette55.gd`资源：可改一天时长、起始/醒来/停留时间、各节点颜色和强度。`day_clock55.gd`只负责日数和时钟；`world_time55.gd`把结果送到已有材质与灯光；`day_fill55.gd`把白天的空间光照场逐渐减弱。可在其它场景复用同一资源及采样逻辑，场景只需绑定自己的环境、日光和发光物。

本版保留原太阳/投影方向，不实现日影转向和随太阳高度拉长。现有树影、摆件影和人物影来自不同投影路径，后续应统一方向更新后再加入移动太阳，避免地面和角色影子对不上。没有增加地形改动、重烘焙循环或运行时贴图读取。

验证脚本：`scripts/world/day_cycle55_probe.gd`，结果`docs/day55-validation.json`；截图在`docs/captures/world_restart/day55_*.png`。覆盖时钟推进、暂停、深夜停留、睡觉、插值连续性、四时段实际渲染、林路光束、缓存复用和战斗兼容。不把短时测试当成偶发卡顿已解决的证据。
