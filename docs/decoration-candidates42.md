# 林间装饰候选 42

2026-10-17。当前候选层继承 world41 → world40，不改已确定的镜头和每波选卡规则。

## 玩家硬件优先：继续 Compatibility

用户明确担心其他玩家的硬件覆盖，因此本轮**没有切换 Forward+，没有创建要求 Vulkan 的正式入口，也没有启用原生体积雾**。Forward+ 不是 NVIDIA 或当前机器专属，但它的图形 API、驱动和硬件要求较高；将来可以考虑高画质可选档，不宜为了光束直接抬高最低配置。

当前新光束仍是风格化模拟：增加宽度、柔化两端与横向边缘，使用缓慢的世界坐标雾状噪声打散均匀亮带，并以场景深度淡化与树/地面的交界。它不是物理体积散射；默认关闭，Ctrl+F12 对照。真正随光影计算的原生体积散射仍需 Forward+。参考 [官方渲染器支持表](https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html)。

轻景深仍默认关闭。相较 41 的极弱模糊，42 的半径从 1.6 增至 3.4 像素，远景起效范围从角色之后约 7 米缩到 3.5 米；人物和附近地面保持清晰。它依旧是 Compatibility 下的简单深度模糊试验，不是原生散景，也不包含动态模糊。

## 素材与选择

新资产由内置 image_gen 生成，使用现有 forest14/a_trees.png 与 house16/slate.png 作为风格参考。原始透明图集、提示词、锚点数据均保存在 `assets/decor42/`：

| 图集 | 四个候选 |
| --- | --- |
| flowers.png | 小雏菊、蓝风铃、淡金花、粉苜蓿 |
| shrubs.png | 野枝矮丛、林下蕨叶、蓝果小丛、蔷薇嫩枝 |
| stones.png | 暖灰卵石、青灰圆石、微苔碎石、浅色石片 |

这是供用户选择的候选资源，不代表风格已经验收，不应把 12 种全部密铺进大地图。当前默认搭配为小雏菊＋蕨叶＋暖灰石，在小院到入林路稀疏布置。被否定的 41 版精细花朵隐藏，但文件保留。

根目录 `preview_world_decor.cmd` 进入 world42。Ctrl+F2 打开/收起选择面板，点击每类任一候选，再点“回到场景”或 Esc 收起；选材面板打开期间停止人物输入、取消蓄力并屏蔽射击。仅探索状态可打开。GUI 选择保存到 `user://decor42_choices.json`，下次启动恢复；不会写入卡牌或战斗存档。

F12 对照整套氛围；Ctrl+F12 柔光；Alt+F12 景深；F3 回小院。旧战斗控制、选卡、F5/F8 和地图快捷键保留。

## 接地、交互与复用

- 低花使用一个 MultiMesh 批次。草木有微风、近身拨动；矮灌木沿用已建立的树根裙边适配，不增加行走碰撞。
- 8 颗石子是独立小物，固定世界尺寸；更换贴图不累计缩放。轻碰时根据角色移动方向获得少量速度，小跳、滚动后落地。地面 Y 取当前实际三角网格；靠近树/房屋时检测物体碰撞，水面不允许滚入。
- 石子本身没有阻挡胶囊和弹丸的碰撞体。这是地表互动试验，不是战斗道具，也没有做正式石子声效。面板可关闭踢石；当前动态石子位置不跨启动保存。
- profiles.json 的可见范围取 alpha>=0.5，不把透明像素中的 RGB 扩散误算为轮廓。运行时裁出各象限并生成 mipmaps；原图完整保留。

## 代码与验证

- `scripts/art/decorations42.gd`：候选、摆放、面板、被动踢石。
- `scripts/art/woodland_atmosphere42.gd`：替换 41 的花、柔化光束、调轻景深；继承旧氛围的开关恢复机制。
- `world41.gd` 只增加可覆盖的 `_atmosphere_script()` 接口，41 的默认资源不变。`world42.gd` 选择新模块并处理选材面板输入。
- `scripts/world/decor42_probe.gd` 与 `docs/decor42-validation.json` 记录实际图集加载、同机位四组比较、缩略图尺寸、开关、踢石落地及战斗入口验证。
- `scripts/world/decor42_performance.gd` 独立采样开关前后的本机帧时间，输出 `docs/decor42-performance.json`；不是低配电脑的性能保证。
- 截图：`docs/captures/world_restart/decor42_catalog.png`、`decor42_set1..4.png`、`decor42_home.png`、`decor42_softlight.png`、`decor42_focus.png`。

本轮 16 项检查通过。本机 1440×900 小院单独采样各 120 帧：关闭氛围约 112 FPS，装饰层约 110 FPS，另开景深约 111 FPS；只能说明这个机位未出现明显退化，不代表已验证低配机或战斗峰值。

本轮保留候选供挑选；下一步依据用户选中的材质和大小再推广到更多区域，不要未经确认重画主角或整张地皮。
