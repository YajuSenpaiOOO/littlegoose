# 05：纠正草的含义、恢复立牌方向、先核对视角

2026-10-16。用户澄清：希望原本画在地皮上的短草、高草变成可穿行、可拨开的植株，**不是额外撒许多灌木丛、奇怪的花或圆团状草**。认可旧细节地皮，光照要有厚度，允许人物与环境不同画法并强化立牌感觉。

## 本轮已做

- 主连续世界移除小屋的混搭花丛、低灌木组和路边免费平贴草，默认不生成互动植被。保留旧细节底图、地理布局、人物和镜头手感。
- 单独的 preview_world_grass.cmd 显式使用 --grass-count=420，只保留细小占位草验证拨草机制，去掉其中所有灌木组。其免费草也不是正式美术方向；G 可关闭。主场景/preview_world_art.cmd 不会再默认刷这些素材。
- 日光的环境项从 (0.78,0.81,0.84) 调整到 (0.65,0.70,0.78)，直射项 0.18→0.30，保住大致亮部强度；太阳影透明度 0.22→0.30，冷色暗部增强。夕照影透明度 0.26→0.32。是 2D 近似的对比试验，不宣称已实现实体表面的完整自遮光。
- 新树不扩产，现有六棵候选仅保留做对照。人物不为迁就环境而改画法或压扁；原有鞋底锚点、接触影、前后排序和方向影继续负责接地。

## 性能问题的准确回答

04 版本的所有可见草顶点都会检查人物距离和八个脚步记录，即使最后形变为零，也不是只有被踩到的草才付出计算成本。每株没有 CPU 脚本/碰撞，并不等于每株免费。

05 添加了人物和仍有效脚步记录共同包围的局部矩形。每帧 CPU 只处理固定八条历史记录更新范围；顶点着色器对范围外的草跳过距离/回弹循环，范围内才算触碰。范围外仍有范围判断、基础风摆和绘制成本，透明叠画与节点排序也仍有成本。未做“范围外零开销”的承诺。

尚未把全世界每片地皮改成植株或完成分区加载/远近分级。正式铺满草地应控制同屏数量，近处保留细节和互动，远处/画外简化或按块管理。04 的 0/420/1680 测试是当时混合素材的本机短样本，不能直接当作 05 机制或未来全图战斗预算。

## 制作次序

1. 先核对共同视角，35° 只是已有白模候选；当前连续世界尚未严格按此校准。
2. 用旧细节地皮为材质依据，制作一组自然短草/高草，保留拨开回弹机制。避免球状灌木、强卡通叶团和不相关花种替代草。
3. 同屏放少量花/花盆、树的体块和房屋白模，检查从小草到建筑的一致性；不先把所有花草都制作完。
4. 这组通过后才做变体、自然分布及树木扩产，随后处理道路林缘层次。

统一视角的具体几何约束与生成参考方式见 asset-view-contract.md。本轮没有继续生成图片，避免在角度还没通过核对时再扩大不合适的资产。
