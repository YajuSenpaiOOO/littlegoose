# 61 远水柔光

用户目前偏好绘本水，5号绳桥比7号石桥自然。采用5号绳桥＋绘本水作为当前工作搭配；石桥保留可切换，桥墩水线、局部水纹与反射的打磨暂缓，不把这项变成当前前置工作。湖水与远景效果仍待用户验收。

本轮只调整水面反光。lake61继承60的近水算法，按相机空间深度与主角焦点的差值渐变：焦点后4米开始、后17米完全过渡为远水反光。以更宽、更平滑的波峰和慢速明灭取代远处细碎亮点，稍提高远处反光的发光分量，再交给原有景深化开。近水算法、绘本贴图底色、地形、水位、碰撞、全局景深强度均不变；无额外反射相机、灯光、纹理采样、渲染通道或模糊后处理。增加了少量材质数学计算和每帧一次焦点深度参数更新。

远近判断随相机和角色位置更新，无需给每片湖面手工划区域。这里是画面反光表现，不是实时水体物理或角色倒影。黄昏仍偏金、夜里减弱偏蓝。

入口play.cmd / preview_world_garden.cmd，主场景world61。Alt+V只开关远水柔光；Alt+G总波光、Alt+M总流动保留，关闭总波光也会关闭远水亮点；Alt+W独立水色，Alt+5/6/7只换桥，Ctrl+F6回桥。

验证lake61_probe.gd共7项通过：默认搭配、近处区域像素完全不变、远处明显变化且随时间动画、关闭时与60全画面一致、总波光开关覆盖远水、Alt+V输入。lake61-validation.json记录近处变化像素0；截图在captures/world_restart/lake61_*.png，已查看正午/黄昏/夜间实际渲染。性能同机位交错60/61/61/60，各预热30帧、记录240帧，见lake61-performance.json。

本机RTX5060 Laptop、Compatibility，两个片段的中位帧时：60为13.420/13.052ms，61为13.914/13.770ms，片段中位数均值13.24→13.84ms，约增加0.6ms；绘制次数均670，960记录帧未出现超过33.3ms帧。新增数学计算有成本，短测不代表其他设备或已排除偶发卡顿。

60的岸线折角、桥头衔接等待办保留，本轮没有把桥与湖岸当作最终美术定稿。
