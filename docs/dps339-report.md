# 339 自动输出基准：五槽位纸城堡

> 340复核更正：实际弹力球走275“原弹改向”，普通反射原本有效；此前仅从273回调被绕过推断结构反弹未生效不准确。340新增的是结构间目标识别与同体别名去重，保留原弹/速度/一次70%反弹。339原始DPS结果仍有效，不能把单城堡无增益本身当作Bug证据。见dps340-report.md。

本轮只增加测试脚本和结果，不改游戏耐久、碎片倍率或338入口。26组原生Godot样本全部完成，无运行错误/检查失败；3组第二随机种子复测DPS差异<.001。现有用户CFG哈希全部保持。

## 方法

- 用woodland_world338真实城堡、子弹池、技能/载荷/伤害/碰撞链路；城堡测试血量暂设100万，避免窗口中途结束。
- 固定主角与中央城墙段，XZ距离3米/6米；关闭炮台/敌人出招、纸偶召唤和伤害停顿/受击纸屑。保留地形及普通场景遮挡。不是移动、生存或通关实战。
- 以原生物理步1/60秒驱动，Engine.time_scale=2、physics_ticks_per_second=120加速；真实脚本收发弹，不把理论倍率相乘冒充DPS。
- 每组20有效战斗秒（不含暂停与手电变身前摇）；另加手电40秒窗口。冷起手计入发射与飞行延迟，不计窗口结束后的残留弹后续伤害。
- 自动持续攻击；弹弓满蓄自动松手，另测半蓄；手电分别测不按Q与一就绪就按Q。无主角时刻。低于5槽的控制组明确列出，不假装槽位相同。

## 解读与代码核对

1. 弹弓＋冰火人对弹弓的5.88/4.20=1.40，正好符合额外鹅40%伤害的既有规则。普通攻击也同样4.90/3.50=1.40。本批没有发现该组合异常倍乘/重复结算的证据；不能单靠这批输出测试证明所有技能交互均无Bug。
2. 满蓄高于半蓄，优势约10%。并未出现半蓄无限高频反超的情况。满蓄20秒17次松手、半蓄28次，释放比例实际记录在JSON。
3. 弹力球在本城堡单目标没有额外输出。340复核确认275原弹普通反射原本有效，339从273回调被绕过推断反弹未生效不准确；不能把无第二目标时没有附加伤害本身当作Bug。340已补结构间后续目标识别及同体别名去重，多目标结果见dps340-report.md。
4. 小零食会分裂，但当前测试只有一个城堡，碎片按既有338规则忽略刚命中的同一结构，故不增加单体伤害。这不是对清杂价值的结论。
5. 纸飞机在固定单城堡场景低于直接攻击；它替代连续普通射击，带有巡航/落地延迟和范围覆盖成本。需要多个目标、炮台并存和移动输出场景复测，不能由这一行判定纸飞机整体弱。
6. 手电前20秒吃到完整第一次主动收益，40秒加入冷却后平均回落；因此应同时比较短爆发和完整周期，不能只截红灯段。
