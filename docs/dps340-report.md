# 340 结构间反弹与对照复测

入口仍89/boss314，当前340；16/144血与技能倍率保持。只修结构目标识别/同体别名去重，不凭空增加单目标伤害。

## 对339判断的更正

现行弹力球并非只走273回调，而是275在真实命中后保留原BulletState直接redirect。普通墙面反射原本有效；339关于“结构提前return使反弹完全失效”的推断不准确。340在实际redirect275入口扩展可选目标为附近敌人、炮台、城堡各受击段（半径沿用结构侧6.5米），并检查地形/布景遮挡。无第二目标时按真实法线反射离开。

不生成新弹，不丢失原速度；反弹结束贯穿，伤害70%，第二次命中结束。起始结构的Area/StaticBody均加入忽略，城堡五墙段共享生命视为同一结构，不允许同一弹借碰撞别名重复命中。分裂子弹仍各有自己的原弹反射预算，反弹命中不再分裂；光束沿用当前275折射标记，不恢复旧273的新弹队列。记录以bounces275而非预先设置的ball273判断是否已反弹，修正结构反弹伤害归因。

## 结果

同339真实原生链路，6米、20秒、满蓄自动释放，所有组合均含眼保健操。目标是单城堡，以及城堡＋两门不出招、100万血的副目标炮台；不是普通16血炮台的真实战斗。

|组合|槽位|副目标|城堡DPS|炮台附伤DPS|合计DPS|
|---|---:|---|---:|---:|---:|
|弹弓|4|无|4.20|0|4.20|
|弹弓＋冰火人|5|无|5.88|0|5.88|
|弹弓＋弹力球|5|无|4.20|0|4.20|
|弹弓|4|两炮|4.20|0|4.20|

|弹弓＋弹力球|5|两炮|4.20|2.94|7.14|

弹力球双目标组换种子复测仍为4.20+2.94；20秒17次原弹反射，共给炮台58.8额外伤害。没有把附伤计成城堡DPS。实际16血炮台会倒下并重建，副目标可用性减少，所以实战长期合计不保证7.14。

这支持两种不同用途：冰火人更快集中拆城堡；弹力球能在攻击城堡时顺带压炮，或从炮台转弹城堡。当前没有依据整体加血或削弱冰火人，先保留数值再实玩比较输出窗口/受击压力。
