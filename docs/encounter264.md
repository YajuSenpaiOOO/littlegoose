# 264：林间热身到大团团挑战

用户授权试做普通战：场内两三只团团先玩，触发后开战，后续团团陆续入场；固定名单清完获得Boss对话挑战资格。用户明确要求“最后几个也跑过来了！”等旁白式提醒由小黑鹅用气泡说。

## 这版怎么玩

- 开场2只团团在小范围跳着玩，主角在场地南侧。暂用E打招呼开战，不锁定最终触发方式。
- 场内原来的2只直接进入普通AI，不换演员、不传送。6血/扑击1伤，沿用262气球剑控制与263武器/红灯表现。
- 第一次击败触发下一批2只，累计第3只被击败后触发最后2只。入场间隔1.1秒，所有活体（含入场中）最多3只；初始2+增援4，总共6只。
- 复用261真实林边路线/叶片/小跳。没有合法入口先等.8秒重试；入场途中受阻取消时归还该名额，补一只，不能把取消算击败或提前清场。
- 6个名额全部入场且全部被击败才结束。没有限时取胜、无限刷怪、无伤/弹反数门槛。
- 清场后恢复决心，解锁大团团对话；尚未发正式材料/碎片，旧119液滴奖励不触发。
- 靠近大团团3.5m以内按E，选择“来比一场”才进入已认可Boss战，可选择“等一会儿”。未解锁时只能得到小黑鹅提示。
- Boss失败可直接重试，无须重打普通战；F7重试当前战斗，F8回玩耍开场但保留本次资格。首次清场后F7也不能越过第一次Boss对话。
- 挑战资格仅本次预览运行保留，不写正式存档；退出游戏重置。正式地区进度和奖励后续再接。

## 小黑鹅提醒

复用speech112旧气泡图框与尾巴，新speech264只加暂停冻结和明确“小黑鹅：”署名，气泡仍跟随真实主鹅，不拿其它召唤鹅当旁白。开战、最后一批、清场及Boss结果用气泡；波次本身不弹旁白横幅。最后一批第一次成功生成时说“最后几个也跑过来了！”，后续补位不会重复刷台词。生效/等待/挑战按钮属于UI，其余环境不改。

## 接入与隔离

264继承263，不改旧预览。encounter_roster264只管6只名单、阶段门槛和重试计数；世界264负责场景/交互与阶段切换；minion264在262普通演员上加无伤玩耍状态，沿用原画、锚点、统一影子和真实碰撞。Boss待机保留脚下实体碰撞，关闭目标区域与AI并从敌人列表移出，不可提前伤害，也不会打断普通战。Boss启动重新使用原263链及首轮独自教学，不变更Boss血量/伤害/追踪。

所有新提醒使用旧图像资源，无新PNG/灯光/主角几何/树避让变更。挑战对话先用现有引擎确认窗，属于功能试验，尚未制作正式对话皮肤。

C装配/等级沿用257原配置。普通战记录放encounter_records，Boss仍用boss_records；report补encounter264区分类型、6只进度、资格、本次普通战结果与输出。正常战斗结束保存已开启的记录，回开场/重试也先结束当前记录；最终报告已有encounter264时保留归档快照。C“应用并重开/开始记录”在开场或清场状态先开普通战，再启动记录，避免按E时重置掉刚开的记录。C原地应用保持当前名单，统计片段标partial，不冒充完整普通战数据。
