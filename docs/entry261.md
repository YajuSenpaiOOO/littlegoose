# 261：林边入场与自主追击

用户已选择从林边或坡后蹦进来，后续可复用到普通遭遇。

## 行为

- 修正260在Boss弹瘪/撞扁时每帧重置小团团恢复计时的全体停手机制。261小团团继续正常追击与扑击。
- 保留一次最多一只准备/扑击、1.3秒攻击预约间隔；实际被砸飞、弹反或晕眩仍响应各自控制。
- 保留第一轮单独教学、后续增援2只与活体上限3。Boss血量、伤害、锁点和初始12决心/4槽不变。
- 增援先在林边晃动叶片.55秒，再沿实际导航路径连续小跳进入；进入后才加入战斗目标列表。小跳复用现有轻落地声。
- 规划检查外围起点距中心至少7m、距主角4m、起点间距1.2m、胶囊净空与地面高差。独立入场导航在摆件就绪后烘焙，不替换当前战斗导航。
- 入场受阻1.5秒或超过6秒取消，不传送到场内；不存在有效路线则取消该次生成。地面追击受阻会尝试短暂侧跳。
