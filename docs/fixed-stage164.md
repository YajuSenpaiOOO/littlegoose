# 固定幻想舞台 · 164

按用户反馈，把163跟随角色的装饰光膜改为固定的区域增益。Q在开启位置展开半径6.5米的地面圆，持续7秒；角色只有在圆内、且和圆心高度差小于1.2米时，获得伤害×1.3和射速×2。离开不拆区域，可返回，但持续时间不暂停/不刷新；结束后冷却20秒。本身不提供免伤。枕头窝仍为3秒存在、消失后10秒冷却。

## 空间与表现

区域中心保留为世界坐标，镜头或角色移动不会带走它。地面网格在开启时采样原有floor_height生成，约0.72秒展开，柔和蜜桃底色与细边界沿地形铺开；不修改地图。地面样点与圆心高度差超过1米的地方淡去，避免把下层或断崖当作平地连接。视觉调色膜使用圆心和世界半径的投影轴，随相机投影变化，而不跟随角色；边界以真实地面圆及HUD“圈内/圈外”为准。

沿外围放五个世界空间纸风车。头部使用原163四片折纸的程序像素纹理，木柄使用独立像素图，均由Godot运行时创建，不依赖额外生成资源。风车脚点采样地面；太低/太高的落脚点隐藏。木柄和转子各自加入已有地形轮廓投影，共10个，复用159昼夜环境染色。五个摆件与投影只创建一次，重复开启复用，避免累积。无阻挡碰撞、受击或伤害判定。

当前保留匀速轻转，无杆身风摆、战斗强度风速或剩余时间风速映射，这些按用户意图后续再做。区域星星也固定于圈内，取消随角色移动的舞台标记和人物残影。结束保留0.65秒视觉淡出，此时增益已停止；暂停冻结计时和转子。

## 增益与组合

射速通过原buff rate通路变为×2，同样影响放飞间隔和弹弓蓄力。伤害继续使用发射时快照：圈内发射的弹、飞机载荷出圈后仍保留这次攻击的增伤；人在圈外的新发射无增伤。固定载荷与剑、分裂不重复倍率。圈外可以继续普通攻击。课堂笔记与主角时刻仍共用单主动位置。
