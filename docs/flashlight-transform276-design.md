# 手电变身设计草案 · 被窝里的英雄

本轮用户要求开始变身设计，允许不neta但要燃帅、不过于露骨。这里只记录可实施方案，276没有改变手电战斗规则。

## 核心视觉

用“被角披风＋玩具手电＋自制纸贴章”的童年英雄想象。现有主角服装/白毛/身形/脚锚保持，不改成特定作品的银红装甲。披风为一角柔软被子，淡奶油外侧、暗蓝小星点内衬，长度不过脚、不遮脸；贴章用自有手绘小鹅/星形纸贴，手电保持家用玩具轮廓，避免现成变身器/胸灯图案。手电造型和持握姿态需要专门画稿或现有角色分层适配后再实现，不能用歪斜整个人来模拟抬手。

## 一次约.7秒的启动节奏（待实玩）

1. 0–.12s：手握开关“咔哒”，身体轻沉、脚下站稳，低频开始收拢。背景只做短暂局部压暗，仍能读到敌人和危险。
2. .12–.38s：被角从肩侧向后舒展，轮廓被窄暖光勾亮，纸贴章一闪；不是满屏散碎粒子，力道来自聚拢和姿态。主角白毛末梢稍后跟随。
3. .38–.55s：双手握手电向前递出，光束聚成极亮的一点，声音短暂留白。此处可试.04–.06秒短顿帧与小幅推近，不长时间锁镜头。
4. .55–.72s：光束前冲、披风向后受力，低频冲击叠一声清脆电子音，进入可移动/转向的持续状态。

参考方向是“蓄力的安静与发射的爆发形成反差”，不用交叉双臂发射姿势、具体作品的开场镜头、彩色计时器轮廓、原台词或音效。

## 主动规则提案（尚未实施）

约8秒持续，前6秒正常强光、末2秒电量红灯与加速提示音、伤害提高；结束时光束收窄/开关熄灭，被角轻落回收，进入冷却。首先不混残血触发，避免压血成为必选策略。持续时间从真正出光起算，不吞启动动画时间。变身短保护/操作锁定/冷却起点需要实测，不靠长无敌拖过Boss。玩家仍能看敌人动作和撤退路线。

主动槽建议与主角时刻/课堂笔记一致选择其一，装配时明示，不偷偷占同一按键；正式输入/冷却数值下一轮结合现有主动实现决定。先做可回退试演，再接自有被角/手部/手电画稿，不需要同时改Boss外形。
