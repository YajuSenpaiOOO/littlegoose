# 288 手电主动技能 / 三秒红灯 / 原角色轮廓同步

用户反馈287移动轮廓抽动，要求红灯改3秒，并授权接入具体技能、讨论伤害冷却。288继承276最新战斗功能，复用284姿态、286光柱和287原创声音，保留旧预览。

## 第一版规则

装备被窝里的手电筒（2槽）后，战斗中按Q变身。沿用约3.15秒进入演出，暂停战斗/角色输入；显形恢复移动后才开始8秒有效时间。期间按住左键直接发射可瞄准贯穿光束；闪避/防御时停射，状态时间继续。前5秒正常光能，后3秒红灯，满血同样触发，无残血二次叠伤。结束后.45秒散光退场且保持移动，光束采样和待生光线分裂立即收束，恢复普通攻击/原武器；冷却从光线结束起30秒。

不做极长冷却的一键满血Boss秒杀。初版旧光线基准倍率前段1.2、红段1.9，红段为前段约1.5833倍，射频仍为.04/射速倍率；倍率仅用于真正有效期内发出的光线。Q与主角时刻/课堂笔记共享主动位，装配互斥。气球剑等既有互斥沿用275。初次无配置默认4槽光能弹力（手电2+弹力球1+课间操1），C可自由改。

普通时buffs不携带flashlight武器标记，但levels226仍保留已装备主动，防止常态继续发光束；有效期才临时赋回武器标记。弹弓常态蓄力保留，变身时按住直接照射；纸飞机常态普通载荷保留，变身时临时改直射光线，期间不让旧飞机点击处理器排队投弹。弹力球光线保留原采样对象改向，既有分裂/射速/队友倍率仍走原解析，不另乘一次已经解析的伤害。

技能期间C/暂停冻结计时和冷却；手动取消、倒地或离场中断消耗冷却。新一场普通战/Boss挑战恢复可用，便于独立场次测试。退出或换装清理状态、附加材质、声音，恢复输入/相机。当前仍为开发预览技能配置，没有迁移正式故事获取/跨场景存档。

## 伤害实测

固定Boss碰撞体、无其他增伤/追踪/分裂，200个真实发出的光线采样经过原生追踪/飞行与实际碰撞：前段每采样.197647，红段.312941，总200次光线命中，8秒总伤48.17647。约为默认90HP Boss的53.53%。对应理想单束DPS约4.94/7.82，不代表跑跳Boss实战命中率。此碰撞台允许末端采样完成飞行；实际技能结束会收束尚未命中的采样，所以真实8秒结果还会受距离和飞行延迟影响。测试把固定Boss血量放大至10000防止中途死亡，比例按正式预览基线90换算；并非调低/改动默认Boss血量。

允许残血收尾与成型组合快速击杀，不设Boss专属伤害上限；高射速、队友、分裂等构筑可超出这组单束结果。首先根据玩家实际照射时间和伤害占比再调倍率/冷却，不通过延长等待来弥补过量伤害。战斗报告新增flashlight288的激活数/实际光线伤害/参数，并更新旧红灯倍率字段，避免继续记录残血×2。

主动光线使用287原创能量底音，288技能渲染器停用旧光束每.12秒重复的糖弹枪声；命中反馈仍保留。

## 轮廓修正

287复制Sprite3D轮廓在_process读取当前物理变换，而原角色走物理插值；二者有不同步来源。288轮廓直接作为原角色材质next_pass绘制，使用同一原生网格、帧UV、翻转、缩放与插值，不再显示第二张轮廓卡。独立光效/胸前标记根节点使用get_global_transform_interpolated并关闭自身重复插值。轮廓alpha邻域使用线性采样和软阈值，降低亚像素硬跳。

next_pass仅附加在当前主角实例材质上，记住并恢复此前通道；材质切换时先恢复旧材质，再跟随新材质。原基底材质/几何/受光/碰撞与影子策略不改。轮廓正常深度测试，无禁深度置顶。连续运动观感仍待用户实走验收，不能用同网格断言代替无闪烁视觉验收。
