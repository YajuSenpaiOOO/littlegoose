# 386 正面施法实战

在385森林战基础上接已确认的两格连体正面动作。主鹅仍继承385无场景碰撞/4.6m/s实际三维限速，多鹅仍168鸟形和40%伤害，主角192与侧背层序不改。旧385保留独立入口，新386存档、装配和记录路径隔离。

正面显示沿用383独立四帧翅膀、受光、悬浮呼吸与并集地影，新增身体两格Atlas来自已保存的无翼源图，信息见assets/black_goose_attack386/manifest.json。每格512×1024，共同脚锚256/887和1.44/767密度；手臂与表情仍连体，第三格不采样。侧背无攻击稿，继续当前飞行显示。

普通释放保持.32秒后直接idle，高速4Hz入/3Hz出保持释放，只追加有界小后坐；光束按真实发射事件及beam_left110保持释放，停止回idle。后坐沿真实-Z，头不因出手额外缩放。准备只利用已有蓄力或慢速攻击冷却，释放后至少有.1秒idle才允许为下一发准备，避免短间隔重新插入回抬手。实际fire_at、蓄力释放、emit_stream仍同步调用原实现，不await动画、不推迟冷却。显示只在原发射后获通知；发射调用内部枪口先按释放掌心计算，保留原弹幕5px前置偏移。复制体、实际弹体/伤害/弹数保持原武器。

goose383只增加默认仍指向flight_visual383的显示工厂方法；386覆盖为新显示，383/384/385默认不受此替换。world386仍禁用旧主鹅重复影，F8旧鸟对照和影切换继续可用。暂停冻结动作/翼/悬浮，重开按385放回主角旁。

启动：父目录00_开始游戏.cmd回车/1为386，独立129/flight386，128/flight385为旧对照。F4切手动瞄准，朝画面下方开火可看正面；C装配，手电筒仍按原Q技能启用，F6暂停，F7重试，F8鸟形对照。

验证：validate_attack386_state检查无首发准备门槛、三模式释放→idle、高速/光束保持。validate_flight386在真实森林检查工厂、四向/枪口/伤害、实际首发即时产生弹与释放事件、5px原生偏移还原到掌心、光束真实发射、暂停/侧背层序、无碰撞和速度上限、复制40%、重开与旧CFG完整性。状态测试不等于硬件输入延迟测量；美术衔接与持续实玩观感仍需用户确认。
