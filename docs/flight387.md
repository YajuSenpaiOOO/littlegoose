# 387 自由空射 / 稳定瞄准 / 羽毛弹

386接入后的用户反馈：瞄准变笨、无锁定不能开火、羽毛未接，基础射速也闪姿态。此轮保留386独立对照，新387修正显示对输入的依赖并补基础弹视觉；不调整基础攻击间隔或伤害。

1. flight_visual386提供可覆写trigger_held386；387显示只读physics侧缓存held387，不再每帧调用有刷新瞄准副作用的fire_input_held。旧386默认函数行为保留。
2. 387刷新轻辅助/鼠标射线时使用主鹅global_position+UP*.44的稳定参考，不使用会在idle/ready/release之间变动的手掌高度。实际发弹仍来自释放掌心，同步原武器、不等待动画。手动/自动轻辅助原选择规则保留。
3. 自动模式原来必须有target114才会开火，这不是本轮新写的判断，但不满足用户空射需求。387在原输入基础上允许无锁定时左键向鼠标平面方向发射，仍检查暂停/角色控制/防御/倒地/笔记写入等约束；自动有目标原自动射击继续，F4仍切手动。
4. 基础.34s间隔对.32s姿态窗口仅剩.02s idle。387按可读停顿阈值进入保持：间隔<=.44s保持释放，退出需射速<2Hz。普通慢速仍释放→idle，不再插恢复ready；实际射速不改，停止后恢复idle。光束继续持释放。
5. 原像素羽毛feather-pixel.png无损复制assets/black_goose_feather387，原图来源/提示保留概念目录。原生批量渲染新增默认false的自定义弹体钩子，仅387覆盖；基础羽毛宽.40m，长宽比1044:518，按实际子弹位置/方向绘制，不改变命中/速度/伤害。音符、气球剑、光束保留专属，charged糖弹保留；复制体仍40%，基础羽毛同一渲染规则。不是把特殊武器全换成羽毛。
