# 笔记本与纸星惯性跟随 · 162修订（默认仍world161）

笔记本旧版每帧直接写角色/小黑鹅位置，翻阅时切换锚点会跳动；纸星将屏幕顶点反复取整到2像素网格，会把小幅连续移动变成可见跳格。

新增float_follow162.gd通用临界阻尼跟随器，保存独立位置/速度，使用解析积分，不依赖帧率。超过5米的目标跳变立即归位，清场、隐藏或重新开启重置惯性。视觉以render delta更新，读取角色的插值显示位置；不改变物理、伤害或碰撞。

当前world161的纸张管理器换为paper_float162，保留原152投弹/笔记玩法。旧paper_memories146只抽出update_book_pose146虚方法，旧入口保持原表现。新笔记本增加约0.055米轻浮动、低频摇摆和随移动速度倾斜，翻阅锚点也通过阻尼过渡；Sprite关闭二次物理插值。渲染优先级80，位于相机更新后、地面投影及昼夜染色前。

主角时刻优先级90，聚光锚点平滑跟随，14颗纸星各自持有独立弹簧和不同跟随速度/浮动相位。星形只将相对轮廓对齐像素，平移锚点保持连续，避免整颗星跳格。暂停冻结浮动时间和惯性。地面舞台标记仍对齐角色真实显示位置，避免误读为延迟移动的保护区。投弹弹道、弹药运动、射速、伤害和技能时间均未改变。

验证见float-follow162-validation.json/.log，覆盖30/60/144FPS同一收敛结果、加速/暂停/瞬移、真实笔记本追赶/翻阅过渡/隐藏、纸星独立状态与渲染计时、清场重置。截图hero_moment161_float_follow.png。只运行本次跟随检查，不重跑旧地图或数值套件。
