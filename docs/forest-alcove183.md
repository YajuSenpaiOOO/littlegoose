# 183 环抱低地与岩壁小屋凹窝

入口：工作目录 `preview_forest_alcove183.cmd`，或 `res://scenes/world/world183.tscn`。F8入口样板、F6台阶上口、F7新小屋前、F3小院。保留默认169与180–182独立预览。

按反馈撤销182的南侧开口，沿用180不规则环抱低地；北岸保留Y0.2，森林底Y-2.2，三段短台阶不变。西北增加以(-11,-11)为中心的小屋凹窝，在主空地外增加两侧岩肩与进屋石路，岩面沿用大地图bedrock92体系。世界边界不扩展。

小屋卡片落脚从(-8,-6.85)移到(-11,-9)，实体盒中心(-11,-11)，完整相机朝向billboard继续抑制横移拉伸。新增手绘石基薄棱柱、宽接触影、actor_shadow113实际地形投影。它仍是单张贴图房屋，未实现室内或立体屋顶。

image_gen新增三件透明资源（assets/forest183）：中央蓝绿花叶古树、毛线篮与软幽灵猫手工角、低矮淡紫花蘑菇苔石。树高7.6m替换旧中央橡树；两处手工角有实体碰撞与阴影；花丛可穿行，放在根边与岩脚。彩旗/托举夜灯沿用独立资源。原始prompt随资源保存。

验证：forest183_probe.gd 在Compatibility真实大地图中检查地形高程、岩肩、房屋定位与投影、主要南侧行走位置的相机射线、从入口绕树到小屋往返、三段台阶上行及默认入口隔离；结果见forest183-validation.json。截图在docs/captures/world_restart/forest183_*.png。原四项关键文件哈希隔离结果见forest183-source-isolation.json。

限制：恢复南岸后，贴近前景岩壁仍可能出现遮挡；已验证主要通路，并非整个岩壁边缘都无遮挡。旧外围树的颗粒式淡出仍沿用，待专门优化。正式三鹅门禁、蜘蛛姐姐与森林遭遇未接入；使用独立forest183_preview.cfg。
