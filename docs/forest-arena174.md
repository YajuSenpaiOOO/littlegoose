# 174：独立森林双路线试玩场

2026-10-26。用户要求先试用地形强化现有网垫，而不是增加蜘蛛主动远程控制，并明确要求不影响已搭好的场景。本轮只新增沙盒场景 `scenes/sandbox/forest_arena174.tscn`、174专用脚本和入口 `preview_forest_arena174.cmd`，原场景及project.godot未修改。

## 隔离与布局

174继承173战斗基础，在(320,320)建立单独的DetachedForestArena174节点，距离旧林地超过300米；原地图节点保留原位，没有搬树、改地面或改路。测试区有自己的平地碰撞、障碍和导航网格，不连入正式地图路线。新增地面使用原草地纹理，树叶/蕨草/苔岩复用现有素材，树干/树根使用现有公园木材材质作布局原型。没有宣称完成「很吓人的森林！」正式美术。

有效场地约22×20米，南侧入口留宽敞退让口袋。中央粗树干与根肩分出右侧近路、左侧较宽外圈；右侧苔岩形成局部收窄。左侧(-6,0)与右后方(5.5,-5.8)为无密集障碍的停留/输出空地，供弹弓、小窝、舞台试站位。两条路线都接北侧并可返回，未做必经减速单走廊。路牌仅帮助辨认路线，入口路牌已从主角正前方移到左侧。

树干与苔岩有真实碰撞，可挡直线弹丸；外围灌木仅作装饰，边界碰撞围合试玩区。近镜遮住角色时树干/边树做淡出。中央树干是当前形体代理，不是新的正式树资源。

## 玩法与入口

默认3只蜘蛛，完全沿用173：小跳/搓球/脚下织网/开心两跳，网垫直径4.8米、10秒、最多3块、不可射散、移速降低45%且不叠加；正常闪避、弹反与攻速保留。不增加技能或敌人强度。

F6切单只/三只，F7从入口重开，1—9仍为同组装配。174屏蔽旧地图旅行及F4/F5换区快捷键，避免把测试导航带回旧场景；173等旧入口的快捷键不变。结果页有再演与关闭试玩，不误导为回正式小院。关闭窗口即可退出。

使用独立预览进度路径forest_arena174_preview.cfg，试演场次仍走既有临时保存通路；不发材料、不推进正式事件。原默认play.cmd和project.godot仍指向world169。正式三鹅解锁/森林地图均未接入。
