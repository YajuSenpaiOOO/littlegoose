# 林间小屋13：验证围合、画风与体积层次

启动根目录 `preview_forest_cottage.cmd`，独立场景 `scenes/sandbox/forest_cottage13.tscn`。原 `preview_ground_lab.cmd` 保留为地皮/草实验，正式世界入口没有迁移。

后续14追加：此入口也默认短高混草，M开关混合，7/8/9仍可单独比较。原13贴图、布局与光照保留；以下截图和内容描述记录13初版。

## 内容

- 保留用户认可的D地皮及12版贴地短草；3426个可拨草实例，清除小屋占地、门阶和接近道路上的草。
- 两种新生成树贴图，89棵树构成后方三排交叠林带、两侧树群及少量中近景树。63棵属于可切换的远林；树干有小范围碰撞，树冠可穿过。
- 一栋重新生成的小屋，正面、轻微俯视，保留红瓦、木梁、石基和暖窗。贴图面朝固定25°镜头，无烘焙侧墙，放在平整的0.12米基座上，有屋前支路和门阶空地。
- 地势改成林缘缓丘、道路浅坡及平整屋基，降低12版左右试验坡的幅度，不把所有物体随意放在凸包上。

## 厚重感的处理

这版没有换地皮，没有加全屏风格滤镜。暖向光、较弱环境补光、真实贴图轮廓投影、林冠下柔和变暗及根部/屋基局部暗部共同提供层次。草和地面读取同一个世界空间阴影场，避免只有地面变暗而草依旧发亮。

树与房屋的着色器接受场景光照；人物保留原画法。投影直接来自贴图的透明轮廓，撤掉试验中圆球树冠和方块房子的隐藏投影代理，避免圆影和矩形影暴露简单几何。根部/林下补暗来自512×512预计算遮罩，是固定场景的近似，不是完整实时环境遮蔽。遮罩只在建场和B切换远林时重建，不逐帧更新。

“厚重”仍受物体尺度、前后遮挡、道路边缘与配色影响，不能只依赖调暗或滤镜。这版显示现有地皮可以先继续使用；不是最终美术定稿。

## 操作

WASD移动、Shift快走、滚轮缩放、R起点、F2远看、F3屋前、F1隐藏说明。

| 按键 | 对照 |
|---|---|
| N | 林下/根部暗部及暖冷光照层次，或原实验平光；不移动相机与人物 |
| B | 远处林带开关，同时重建林下补暗遮罩 |
| F | 遮挡人物时的树/房屋淡出 |
| 1—6 | 原六种地皮 |
| 7 / 8 / 9 / 0 | 短草 / 高草 / 圆叶 / 旧11草 |
| T | 缓坡/平地，同时调整草、树、小屋和人物高度 |
| G / K / L | 草 / 风 / 原色受光 |

默认镜头距离15，角度25°、FOV42°，保留滚轮自由缩放。角色主路向前通行，屋前支路可接近门阶；当前房屋是固定视角贴片候选，侧面与绕后内容尚未制作，室内未接入。当前样板不是完整世界地图。

## 资源与验证

资产：`assets/forest13/oak.png`、`young.png`、`cottage.png`。由内置imagegen生成，提示与引用角色记录在 `art/source/forest13-prompts.md`。透明边缘按alpha≥0.5显示；原图不改写，运行时共享三份带mipmap的纹理。`build_forest13_profiles.gd` 按相同alpha阈值测量边界与根部锚点。

实际OpenGL运行 `--path godot_world --script res://scripts/forest_cottage13_probe.gd`，16项通过：原D地皮、25°透视、89树/63远林、树根高度/碰撞、三份透明mipmap纹理、固定朝向小屋、平整屋基、真实轮廓投影、地面草叶共享暗部遮罩、N与B对照、真实主路行走与屋前碰撞、树与小屋遮挡淡出、T同步放平。它验证功能与构图结构，不代表最终画风已获认可或全地图性能已验证。
