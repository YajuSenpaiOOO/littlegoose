# 181 森林入口氛围样板

2026-10-26。用户批准从入口最后一段台阶到第一盏灯/彩旗/布偶做完整样板，并把土路与零星石片延伸到小屋。入口preview_forest_dressing181.cmd，完整大地图scenes/world/world181.tscn。地形沿用180，169普通默认与180对照入口不变。

## 本轮交付

- 删除180两条悬空紫色占位弧带。新彩旗有两端结头、细绳、五片布旗和两根独立木支撑；布偶单独悬挂，整体移到路旁偏里的位置，避免覆盖初始人物脸部。
- 内置image_gen分别生成三张透明原图：assets/forest181/woven_lantern.png、ghost_kitten.png、lavender_bunting.png。完整提示词和参考图路径同目录prompts.json。原图及alpha保留，显示时用0.6 alpha阈值定边；没有用脚本改图像像素。
- 所有原有圆柱灯外观隐藏，保留其真实OmniLight3D照明，替换为淡紫布帽编织罩与木桩贴图，入口样板额外放一盏暖灯。图片提供外观，灯光继续由引擎产生。
- 三段共18级台阶调用现有park99._prism99生成不规则石片，使用同一stone97手绘材质。关闭新增石片自身硬碰撞，沿用180的每段平顺支撑/脚部补偿，保持上下通行。不是另画一套石阶贴图。
- 新增贴地、柔边的踩踏土路，从下降小径延续，沿中央根岛前侧和西侧绕到小屋；复用woodland103/painted_soil103.png。台阶口、转弯和门前共9块薄石片，复用同一手绘石材。不铺满战斗空地。
- 对已缓存草丛姿态做局部路面裁切，减少草穿过石阶口和路面的现象；其余草地保持。

## 组织与操作

world181复制180入口逻辑，仍继承173完整地图；新forest_art181继承forest_art180，只替换本轮摆件与路面。surface180/岩石分割/小屋稳定投影保留。没有改变正式三鹅门禁、遭遇、奖励或原版存档。独立user://forest181_preview.cfg。

启动直接站在低地入口样板前。F8回样板、F6入口上方、F7小屋、F3小院；正常移动/闪避沿用原游戏。新彩旗和布偶是环境装饰，无受击体或阻挡。

## 验证

forest181_probe.gd的17项检查在Compatibility实机通过：三张透明资源、长占位条消失、真实暖光、台阶共用材质/无新增硬坎、土路与薄石片、小屋投影，以及主角真实走完样板到小屋并返回、沿台阶上行回小院、下行回样板。报告forest181-validation.json，日志forest181-visual.log。

实机查看后发现初始彩旗盖住脸部，随后只调整路旁摆件位置（无新增碰撞或地形修改）；最终截图由forest181_capture.gd单独核对，文件docs/captures/world_restart/forest181_sample_final.png。其余截图forest181_sample.png为调整前；forest181_cottage_trail.png、stairs.png、sample_return.png作路径记录。未重复旧地图/战斗全套。

本轮仍是局部美术样板：木支撑采用原手绘木材的简单几何，布偶/彩旗还没有风摆动画；尚未把所有树旁都布置满。原树冠颗粒式淡出仍沿用180，后续可单独改观感。
