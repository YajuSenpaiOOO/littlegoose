# 187 连续道路、贴地拆层与像素采样对照

入口preview_forest_ground187.cmd / scenes/world/world187.tscn，独立forest187_preview.cfg。F8样板/F6入口/F7小屋/F3小院，F9阴影/F10森林光色。地形仍为183，尚未整体迁移。

## 道路

186的道路按每段独立正交方向生成截面，转角两端边缘不相接，产生三角缺口。187将入口PATH和屋前TRAIL合成一条折线，计算共用的角平分线截面和有限长度的miter连接，再按0.3m细分铺面；跨段UV距离连续。检查每个相邻段的左右边缘端点一致，并实际行走入口到小屋。

## 接地试验

原卡片的根、屋基带有绘制出的地面透视，整体按竖立billboard显示时，只有最底一个锚点贴地，其余脚边仍可能离地。187将树下部9%、房屋下部12%拆为独立地表网格，上部仍为billboard；地表按25度相机的投影比例展开，采样真实地形，拒绝爬上岩壁的网格，交界带用透明重叠。贴图原始像素不修改。

这是接地拆层的试验方案，尚非完成的立体资产。根部和屋基拼接、透视仍须根据实机反馈继续校准，不能用“创建两层网格”作为视觉已经解决的证明。主景树淡出改为实际画面上的alpha遮挡测试，避免空白包围盒触发整树消失。独立灯笼挂点适配裁切后的树卡；轮廓投影适配AtlasTexture区域。

## 摆件

小摆件使用统一约0.016米的逻辑像素采样和20级通道量化，以便和主角对照；该步骤是运行时渲染，不是重新绘制像素美术。若轮廓、色块仍不合适，应重画源资源，不能仅靠降采样当作最终画风统一。

## 林地距离：待做迁移

当前团团林地中心约(-49.99,-45.66)，森林中心(-48,0)，中心距约45.7米。但团团侧林缘延伸到z约-25，森林北侧约-15到-17，实际缓冲仅约8–10米。玩家很快走到，镜头也能看见明亮林地。

建议森林中心向南移20–25米（可先用z24），入口上口保留，延长转折下行小径；北面增加连续远层林冠与岩肩挡景，保持团团区原来的明亮基调。当前地图南边界约z18.38，迁移会越界，必须做仅向南的局部扩展，保留原网格原点与旧地形、旧场景，再验证寻路/阴影高度场/边界。187未擅自修改边界、未迁移地图。
