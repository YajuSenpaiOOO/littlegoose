# 190 森林与夜间受光修正

2026-10-27，基于189，独立 `user://forest190_preview.cfg`。统一启动菜单的最新预览指向190，普通主版本169保持。

## 根因与处理

- 旧主角跟随补光灯实际上已经关闭；异常主要来自屏幕滤镜的角色椭圆提亮、聚光灯空气叠色，以及按像素暖色判断的保光。这会保护皮肤、毛发轮廓和玩偶暗部中的暖色。190关闭两处角色豁免和屏幕灯锥叠色，保留原生舞台聚光灯。
- 主角改为标准 Sprite3D 受光，使用原生图集材质，无 emission。卡片向上倾25度以接收顶部灯光，取消旧角色舞台色增益，并给白发保留亮部余量；受伤颜色仍乘算保留。
- 森林保光改用逐帧投影的灯芯与窗户位置、半径和深度，最多20个。不会按暖色把整只玩偶当灯泡。树挂灯按实际贴图灯芯位置登记。
- 原灯光图集南边界在 z=18.38333，森林南移后仍越过这个边界。190在6米宽范围将图集alpha平滑退到0，地面着色与CPU角色采样采用相同过渡，消除硬切。
- 夜间森林滤镜不再与大地图夜色全量叠黑。暖光池仅恢复部分原色，不往阴影里加亮色。

## 验证与范围

`scripts/world/forest190_capture.gd` 在 Compatibility 下运行：原生受光、两处屏幕角色豁免移除、旧跟随灯关闭、原生聚光灯保留、明确光源登记、旧图集边界连续性、189花草与吊床保留，共9项。截图覆盖小屋早晨/傍晚/夜晚、中央白天/夜晚、小院夜晚，见 `docs/captures/world_restart/forest190_*.png`；结果在 `forest190-validation.json`，日志在 `forest190-visual.log`。

这是光照修订预览，不重画树屋，不改地形、摆件、战斗和正式解锁。树屋贴图原有的绘制明暗以及透明材质与后处理的差异仍存在；不能据检查通过宣称整个场景已经达到设计图最终光感。此前诊断与开关对照见 `forest189-light-diagnosis.md`。
