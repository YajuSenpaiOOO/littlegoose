# 191 窗前暖光与林间小舞台

2026-10-27，基于190，独立 `user://forest191_preview.cfg`；主版本169不变。

## 本版行为

- 新的 `forest_lighting191.gd` 统一管理森林路灯、树挂灯、三个窗户与门廊的真实 OmniLight。灯位置由当前贴图灯芯/窗户坐标转换得到。旧181/184灯节点关闭，避免重复叠灯与188亮度上限继续生效。
- 路灯0.9/5.2米，挂灯0.75/5米，窗户0.6/5.8米，门廊0.8/5.5米。灯色统一琥珀暖色。灯罩仍保留手绘明暗，不让近距离自身照明把灯芯周围漂白；布偶、手工角、花草、中央树及树根接真实受光。主角保留190的原生图集受光材质。
- 屋体、中央树干、路灯柱、旗架、手工角增加简化的原生投影遮挡体，专属第二层，仅投影不可见。最近3盏地方灯和舞台灯开启阴影，`shadow_caster_mask=2`；其余灯照明正常。排除地形自投影，避免低角度贴地网格阴影条纹。树干卡片不接代理体自身阴影，主角保留原有接触/轮廓影，避免简化体把衣服遮黑。不能据此称所有贴图已拥有精确三维投影。
- 屋体贴图仍保留暖色自亮的绘画处理，本版补的是照向外界的窗口/门廊光。森林其他旧树和大地图旧物件不在这次材质迁移范围。
- `forest_mood191.gd` 在190调色中加入真实灯位和世界坐标舞台范围的调色减弱；其作用是保留原生灯已经照亮的颜色，不在屏幕上给角色画提亮椭圆。光照叠加由原生灯完成。范围调色减弱是美术近似，不是二次可见性求解。
- 森林舞台按核心区域与长小径进度渐入，白天森林内强度0.68，外界白天关闭，17:30—20:00渐亮、清晨渐退。完整强度的原生SpotLight能量1.25，24度、9米，顶部偏前照向主角，形成约4米柔边光池。极淡的深度检测空气光束仅作空气感；无主角自发光、无跟随点光、无旧角色屏幕豁免。
- 两级平滑用于区域及舞台灯切换，瞬间传送后应等约3秒再检查完全退出；正常走路沿小径渐变。

## 入口与验证

统一 `00_开始游戏.cmd` 最新预览191。F7小屋、F8样板、F6入口、F3小院、F11长小径中段；F10调色对照，F12新增灯光整体开关。旧190场景保留，可在Godot中直接打开。当前主版本169未迁移本版灯光。

`scripts/world/forest191_capture.gd` 用Compatibility实机验证：原生灯/遮挡体登记、关闭舞台灯后仅窗前灯让主角实际像素变亮且偏暖、森林白天舞台灯、小院白天退出与夜晚恢复、只给最近3盏地方灯投影、自身跟随补光保持关闭。截图覆盖窗前开/关、入口路灯、森林白天舞台、小院昼夜。结果 `forest191-validation.json`；截图 `docs/captures/world_restart/forest191_*.png`；日志 `forest191-visual.log`。

初版曾出现过曝及地面阴影条纹，已降低灯能量、排除灯罩自身受光并限制专属遮挡层。最终视觉仍为样板，需用户移动试玩评价暖光范围和舞台强弱，不能以检查通过代替美术验收。
