# 193：昼夜演员、系绳吊床、林间暖光

2026-10-27，继承192。统一启动菜单最新预览193，独立 `forest193_preview.cfg`；普通主版本169不变。

## 敌人的昼夜调色

气球剑159使用 `world_effect_grade159.gdshaderinc`，读取 `combat_world_tint159`；团团怪/纸怪沿用的软体shader没有接入这条路径。193新增 `enemy_grade193.gd`，仅在当前预览运行时包装敌人独有的ShaderMaterial，不修改共享32/123/124资源文件。

控制器使用同一159颜色来源，覆盖world.enemies和roamers122，包含普通、翻滚和尸体渐退的shader切换。包装shader按源资源缓存，逐帧跟随原动画切换，不重复编译；切换时保留原有art/tint/dent/roll等参数。只乘RGB，不改alpha或UV。为避免浅色角色在夜间变成饱和蓝，演员专用蓝色上限为max(R,G)×1.25，不改变159弹幕的调色。

本项是环境颜色接入，不是把敌人的软体材质替换为主角192的原生受光材质；敌人暂未增加地方灯/树影接收。受击提示、变形、AI、伤害与掉落保持原逻辑。

## 吊床

沿用现有两层紫布与猫猫贴图，增加两条分段实体绳：树干/横枝原画绑点固定，小吊床结点随猫猫轻摆。每条6段，半径0.019米、6边圆柱，使用普通粗糙绳色材质，接收灯光、不投阴影。两端从贴图不透明范围坐标转换到世界坐标，跟随现有固定相机基向量；不是把浮空的小床整体再次放大。

这次没有重画大树或吊床，也没有新增碰撞；绳子是装饰。若未来旋转相机，需要一并更新树上吊点投影方式。

## 暖光范围与舞台

- 沿用192现有灯具数量，范围扩大1.35倍（路灯约7米、挂灯6.75米、窗户7.83米），衰减从1.4改为1.05。地方灯能量不加，以扩大低亮度区域而非提高灯旁峰值。
- 舞台灯更靠前：(-0.45,5,2.2)，朝主角上方0.7米处照射，25度，衰减1.3；色ffc584、能量系数1.65，沿用森林白天0.68/外界夜晚1.0及平滑进出规则。
- 已登记灯光范围减弱夜间冷色覆盖，灯下仍蓝时做保亮度的暖色校正（颜色比1.24/1/0.76，前后保持亮度）。不按像素颜色猜光源，不加亮屏幕角色椭圆，不改变主角几何。实际光暗和遮挡仍由原生灯/阴影决定。
- 主角继续使用192标准材质常量法线，保持169身形、贴图与脚锚点。
