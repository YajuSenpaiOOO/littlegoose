# 186 森林区域光色与轮廓投影

入口：preview_forest_mood186.cmd / res://scenes/world/world186.tscn。F8样板、F6上入口、F7小屋、F3小院；F9阴影对照，F10森林光色对照。Ctrl+Alt组合键继续交给原地图功能。独立forest186_preview.cfg；默认169及185保留。

## 投影与接地

撤掉184/185的球形树冠、轴对齐房屋墙/屋顶投影体，彻底清空native_casters184，避免黑椭圆与正面方屋影。隐藏CottagePlinth184、CottageFoundation183、RootStoneIsland184，不再增加可见石板。

大树与小屋使用forest_projection186：读取实际贴图alpha，按Sprite3D渲染使用的相机平面基向量还原卡片顶点，再沿太阳方向投射到实际地形；16×16细分、三次地形迭代、少量alpha柔化与较低透明度。阴影更新随太阳/卡片姿态变化，限制重建频率。该方案是贴图轮廓的地面投影，仍非完整3D房屋体积重建。

房屋接触影按贴图左墙与前门廊三点，通过相机射线落到地面，构成窄柔边条带；撤掉重叠的大椭圆接触影。树根只保留单层轻接触影。小摆件沿用既有投影与实体碰撞。

## 光色

forest_mood186扩展当前已有的景深/昼夜后处理Shader，保留原参数和逻辑，不修改全地图昼夜系统。深度重建世界位置后，只对西南森林、凹窝和入口路径着色；主角沿三段台阶深入时区域强度渐增，进出用指数平滑。

- 外围、树冠与后景压低黄绿色，偏深蓝绿；暗部加少量灰紫与最低亮度保护。
- 中央通行区域减弱压暗，沿用已有主角局部可读性保护。
- 亮琥珀灯火保色；最多12个现有暖灯的位置提供小范围暖色保护与轻补色。
- 后景少量冷紫空气层次；没有用大量摆件或不透明雾遮盖通路。
- 新森林旧边缘树的forest_cutout17颗粒淡出换为forest_cutout186柔和alpha淡出；舞台树也使用连续透明，减少暗色调放大的颗粒。

## 验证与限制

forest186_probe在Compatibility完整地图中通过15项检查：移除旧投影体与石板、入口光色权重单调增加、实际入口绕树到屋前往返、区域Shader接入、同机位光色开关图像对比、回到小院清除光色、默认169保持。最终柔和淡出另做视觉复核，报告forest186-final-visual.json。所有截图在docs/captures/world_restart/forest186_*，包含plain/mood、shadow_off/on、stairs_transition和home。

小屋与树仍为2.5D贴图；斜视小屋底部透视与太阳投影是近似，需继续根据实际镜头反馈调整。土路视觉层略抬高、薄石片同步抬高，通行碰撞不变；道路仍能看到局部三角状边缘，尚未完全定位，不能当作已修复事项。未新增美术资源、正式三鹅解锁、森林遭遇或蜘蛛姐姐事件，地形与通行碰撞沿用183。最终3项光色/返院视觉检查通过，阴影对照中树根区域可见轻暗部变化，截图已人工检查。
