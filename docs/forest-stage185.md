# 185 紫布舞台树与接地

入口preview_forest_stage185.cmd / res://scenes/world/world185.tscn。F8入口样板、F6台阶、F7小屋、F3小院、F9新摆件阴影开关对比。独立forest185_preview.cfg；默认169保留。

用户认为183树过于写实、密集、偏小，184中途图又过圆且根部包球石令人不适。因此185使用新image_gen透明树：不对称分叉、横向错落叶簇、自然伸入土壤的根，不包石；一段淡紫布形成小舞台主题。高11m。旧整圈石盘隐藏，两个薄岩碎片独立摆放，未新增阻路碰撞。

独立灯笼来自assets/forest184/hanging_lantern.png，两盏按新树紫布两端的贴图挂点，通过相机平面基向量精确定位；对应OmniLight跟随。树资源与完整prompt在assets/forest185，灯笼prompt在assets/forest184。

接地方案来自184：房屋墙/屋顶与树干/树冠配置只投影、不显示表面的简化立体形状，投在真实地形上；静态贴图辅助轮廓投影改用CPU路径；接触影使用随地形网格及更宽的暗部曲线；小屋底部增加薄石基。可见表面仍为单张相机朝向贴图，未变为完整3D模型。

排查纠正：过程中曾推测CPU可见范围用了世界坐标，进一步查看与实测证实原代码已正确转换为局部坐标，这一推测及额外坐标转换均已撤销。这里不将其作为已修复的根因；最终改善依靠原生立体投影、接触暗部与石基。原actor_shadow105/113未改。

验证：forest185_probe.gd包含实际绕树往返小屋、三段台阶上行、南岸主通路射线、取消石盘及新主景尺寸；同时保存房屋/中央阴影开关截图，并检测暗像素差异。像素差异不是单独的效果证明，最终截图还需人工核对。报告forest185-validation.json；截图docs/captures/world_restart/forest185_*。184此前23项通行/投影检查与4项最终截图检查通过，报告单独保留。

限制：外围旧树仍用颗粒淡出，近前景岩岸仍可能遮挡；正式三鹅解锁、蜘蛛姐姐与森林遭遇未接入。

185最终近景4项对照通过（forest185-final-visual.json），房屋底边下移0.18m后单独复核；投影体轮廓仍为近似，非贴图全轮廓的精确立体重建。
