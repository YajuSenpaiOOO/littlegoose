# 森林成套风格14与短高混草

入口：根目录 `preview_forest_styles.cmd`，场景 `scenes/sandbox/forest_styles14.tscn`。这是13版布局上的成套美术对照，不更改正式世界入口。旧13入口也已默认开启短高混草。

## 四套画法

| 按键 | 风格 | 关注点 |
|---|---|---|
| 1 | 原13卡通绘本 | 保留作原版基准 |
| 2 | A 轻像素绘本 | 较克制的像素笔触、较自然的树冠，细节变化较轻 |
| 3 | B 细节手绘材质 | 更多树皮、石材与瓦片细节，保留绘制感 |
| 4 | C 自然像素质感 | 更自然的材质与叶群，保留像素簇、阶梯边缘 |

Tab切到下一套。每套同时替换地皮、宽树冠树、瘦高树和小屋；所有物体位置、角色、相机、光照、地形、碰撞、混草高低标记保持一致。草根跟随当前套地皮底色；轮廓投影随树和房屋的贴图自然改变。图像生成并不能保证只改变细节，树冠形状和材质配色仍有小幅差异，不能把这组比较解释为严格的单变量实验。

三套新素材共9张：每套一张地皮、一张含两棵独立树的透明图集、一张透明小屋。存放在 `assets/forest14/{a,b,c}_{ground,trees,cottage}.png`。生成模式为内置imagegen，提示与引用角色见 `art/source/forest14-prompts.md`。保留绿色连续地面，无意加入裸土斑；更丰富的细节主要放在树与建筑的材质上。未通过后处理滤镜伪造新风格。

## 混合草

原13及新14默认以短草铺底，混入少量高草，林缘高草概率更高，屋前与支路保留空地。使用3426个现有实例，固定标记决定短/高；没有额外叠一批草，也不会在切换风格时重新撒点。高草和短草共享弯叶轮廓几何，着色器沿地表法线调整生长高度；不是同时启用两套独立碰撞或逐株脚本。

M开关短高混合；7/8/9切到独立短草/高草/圆叶，切单一草种时自动退出混草。原有拨动、脚步轨迹回弹、风摆和片区高低变化保留。房屋与道路占地仍不生草。

WASD/Shift移动，滚轮缩放，F2远看，F3屋前，R复位，B远林，N光影，F遮挡淡出，T缓坡/平地，G草，K风，F1隐藏说明。新14的1—4用于整套风格，不再单独换旧地皮；旧地皮实验仍在原草地入口。

房屋继续使用固定25°视角的正面贴片，侧面、绕后与室内仍未制作。完整地图、最终光照及全地图性能不在此次对照范围。

## 验证与素材边缘

运行 `--path godot_world --script res://scripts/forest_styles14_probe.gd`，13项实际OpenGL渲染检查通过：四套资源完整加载；整套切换保持人物/相机/树根/草/小屋/光照；地皮与草根颜色同时换；两种树及小屋同步换；透明边界/mipmap；混草标记保持；M与单草种可逆切换；三套新风格均在实际画面上产生变化；切回原版恢复逐像素一致的冻结视图；混草拨动与无残留恢复。

3426个实例中1036个高草标记，约30.2%。实际拨动局部改变1538个像素，恢复残留0。冻结视图中三套相对原版分别改变1055675、1057340、1057407个像素，这些计数验证显示切换，不评价美术好坏。

树图集实际间隔未必等于半幅，因此离线按透明间隙分出两棵树；运行时加4像素透明边界后生成独立mipmap，防止串入另一棵树。C树经imagegen补足左侧树冠与画布留白。B源图有半透明光晕，候选材质用0.9 alpha阈值拒绝它；A/C及原版仍为0.5。B的细边缘、远处叶片稳定性仍需走动观察，不把功能检查视作所有闪烁已解决。原PNG保留透明信息，不由代码改写。

同镜头实机截图：`docs/captures/world_restart/forest14_0.png`（原卡通）、`forest14_1.png`（A）、`forest14_2.png`（B）、`forest14_3.png`（C）。地皮细节差异刻意较轻，树和屋的材质变化更明显。
