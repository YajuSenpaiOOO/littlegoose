# 70 石阶林地：有厚度的可玩地形样段

2026-10-19。用户参考最初设计图要求大石、明确高差、楼梯、石墙，否定69缓台加环形小径的方向。本轮重做西林地，车站仍保留69功能高差草稿。

## 空间

中央战斗平台标高2.65m，下层林路约0.14m。平台是不规则九边轮廓，正面14级石阶接下层，东侧缓坡通回下层小径。删去69围空地一圈的土路与回程路线，入口改为平台脚下接石阶。正面残留石砌挡墙、自然岩壁和七块主岩体明确显示厚度，中央留移动/闪避空间。林缘保留树木，石阶入口留视线通道。

普通入口从石阶下正午预览开始。7回石阶下、8到东侧坡口、3到战斗平台，5仍到车站；Alt+1/2/3/4预览时段，Alt+0恢复自然时间。入口play.cmd/preview_world_garden.cmd不变，标题“石阶林地70”。

## 实现与复用

world_surface70统一提供真实高差、地面碰撞、摆件高度、角色影子与道路定义。战斗平台边缘陡变处使用岩壁遮面；非通路边界另有静态障碍，避免玩家或敌人直接穿过崖面。正面石阶采用视觉台阶加平顺地面坡面，视觉单步约0.18m；台阶不另设逐级碰撞，减少快速移动卡顿。

forest_terrace70将岩面/巨石、石墙/楼梯、苔藓分别合并为静态网格。岩石用有侧面与顶面的不规则立体轮廓，复用garden45/slate.png，以世界坐标三向投射材质；接入现有林间/日夜光照材质系统。不是放大的正面石头立牌，不新增实时阴影灯，也没有每帧重建岩体。楼梯、大石、崖边障碍在物理服务器就绪后重新烘焙原敌人导航网格。

模块入口为outline70、LEVEL70、stair70/side70对应开口及forest_terrace70的岩体布置；后续石墙、阶梯、崖面可移到车站和湖岸复用。当前材质与轮廓用于构图/玩法验证，尚未制作最终手绘岩壁资产。小屋、银柳环岛、车站、桥水的已有标高不改。

Compatibility、原25度镜头、景深、69局部灯影、67整树隐去与帧率面板、40战斗基线保留。主角与史莱姆姐妹眨眼继续暂缓。繁忙战斗55FPS反馈未宣布解决。
