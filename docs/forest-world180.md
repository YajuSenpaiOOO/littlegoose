# 180 大地图接入：弧形下沉森林与稳定小屋贴图

2026-10-26。用户要求把森林接进大地图，解决侧向小屋左右移动时的拉伸，场地改为设计图式的弧度、内收和层次，岩石断面参考原大地图。

入口：preview_forest_world180.cmd，完整场景scenes/world/world180.tscn。继承173（含169完整大地图与既有战斗/装配），不再使用177—179的独立地形平面。普通play.cmd仍保留169作对照。此版实际修改新world_surface180生成的整张地面网格及其碰撞，并在小院西南世界坐标添加森林布景；不是把小试场浮在原地面上。

## 场地

forest_plan180的轮廓由几个不等半径的椭圆凹湾相连，减去西侧岩肩和北侧突出肩部，替换方形边界。小屋处有后凹湾，入口较宽，西侧收窄，中央根岛仍保留两路绕行。北侧仍Y0.2，森林最低Y-2.2；入口沿用三段各6级短台阶和中间落脚段。物理支撑在每段短阶梯内部平顺，脚部补偿对应13厘米视觉踏面；不是整体长坡。

world_surface180只在森林及入口附近覆盖旧高度，局部加密网格；原小院、团团空地、车站、山顶数学高度保持。新入口清理仅限版本180的新通路和低地区，晚期补种树隐藏并关闭自身碰撞以保留旧光照服务引用。原岩石若位于凹地则隐藏，防止悬空。旧版源文件和入口不被改写。

小院附近原有饼干罐、树桩锅和矮石边，因此接入段按其真实碰撞空隙计算一条局部路线，并沿路摆少量可见小石子；不搬动原摆件。实际测试路线大致从小屋前(-4.7,-2.6)，绕到z约-1.5的摆件空隙，再往西接(-15,-3)森林入口。进森林之后仍是此前的弯折小径与下降台阶。

## 大地图岩石断面

rock_surfaces180继承rock_surfaces142：沿用既有几何分面/草顶分割、bedrock92.gdshader、assets/stone92/painted_bedrock92.png与草缘。只扩展新森林区域的岩面判定（不能继续沿用旧区域“海拔>2.24米”的限制，否则下沉岩壁不会显露）。原断面逻辑保持。森林地面做局部冷色处理，不改变全地图昼夜。

## 小屋拉伸

179的整张图竖直摆在世界里，透视相机向下25°看它时，图内的侧向透视叠加了卡片的透视，左右移镜容易显得剪切。180保留已生成的右向/带俯视的小屋图，Sprite3D改为BILLBOARD_ENABLED，使画面平面与相机画面平行，图内透视整体保持。没有直接换成正面图，也没有改成可旋转的立体房屋。

保留透视远近带来的整体大小变化；这和图片自身被剪切不是一回事。当前仍是一张固定视角建筑卡，屋顶、门廊未拆层；室内/开门/姐姐形象未做。碰撞仍简单盒体，屋后整张淡出。正式多方向绕屋观察时应使用分面/立体房屋，不能把本版当成全视角建筑。

树卡的遮挡淡出必须向forest_cutout17材质传入fade参数，单改GeometryInstance.transparency不足以控制该自定义shader；本版同步设置二者。灰盒根块仅保留碰撞，隐藏简单圆柱视觉。

## 操作与范围

从小院前开始，沿小石子向西走。非战斗时F6到森林入口、F7到小屋前；F3沿用原回院。原地图探索、纸怪/团团试演与装配入口保留。新森林尚未接正式三鹅门禁、怪物遭遇、材料或姐姐事件。使用独立user://forest180_preview.cfg，不写回169存档。

## 验证

forest180_probe.gd最终23项检查在Compatibility实机全部通过。在完整地图中驱动真实主角行走：小院接入/三段台阶/两侧路线/小屋/沿台阶回小院，核对旧区域高度、旧地图节点、原手绘岩石材质、下沉支撑、三个镜头位置的画面平面投影，以及树shader实际淡出。结果以forest180-validation.json和forest180-visual.log为准，截图docs/captures/world_restart/forest180_{home,entry,clearing,house_center,house_left,house_right}.png。树卡目前沿用forest_cutout17的颗粒式淡出，可见噪点；后续可专门调整遮挡视觉，不能把当前颗粒感当成最终美术。

forest180-source-isolation.json确认project.godot、world169.tscn、woodland_world173.gd与forest_props87.gd的既有SHA256保持。没有重跑全部旧战斗组合或全地图所有路径。初次新地形和旧版本链的缓存准备较慢，实测缓存启动仍可能约一分钟，需等待进入地图，不要误认卡死。

后续优先体验：接入路线、弧形岩岸宽窄、下沉空间、左右移动小屋的稳定感。主题主景树、布偶、正式灯具/紫带仍后续细化。
