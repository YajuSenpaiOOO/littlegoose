# 鹅队开火车 / 住校团聚 · 168

按用户确认先试统一模型：每只额外鹅40%本体伤害，保留原射速、射程和弹幕形态，本体无属性惩罚。森林冰火人+1只/1格，三人小游戏+2只/2格，新增住校+3只/3格。理论直射总量1.4/1.8/2.2倍。卡可叠加，四格内最多额外4只（住校+森林冰火人）。这只是试玩起点，实际命中收益另评估。

## 队形

火车沿原始小黑鹅的实际世界路径按弧长采样，每只相隔0.72米，转弯跟着前方走过的路线，不再用左右阵型偏移。保存约8米路径、最多256采样；停步后在各自队列位置收稳。新跟随器保留小幅惯性、原扑翅及射击姿态。

装备住校后切成主鹅附近0.39—0.49米的小团聚队形，仍平滑跟随。暂停冻结；瞬移超过5米重建路径并立即带走队伍。原杯电话接触能力保留，但复制鹅接触伤害同样40%。额外鹅没有新增碰撞/HP规则。

鹅节点和地形投影按最大需要数量建池，换组合只隐藏/复用，不反复增加投影。射击只使用当前激活的鹅，隐藏鹅不会参加输出。

## 伤害和旧惩罚

在新168 buff book中增加同步数学作用域，进行伤害、冷却、载荷快照及光束节拍计算时，屏蔽旧森林冰火人×0.6伤害和三人小游戏×0.5射速。真实装备等级保留，数量、槽位、UI正常读取；嵌套计算结束立即恢复作用域。没有覆盖、清空或伪造玩家持有等级。

普通/蓄力弹记录鹅来源和伤害比例；光束按原发射lane识别来源。飞机和课堂笔记保存已经折算的伤害与来源，延迟发射、分裂、剑载荷不二次乘40%。飞机仍沿既有“一架飞机携带当前一轮所有弹道载荷”管线，不在本轮改为每鹅独立飞机。

分裂伤害自然继承40%预算；气球剑减速层等控制效果暂沿现有规则，没有声称所有附带效果已平衡。多鹅加快控制叠层属于后续试玩要单独评估的收益，不能只看理论DPS。
