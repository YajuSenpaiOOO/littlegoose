# 草地对照 11：去掉土斑，减少贴图细节

入口：根目录 `preview_ground_lab.cmd`。独立样板，不更改正式世界的入口。

| 按键 | 地皮 |
|---|---|
| 1—3 | 原三版地皮，保留用于比较 |
| 4 | D，柔和绘本，绿色连续底纹，无裸土斑 |
| 5 | E，简洁卡通，大块绿色色差，无裸土斑 |
| 6 | F，纯色底，主要由立体草补充细节 |

默认开启新草。J 切换旧透明贴片/新实体草叶，G 开关草，K 开关风，L 原色/受光，C 镜头跟随，滚轮缩放，WASD 移动，Shift 快走，R 复位，F1 隐藏文字。各版保留中央连续道路作为尺度参照；“去土斑”指草地内部，不是移除整条道路。新地皮不覆盖旧素材。两张新图采用内置 imagegen 生成，原图保留，提示在 `art/source/ground-lab11-prompts.md`；F 为原生着色器纯色。

## 草的修改与原因

旧草是含细小透明轮廓的交叉片，缩小、风摆、镜头移动时有轮廓采样和透明遮挡变化的风险；它的叶形和图像内部细节也偏离人物画法。之前仅调整透明边缘未解决用户看到的问题。

新草用五片分开的弯曲叶片组成实际轮廓，单实例 25 三角形，不采样草图片、不使用透明混合或 alpha 裁切。3600 个实例共享几何，合计 9 万三角形；未增加逐株脚本和碰撞，保留批量拨草、轨迹回弹和远处整体缩减。场景使用 4x MSAA。基础/叶尖采用接近地面的柔和配色，避免白亮尖叶像独立摆件。这里只是草形态候选，仍有重复、尖叶和均匀撒布感，不是最终植被美术。

1—3 的地皮保持原样；默认草已换新。若要恢复旧版组合，按对应数字后按 J。新4借用旧2草贴片、新5/6借用旧3草贴片，仅用于 J 的几何方案对照，不能当作已制作的新风格草图片。

## 验证

`Godot ... --path godot_world --script res://scripts/ground_lab_probe.gd` 使用真实 OpenGL 渲染运行 19 项检查：人物落地与实际穿草移动、25°透视、六版切换保持相机/人物/光照/种植位置、纯色方案、旧草切回、新草不含透明采样、六版 GPU 接触变形及回到逐像素一致的静止画面。无新房树混搭。

慢速镜头平移诊断：关闭风和人物移动、隐藏地面，9 帧同一局部截图，每帧相机横移 0.006 世界单位，记录 RGB 时间二阶差分，最终配色下旧透明草片为 0.140149，新实体草叶为 0.027573。该值仅衡量这段局部画面跳变；旧草与新草的轮廓和颜色不同，不能据此宣称整个游戏闪烁已完全解决。静止稳定、拨动及恢复检查与主观移动观察是不同结论。六版接触区域分别有 977、965、967、965、967、970 个像素改变，恢复残留均为 0。

效果截图：`docs/captures/world_restart/ground11_d.png`、`ground11_e.png`、`ground11_f.png`，均为同一近景镜头。宽阔空地是控制变量的材料试验，不是最终世界布局；地皮的重复、道路边缘与光照层次仍待后续处理。
