# 197 主角相机平面对照

2026-10-27，用户明确授权试用主角朝向相机，与之前为受光而临时旋转190不同，本次是独立的形体展示试验。

hero197继承192，render_pose先完成原有动画和图集，再将实际相机的正交基变换到显示卡片父节点空间，乘以原平面内侧摆和动画缩放。不是开启全billboard覆盖动画；没有改CharacterBody3D、物理碰撞、速度、受击体、角色原图、pixel_size或贴图脚点。显示原点保持，原有上下起伏也保留。

相机朝向时关闭192的额外常量法线倾角，避免几何倾角与材质重复。切回竖直时恢复该法线。原生材质继续绑定图集原始sheet；角色轮廓投影113读取visual_world113，会随真实显示变换更新；残影继承显示transform。树影接收仍是平面上的真实遮挡，不是角色体积模型。

world197继承196，保留近景预清场。默认将196的路灯/站台竖直实验恢复原朝向，便于与主角一起比较；F2仍可切换。F1主角相机朝向/192竖直，F6入口、F7小屋、F8样板、F9吊床、F3小院，F10调色、F11长小径、F12灯光。独立forest197_preview.cfg，169/192/196源文件不改，统一入口最新197。
