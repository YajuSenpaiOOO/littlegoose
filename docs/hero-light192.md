# 192：恢复169身形，独立调整材质受光

2026-10-27。用户明确选择：恢复169的身形，保留真实灯光和树影接收，通过材质单独调整顶部受光。

## 根因与不变量

190的 `hero190.render_pose()` 把整张卡片转了X=-25度，169则是X=0。相机同为-25度，贴图尺寸、pixel_size和scale均一致，但实机投影单位Y/X比从0.91015444变成约1.0，造成约9.9%的相对拉长。审计见 `lighting191-audit.json`，169资源引用扫描见 `lighting191-dependency-audit.json`。

192不再继承hero190，而是继承hero188。沿用169的竖直几何、脚锚点、动画缩放/侧摆、相机角度和全部原有贴图；不要为灯光再转动角色几何。新增材质仅调整受光，不修改角色图片文件。

## 实现

- `hero192.gd` 使用原生StandardMaterial3D：不透明裁切、最近邻mipmap、顶点调色、无金属高光/自发光。2×2常量切线空间法线贴图让受光法线朝上25度，不移动顶点。法线绿色方向在Compatibility实测确认，不能仅凭约定猜测。
- 每次姿态更新后，材质绑定AtlasTexture的原始图集；UV仍由Sprite3D产生，不再次裁切。走路、转向、闪避沿用原生图集定位，避免此前自定义shader的帧采样问题。
- 标准材质接收真实灯光和阴影。法线小样中同一竖直角色的顶部照明响应由0.03122增至0.05103，加入仅投影遮挡体后降至0.01622；无角色旋转、无屏幕角色提亮。
- `forest_lighting192.gd` 继承191，地方灯统一减半，舞台改为琥珀色 `ffd39b`，强度系数1.2；空气光束降至0.015。`forest_mood192.gd` 降低灯下调色豁免，避免把原生叠灯的过亮区域直接恢复成原始高亮。
- 191只增加灯光脚本工厂，默认仍返回191脚本，行为不变；192独立覆写工厂/主角/调色。默认主版本仍169，192独立存档 `forest192_preview.cfg`。192内的小院等旧区域采用新主角受光，这是该预览的全局角色变化；不将其等同于169被修改。

## 验证

1. `material192_probe.gd`：四朝向原生图集显示，截图 `material192_atlas.png`。
2. `normal192_probe.gd`：顶部受光与遮挡体阴影接收实测；结果 `normal192-validation.json`，三组 `normal192_*.png`。
3. `forest192_capture.gd`：投影比例与169一致、标准材质法线、窗前正午/夜间多灯重叠的头部任一通道截断比例、实际地方灯/舞台灯像素响应、三向行走图集与闪避几何、琥珀色和真实阴影开关。结果 `forest192-validation.json`，日志 `forest192-visual.log`，截图 `forest192_*.png`。

头部取样测试约束指定镜头下任一通道>0.99的像素比例低于6%，不代表对所有位置/姿态的过曝保证，必须与实机截图共同判断。标准材质的常量法线不提供真实脸部体积；阴影仍落在平面角色上。树屋原画亮度、透明材质后处理差异与简化摆件投影沿用191，未在本次全面重做。
