# 正式画风以主角为基准

**05 最新决定已取代本页早期目标。** 用户认可旧版细节地皮，允许人物与环境画法不同并强化“立牌人物站在环境中”的表现。环境不再要求简化为主角同款卡通；以共同视角、尺度、脚点、遮挡、接触影与明暗关系协调。见 direction-and-view-05.md、asset-view-contract.md。下文保留为 02–04 的历史探索。

2026-10-16，依据用户本轮要求。布局草稿的免费树、生成地皮、现有建筑属于占位资源，不能被默认为正式环境风格；没有因为通行检查通过而完成美术验收。

## 已有视觉基准

现有主角资源为 assets/hero_pixel/walk_source.png 及其四向配套，当前世界中可见高度为 32 世界单位。查看源图可见：Q 版体量、完整而有辨识度的轮廓、柔和分组的阴影、细像素层次、奶白/灰紫/粉色与低饱和绿色点缀。保留主角，不为迁就环境而改成粗颗粒像素角色。

环境应当使用同样的清楚轮廓、柔和体块和受控纹理，材质仍有自己的自然颜色，不把整张地图染成角色的紫色。树叶以成组叶团为主，避免每片叶子都有强烈黑边或高对比点；地面压低微小颗粒对比与细节密度，为角色和可交互物让出辨识空间。房屋和摆件保持可读结构，减少写实材质噪声。

## 为什么现在要处理

地形轮廓、道路和物件分离后，替换图片在技术上仍可进行；但树冠体量、屋檐遮挡、可见脚点、材质细节尺度都会改变构图和镜头阅读。因此不能先把全图铺满，最后只靠调色来统一。

现在可以使用占位验证行走距离与空间，但只在一段连续区域制作代表性正式素材：一棵树、一种草地/土路及过渡、一组石板，与原主角同框，再扩展房屋和其他植被。现有原图、素材许可和旧样板保留作对照，不批量重绘未确认的方向。

## 下一轮验收方式

- 固定主角高度、实际游戏镜头与中性白天，先检查整体轮廓和像素细节尺度，不先用暮色盖住差异。
- 比较角色、树、地面三个对象的轮廓锐度、纹理频率、阴影软硬与颜色饱和度；不把全部设成 nearest 或整体模糊当作画风适配。
- 检查主角是否自然站在地面上，是否仍像来自另一套素材；通过后才制作该树种的变体及大范围地表。
- 保留 2.15 默认镜头作为固定比较，同时检查用户滚轮常用范围。连续缩放可能暴露高频纹理闪烁，需要在素材/采样阶段解决，而不是限制用户只能使用整数缩放。
