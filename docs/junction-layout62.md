# 环岛与车站：讨论草案，未实施

目前世界树环路半径6.2m，围绕中心树的路是规则圆环，四条线路从四个方向接入；车站在树正北约22m。布局虽然已有小幅曲线，但world19为车站和岔路主动清空了摄像机前方13m的楔形树带，车站入口因此缺少中景遮挡，站台铺装也一次性露出。只扩大环岛或增加地形噪声，不会自动获得探索层次。

建议先确定看见车站的过程：树下只露出车站的招牌或屋顶；沿岔路绕过一片树丛；上一个短缓坡后，才看到完整站前广场。保留辨认方向的地标，但不要第一眼看清所有内容。

推荐分两次小范围尝试：

1. 先做平面和遮挡。圆环改为偏心、略呈豆形的树根小径，三四处宽窄有变化；通向车站的出口偏移，形成一段缓S弯。用两组错位树丛/岩石遮住站台下半部，中间留清楚可走的路；不是重新堵上一整排树墙。树林与道路同步调整，重新烘焙51光照场，保证新的树荫与阳光开口对应布局。
2. 再做局部高差。世界树一侧保留低缓根台，车站前广场考虑整体高1.2—1.8m，带外围林带一起抬升，用较长缓坡或几级宽台阶连接。边缘由短挡土墙、坡面和灌木交代厚度，避免只抬建筑造成悬浮。环岛只保留0.3—0.6m的温和坡差，不急于做多层山路。

上述尺寸是待试玩的起点，不是已确定的设计。可以先用现有树、石头和简模做遮挡/坡道草模，确认步行和视线，再决定是否值得生成专门的挡土墙、树根台阶、站台边缘素材。

后改高差仍可行：树根和草会贴地，桥/建筑、碰撞与通行高度有共同地表接口。但车站基础、路牌落点、门槛、坡道衔接需要随之调整，选定最终车站布景前先做一次小范围高差试走，会比全部摆完后重做省工。

本轮保持world_surface21、原树位置、路径和碰撞，未清树或改变车站/环岛地形。
