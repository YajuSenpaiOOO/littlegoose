# 252 四时段入口恢复 / 主角材质诊断

2026-10-31。用户发现246基线丢失Alt+数字时段预览，并在明亮团团林地发现主角较169明显偏暗，询问森林引入原因与修改影响。

## 输入原因与修复

226 _input数字键保护未排除Alt，Alt+1—4被当成快捷配装数字吃掉，未到world55._unhandled_input→time55.handle_input。现将已知Alt时间操作优先交time55处理，并标已处理；不改普通数字/C控制台逻辑。246姐姐战、251团团和252都恢复Alt+1晨8点/2正午12点/3傍晚18点/4夜22点、Alt+0自然流动，以及原有Alt+T/P。C开着或战斗暂停仍能切换查验。

## 主角差异来源

169系hero146最终使用默认Sprite3D无原生受光显示；192森林阶段明确改为hero192.make_receiver192的StandardMaterial3D，原生受太阳/环境/灯光/阴影影响，且albedo_color为(.82,.82,.82)。法线以法线贴图向上偏25°，保持竖直角色几何。198明确回归hero192，246沿用，251继承246后也沿用，因此该接收材质不是只在森林区域生效。

0.82是额外的材质颜色乘法，不能简单等同最终屏幕亮度下降18%（线性/sRGB、实际照明与后处理共同影响）。原生受光与旧无受光的差别、周围摆件不同受光路径均可造成观感落差。森林mood190/192/193还扩展区域后处理与灯池处理，区域权重受位置控制；不能仅凭偏暗就断言森林遮罩全图泄漏。本次同场景只切主角材质，隔离材质贡献。

## 局部对照，不调整正式森林

新增world252继承251；F9循环：0原hero192原生受光+0.82（默认）/1原生受光白色基底/2无原生受光白色基底。1/2仅复制本实例receiver192，按当前Sprite3D贴图/atlas绑定，回到0还原原材质引用；不保存材质选项，不改hero192.gd、主角形体/脚点/相机方向、森林mood或灯光代码。无受光模式只是同场景接收方式对照，不是声称重现169整套后处理。

默认材质不变；本轮没有把主角全局调亮。若未来正式修改hero192共享材质，会同时影响森林与林外，需要各时段/灯开关同镜头验收。局部252对照不会改变246、169或旧预览的材质；本轮共用变更仅恢复Alt时间输入。
