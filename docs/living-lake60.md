# 60 流光湖水（待用户验收）

用户倾向59的5号绳桥和7号石桥，但湖水未定，暂不选桥。用户指出手绘水面偏高、近乎静态。本轮保留三座桥，只改湖面表现，默认从play.cmd进入world60。

水面实际高度由-0.28降至-0.68米，泥石岸坡末端同步降至-0.655，桥洞和桥底空隙更明显。桥面、桥头通行与水域阻挡的碰撞不变，原地形不改。岸距浅深色仍来自离线烘焙距离图；不是实时测深。

原59波光以线性颜色空间的贴图绿色通道作为显示门槛，实际常达不到阈值，纹理漂移也很弱。60保留手绘底色，以两组不同方向、速度的水纹做轻微扭曲和法线变化；细碎反光按空间位置错相缓慢明灭，格子边缘柔化，避免成片同步闪烁。白天偏浅白青，暮色偏金，夜晚减弱偏蓝。波光是模拟环境反光，没有新增灯、反射相机、屏幕反射、透明折射或水体模拟；不反射角色，也不模拟踩水/涟漪。

Alt+5/6/7现在只换桥、保留水色；Alt+W仍循环三种原水色。Alt+G开关细碎波光，Alt+M冻结/恢复全部水面流动，均默认开启。Alt+1/2/3/4看不同时段，Ctrl+F6回桥。时间预览停表仍允许水纹流动，游戏暂停会停止水纹。

实现：world60继承59，通过桥控制器工厂挂载bridge_lake60；59新增默认行为不变的工厂和岸坡高度接口。lake60.gdshader保留59共享纹理和参数，替换时复用已加载资源。无需逐段手工摆反光，整个湖共用材质，未来水域也可复用该材质并设置各自的岸距图与水位。

验证：lake60_probe.gd 检查实际水位、纹理保留、水面像素随时间变化、冻结完全静止、波光可单独关闭、5/7保留水色、碰撞和地形不变，结果见lake60-validation.json。实际昼/暮/夜和两桥截图在captures/world_restart/lake60_*.png。59已逐桥实测通行，本轮不重建碰撞。

性能：lake60_performance_probe.gd在相同桥中机位、降低后的水位和白天环境，交错运行旧59/新60/新60/旧59材质，各预热30帧、记录240帧。数据见lake60-performance.json；当前机器RTX5060 Laptop，Compatibility，1440×900窗口。短测只评估这次材质变化，不代表其他设备表现或已排除先前偶发卡顿。

最终材质复测：旧59两个片段中位帧时12.332/12.504ms，新60为12.323/12.725ms，片段中位数均值约12.42→12.52ms，差异在短测波动量级。四段各240帧均无超过33.3ms帧，绘制次数均675。没有新增批次；新增像素着色计算仍有成本。

待选型后再细修：湖岸多边形折角、原草坡硬边、桥头局部衔接与桥的重复模块。水色、波光强度和最终水位均未视为用户定稿。
