# 18：草坪厚度、土色斑和临时脚印

继续打开工作目录 `preview_front_cottages.cmd`，当前场景为 `scenes/sandbox/living_path18.tscn`。1号青灰房、17版坡面树根及斜摆件投影保留。U对照草坪与土径高差，I对照土色斑块，F4开关脚印，J仍对照17的新碎边/旧模糊边。滚轮、WASD、Shift沿用。17场景保留。

## 地表关系

草坪保持原有高度，土径中心比原路面浅下沉11cm，0.60至0.98m的横向距离内平滑回到草坪。门口最初一段渐渐收平，不把房屋地基和门槛一起拉低。用真实地形顶点和同一份物理碰撞实现，角色能从路中间走过缓路肩到草上。没有另盖一层悬浮草皮，也没有沿整条路拉一圈垂直沟壁。

更细的四分之一米地形网格解析浅路肩，法线随高差变化；原短草跨过碎边，并随新地形重落脚。路沿补低对比土色暗边，土径内添加世界坐标固定的干燥浅斑、磨损暗斑和原有小颗粒。色斑仅影响土径，不给草坪补回此前不喜欢的大量土斑。当前是浅厚度方向验证，尚非最终画好的草皮断面。

## 脚印

每走过0.62m交替放置左右小鞋底，左右各偏离行走中线0.12m，仅在已落地且脚点位于土路内部时留下。初期清楚，约1.1秒后开始淡化，4.5秒后完全消失；不是永久泥坑。暂停移动仍会消退。传送/空中不拖出长痕，草上不留土脚印。

记录池固定48个，循环复用；不生成脚印节点、贴花对象或碰撞。把世界位置、生成时刻、朝向交给地面shader，直接在路面上画鞋头/鞋跟形状，因此随地形和透视走，不会与地面贴片争抢深度。位置与朝向数组只在新增或清除时上传，时间每物理帧更新；shader仅对土径片元求脚印。不是“零开销”，大地图还需按块筛选附近记录与材质，并在目标设备测试。

## 复用范围与制作顺序

- `scripts/world/path_profile18.gd`：独立的道路横断面，输入离路中心和入口的距离，输出浅下沉量。可改道路样条或地图布局，沿用同一截面。
- `scripts/world/surface_tracks18.gd`：独立脚印记录器，只需要世界位置、时间、落地状态以及“此处能留脚印吗”的回调。与当前角色、相机、房屋均无依赖。
- `scripts/art/living_path18.gdshader`：世界坐标土质、斑块、边缘和脚印，可用于后续地形块。
- `scripts/art/path_surface18.gd`：本小样的接入层，仍读取当前小屋—林口路线，不等于完整大地图地形系统。长路线应分块；当前shader最多32段路线，不能把无限长的整张地图无差别塞进去。密网格也应只保留在近景/路肩，不能据此把全世界都铺成四分之一米网格。

现在值得验证的是地表厚度、道路与草的关系、脚印反馈这组可复用规则；不必先精修每块石头和每根草。确认这些规则后，用它们搭更大范围，再根据完整构图决定额外纹理和装饰密度，避免细节漂亮但世界布局仍需推倒。

## 验证

`scripts/living_path18_probe.gd` 共18项：30/144帧下脚印间距一致、左右交替、传送无连线、停步消退、长时固定48条、草上与空中不留印；实际角色沿浅路行走留印、跨路肩保持落地、实际碰撞跟随U开关；GPU中脚印可见、到期完全消失、I斑块切换并恢复相同画面。实际行走截屏 `docs/captures/world_restart/path18_tracks.png`，路肩/土色近景 `path18_mid.png`。
