# 68 灯下归途 · 2026-10-19

用户要求先加入夜间灯源对主角的投影，眨眼留到后期；另外反馈战斗最低约55FPS，讨论下一阶段场景与战斗顺序。

## 试玩

入口play.cmd / preview_world_garden.cmd，主场景world68。普通入口先站在小屋路灯旁，22:00停表夜景预览，便于直接观察新增效果。绕到灯的另一侧，影子随相对位置改变；走向屋门，主要光源会改为暖窗。Alt+S开关新增灯影，Alt+0继续自然时间，Alt+1/2/3/4预览各时段。战斗入口保留原流程，不自动改到夜间院子。

沿用67整树隐去，Alt+O只对照两种整树方案；保留动态水、根碰撞、帧率面板和Ctrl+F9/F10/F11。

## 实现与边界

local_lamp_shadow68注册已有window_spill56与woodland_life.lantern_light，未新建灯光、未开启它们的native shadow。每0.1s比较实际能量、影响范围和遮挡，使用光源到角色的障碍层射线，避免透过小屋/树干/摆件产生不合理的灯影。昼夜权重来自现有daylight55，白天不加局部影。

只增加一张主角轮廓影，由主要灯源驱动。当前光源分数达到最强分数72%以上时保留它，避免两灯交界频繁切换；换源时先淡出、再从新方向淡入。远离、灯光隐藏/关闭或有遮挡时淡去。主角原月影随局部影权重最多减弱80%，脚下接触感继续保留；其余角色仍按原策略。

这是配合立牌画风的地面近似投影，并非全场景物理点光阴影。方向取角色背离灯源的水平向量，虚拟投影高度不低于1.5m、水平斜率限制1.45，避免现有约1m高的小灯源把角色上半身投成无限长影。不会把影子投到家具/墙上，也不会自动使草叶接受角色遮光。

cached_actor_shadow68复用25的9点地形投影，静止姿态缓存，一般最多20Hz重建；贴图变化或较大传送立即刷新。5次纹理采样做窄柔边，ink在线性颜色空间取很暗的蓝黑，避免夜间暗地面反被影子照亮。没有新生粒子、全屏通道或多份局部影。

world_time67增加默认空的_guide_suffix67接口；time68只返回补充文字，保持67最终一次赋值的UI优化。

## 验证与开销

lamp68_probe：13项通过。覆盖一个投影/两个源、native阴影关闭、白天无局部影、灯两侧选源与背光方向、重建数量、窗前主源、贴地、实景开关确实压暗地面、障碍阻挡、离远消失。

同一进程、同一夜间路灯站位、说明面板可见，关闭/开启/开启/关闭，各180帧：

| 状态 | 帧耗时中位ms | P95ms |
| --- | ---: | ---: |
| 关0 | 9.839 | 13.059 |
| 开1 | 9.956 | 13.140 |
| 开2 | 9.673 | 12.703 |
| 关3 | 9.887 | 12.792 |

短测未见能与波动区分的持续增加，各段均无>33ms帧。这个结果不等于零开销，也没有覆盖实际战斗。用户战斗最低55FPS的反馈单独记录，不能用此静止灯影测试替代。

lamp68-validation.json保留结果。截图captures/world_restart/lamp68_{lantern_-1.0,lantern_1.0,window,window_off,window_on,live}.png；最终window_on和lantern_1.0已检查，灯旁影子背离光源、无局部树冠开窗。
