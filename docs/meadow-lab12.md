# 草与地形对照 12

保留用户认可的 D 地皮（4号，`assets/ground_lab11/d_ground.png`），不重新生成或覆盖它。此次增加的是原生草叶几何及真实地形，供可玩小样比较；不涉及正式世界入口、房屋或树木。

根目录启动 `preview_ground_lab.cmd`，默认近景、4号地皮、贴地短草、连续缓坡。

| 按键 | 比较内容 |
|---|---|
| 7 | 贴地短草，叶片分散、低矮、铺底感 |
| 8 | 弯叶高草，更长、更明显的弧线与摆动 |
| 9 | 圆叶卡通草，较宽的叶腹和简化轮廓 |
| 0 | 旧11尖叶草，保留原几何/着色作对照 |
| T | 真实缓坡/真实平地，同步改变碰撞、植被与角色脚下高度 |
| H | 开关额外的片区/单株高低变化；旧有基础随机缩放仍保留 |
| 1—6 | 原有六种地皮 |
| J / G / K / L | 实体草与旧透明贴片 / 草开关 / 风开关 / 原色与受光 |

WASD / Shift 移动，滚轮缩放，C 跟随，R 复位，F1 隐藏说明。7—9切换时保留当前地皮、地形、人物及相机。T 会重置人物垂直速度并将其放回新地面以防卡入地形；横向位置保留，仍保留当前镜头缩放。

## 悬浮感的具体原因与本次处理

旧草实例根部高于地面0.012米，叶形像集中摆放的尖叶物件；草和地皮独立配色，没有根部颜色过渡或坡向联系。仅更换画风无法同时解决这些问题。

新三种草根从地面下0.035米开始，实例根节点取同一地形高度，根部朝向随地表法线。新着色器读取脚下同一张地皮及同一镜像平铺坐标，根部混合到底色，叶尖保留轻微冷暖/明暗变化；纯色地皮也沿用其实际颜色。没有为每株新增透明阴影圆片，因此不引入又一层透明排序。未宣称已经完成最终根部接触阴影或所有距离的抗闪烁。

每种草共享不透明轮廓几何与材质，仍为3600个批量实例，无逐株脚本和碰撞。短草、高草、圆叶分别为每实例63、45、36三角形，比旧11的25三角形更高；没有把功能正确等同于全地图性能已验证。拨开、风摆、脚步轨迹回弹继续在共享着色器内执行。

## 起伏的逻辑

以两侧宽丘和右前低洼组织大形，叠加固定种子的低频小变化；路中保留浅的纵向坡度，两侧逐渐过渡上岸。不是逐顶点随机抖动。可走区域网格间距0.4米、平滑法线；外围逐渐归平。可见网格和物理碰撞来自同一份顶点数据，草根/坡向/角色脚底/接地影倾角随之同步。

草高混合低频片区变化、稳定的单株差异和低地偏高的倾向；同一位置切换草种不会重新抽样。平地对照中也保留同样的高低分布，以便区分“改变草高”和“抬高土地”的影响。

地皮依旧使用世界XZ坐标铺设，缓坡角度下变形较小；陡崖、垂直切面不在此实验范围，不能直接沿用当前铺法。起伏增加轮廓和坡面受光，但不能代替后续道路边缘、植被疏密、光照与场景构图。当前地皮重复感、宽阔空地和较平的根部光照仍是已知美术限制。

## 实机验证

运行 `--path godot_world --script res://scripts/meadow_lab12_probe.gd`，实际OpenGL渲染13项通过：

- 角色落地、真实输入上坡；最终站在约1.44米高处，脚下高度误差小于1毫米。
- 地表碰撞抽查与连续高度函数最大误差0.001789米；坡面法线朝上，路中坡向平缓。
- 草根中心吻合地形、朝向吻合坡面，高度变化可逆且不重新撒点。
- 三种几何不同、根部埋入、读取当前地皮，且没有透明裁切。
- 三种草的GPU接触变形分别影响1263、1668、1575个局部像素；恢复残留均为0。
- T 同时恢复真实平地碰撞和植被高度。

旧 `ground_lab_probe.gd` 显式选回0号旧11草，19项回归检查通过。旧测试的时间跳变指标只对应旧11比较，不作为新12草抗闪烁的新测量结果。
