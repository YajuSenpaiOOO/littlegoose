## 成长预算建议（未确认）

可先用初始4槽、前两个Boss各+1槽、姐姐前6槽的测试路径，公式4+(等级-12)，作为第一地区预算，不据此承诺后续所有地区无限增长。血上限和槽容量是两个字段，虽可同次成长但不要共享变量。容量增长会让旧4槽下互相取舍的强卡同时上场，应同时检查4/5/6槽，不单独调一张卡。
