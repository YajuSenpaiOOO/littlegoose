# 116：树墩魔法锅与记忆百宝盒

2026-10-22。用户选择A版，已接入实际小院。默认 `world116`，`play.cmd` 或 `preview_memory116.cmd`；关闭旧窗口后确认标题116。

## 体验入口

- 初次启动回小院，不再先弹114/115的A/B菜单。
- 门口左侧是树墩搪瓷锅，旁边是矮木箱上的青绿饼干铁盒。靠近按F整理记忆。
- 点击左侧记忆查看效果，右侧“放进口袋／收回铁盒”。“先不改了”、关闭或Esc取消本次修改；“收好”保存；也可“收好并去林地试演”。
- F5前往/重开林地试演，F3回小院。试演仍复用原45秒、同时三位团团演员的原型，保留115方向软锁定、手动射击和蹲防。F2不再切自动档。
- 演出结束可再演或回院换装，回家、重试均保留已确认的配装，弹丸、光束、演员与临时战斗状态清理。
