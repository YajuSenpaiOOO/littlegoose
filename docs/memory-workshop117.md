# 117：像素百宝盒与棒棒糖轻瞄准

2026-10-22。默认入口 `world117`；`play.cmd` 或 `preview_memory117.cmd`，标题“117 · 像素百宝盒 / 棒棒糖轻瞄准”。沿用116的配装存档。

## 摆件

锅/树墩和铁盒/矮木箱沿用116原始透明素材，使用固定在贴图上的像素采样格和轻微色阶归并，减少平滑细节。锅按原图8像素、铁盒按10像素一格；并非屏幕马赛克，不随镜头位置重新划格。不更改原图、锚点、碰撞或地形。保留共享昼夜受光、贴地轮廓影及局部灯影，蒸汽仍近处更新、远处停止。

## 辅助与提示

116继承了115的方向辅助算法，但把试演UI替换成回家/再演面板时，丢失了旧面板中的持续目标刷新和绘制。因此辅助仍可能在射击调用时生效，却没有可辨认的选中提示。117将持续刷新及提示放进独立控件，与结算面板解耦。

- 保留鼠标大致方向选择、32度获取/55度保留、明确转向释放、遮挡和距离限制；继续手动开火。
- 战斗中鼠标使用小型奶油粉像素棒棒糖，糖面轻微闪光，获得目标时短暂闪一下，已选中时转暖桃色并留一颗小糖星。指针热点始终固定，动画不挪动实际瞄准位置。
- 演员头顶只显示一颗金色像素糖星及小点，轻微上下浮动；取消旧椭圆圈、身体括号和瞄准连线。标记使用演员可见高度，排除贴图透明边距。
- 提示和实际发射共用 `target114`/`aim114` 与物理帧缓存；没有自动射击。鼠标离开身体仍可保留辅助，转身、遮挡或演员退场时释放。
- 暂停、结算、配装、回院、失焦、鼠标移出窗口及退出控件时恢复系统指针，避免双指针。
- 棒棒糖为代码内手绘像素图案，初始化烘焙4张小纹理，每帧一次贴图绘制，不增加粒子、实时灯或物理节点。非战斗时不重复重绘。
