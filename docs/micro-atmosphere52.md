# 52：阳光尘屑与主角暖补光

2026-10-18，基于51；效果待用户试玩验收。默认项目及通用入口切到52，`preview_world_atmosphere52.cmd` 直接到林路。窗口标题“林间微光52”。

- Ctrl+J：尘屑，默认开。
- Ctrl+U：主角暖补光，默认开；在阴影处对照更明显，阳光开口内接近关闭。
- Ctrl+F4 林路、F3 小院；Ctrl+7/8/9 仍为51的原50/树密度/密度＋开口对照。

## 尘屑

`sun_dust52.gd`：固定96槽MultiMesh，围绕附近最多三个阳光开口循环。小院另用已认可的门前开口。尘屑位于世界空间，朝向相机，深度测试保留，树和房屋能遮住它们；不是贴在屏幕上的粒子。

直径约0.017—0.054米，生命周期14—25秒，低速漂移并淡入淡出。使用51光照图估算可见亮度，小院叠加49开口判断；林荫中更淡。柔软淡米色圆点，不作星形闪烁、光晕、全屏白点或真实小灯。每个尘屑不投影、不配置灯。

这是受光外观近似，不读取实时太阳阴影缓冲。尘屑接收区域明暗，个别实时树影与区域图可能不完全吻合。动画需在游戏里停留几秒观察，静态截图差异较小。

## 主角补光

`hero_fill52.gd`：沿用51的人物着色后，按所在光照图的明暗估算补光强度，约半秒过渡。阴影中最大约红×1.13、绿×1.065、蓝×1.012；阳光中趋近原色。乘在既有反馈上，保留受伤红闪。

一盏跟随主角的OmniLight，暖米色，范围1.45米、最大能量0.12，不投影；轻微影响脚边环境，不画地面光圈或可见聚光锥。原角色轮廓投影继续工作，26版已取消的旧椭圆影保持隐藏。不新增世界观设定，未加入萤火虫或夜景。

## 验证

`scripts/world/micro_atmosphere52_probe.gd`：17项检查通过，包含Compatibility、固定粒子池、灯无阴影图、同机位补光开关/恢复、阳光下补光减弱、尘屑实际成像及漂移、院口通行、首波战斗、受伤红闪和原轮廓影。结果 `air52-validation.json`，截图 `docs/captures/world_restart/air52_*.png`。没有进行跨设备性能测评。
