# 271 团团碰碰车混合试演

用户授权两只滚滚+两只普通的碰撞互动，暂不加生气追逐。271独立场景继承270，四演员开场、无后续波次，不接正式奖励/Boss挑战；名单TOTAL4，真实击败四只结束，F8再玩。原269/270单只、268四批仍可进入。

## 互动

滚滚收到角色碰撞后按对方类型处理，不再一律当墙。沿用真实move_and_slide法线，判断碰前意图速度之差的迎面分量（>1.8m/s），因为move_and_slide已消掉法向速度，不能用碰后的静止速度判撞击。低速贴靠不当重撞。同一实例对排序ID后共用.4秒冷却，另一方处理时不重复结算；四人最多六对，重开清空。

- 撞普通：普通被推离4m/s并衰减，.55秒压扁停手且仍可受玩家攻击；滚滚按接触法线反射，消耗一次反弹额度。双方不扣HP。
- 两滚滚擦碰：双方方向分别对同一法线反射，各消耗一次反弹额度，继续剩余距离/时间限制。不是交换HP或无限加速。
- 对向滚滚：方向dot<-.6且有足够接近速度时，双方各弹开.18秒，接原1.8秒眩晕。立即离开rolling分支，不继续结算玩家伤害。

普通团团采用专用短晕/推移控制，避开旧吵架状态；滚滚碰撞后短暂推移也用真实move_and_slide。不同分支保留原攻击/弹反/返程无伤、墙反弹、14m/2次反弹/3.5秒/卡住.3秒上限。仅第二只首轮启动晚.55秒，不让两只必然同步。

269仅新增actor_contact271默认false钩子与状态转移后提前结束伤害分支；旧单只不会处理角色规则。新271使用专用roller271/bumped271，原四批普通怪不被自动添加短晕技能。花与身体继续270运行时合成，显示/光照/脚点/碰撞形状未改，无新PNG。

采集mixed271记录ordinary_bumps/head_ons/glances与actor_collision事件，旧roller269.bounces仍专指场景障碍。每种相撞事件应只增加一次，弹反仍独立计数。未自动提交或push。

## 验证

14项Compatibility检查通过docs/mixed271-validation.json / mixed271-validation.log，无脚本/shader错误；旧relay_flag245导出警告仍在。实际角色走向接触（非只调事件函数）验证撞普通/反向、普通真实推移、正面对撞双方眩晕分离、垂直擦碰双方改向。另测无敌人HP损失、同对去重、暂停短晕、场景障碍计数独立、四击败结束/重开4只。测试免玩家伤害、布置碰撞路线，不作玩家实战压力结论。测试启动期间审查发现move_and_slide会清法向速度，改用滚前意图后重启完整验证。已看head-on实机截图，花仍整体合成。未新增图像、未重开森林遮挡。
