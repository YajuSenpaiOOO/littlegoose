# 97 林间自然游园：运行版

2026-10-20。按用户确认的[概念草案](concepts/woodland-nature-park97.md)施工，默认入口world97；旧96场景与preview_woodland96.cmd保留。

运行play.cmd或preview_woodland97.cmd。Ctrl+Alt+F2到中央游园，Ctrl+Alt+F3看树下秋千，Ctrl+7到西崖；Alt+1/2/3/4切晨午暮夜。正常跟随镜头保留25度俯角。

## 已落地

- 西侧连续高崖约10–11m标高，主活动面约2.1m；崖线前后错落、山顶实际植树，最终15棵树位于高于9m的西侧山顶范围。沿原后林台衔接，遮住西侧虚空。
- 崖脚观景台4.35m标高，实体石阶8级、短木栏，左侧草台与山脚相接。原地形承担阶梯下的可走坡面，阶面和侧缘用真实网格表现，局部隐藏重复地表。阶梯有效宽度及坡面侧肩受控，避免坡面侵占旁边环路。
- 不规则游园环路、入口接入与台阶前支路。主环约19.8m宽、17m深，草坪保留横纵通行与三波战斗空间。原林地入口改为接到环路，取消伸入草坪中央的旧断头土路。路径上真正隐藏原草叶，地面按有机颗粒和柔边着色。
- 树下木板秋千与两条绳索，枝杈由真实几何连接树干；秋千轻摆，镜头缓冲范围外停止变换更新。另有倒木、五个不等高踏桩、木座，放在步道外，场景物件含26个碰撞体。
- 新手绘木材图集用于树皮、裸木纹和端面年轮；石阶/台顶复用84手绘石灰岩顶面，按世界坐标投射，避免拉伸纹理。木材用内置image_gen生成，完整提示词见[素材记录](../assets/park97/GENERATION.md)。
- 656株低野花分布在园内几个连续边缘区域，花与草继续独立；灌木/蕨草保留碰触和受影，路旁摆位避开等间隔一圈的重复感。原95周边更新范围、日夜和主角遮挡淡出继续使用。

## 验证

woodland97_probe.gd最终20项全部通过，结果woodland97-validation.json，日志woodland97-render.log。包含整圈步道实走、观景台上下与返回、原入口返程、中央东西/南北实走、每波刷怪数、完整导航路径、选卡衔接及六敌清场。战斗流程用脚本调用实际受击/击败接口，不等于人工战斗手感验收。

构建中发现并修正了座位/倒木压路、环路切进台地陡坡、阶梯坡面侧肩伸入环路的通行问题；通过碰撞法线与实际物理网格高度诊断，收窄阶梯侧肩后整圈实走通过。首轮规则路面纹样及石阶纹理拉伸已替换。

最后一轮改动只涉及石材色调、非碰撞植被摆位；随后用woodland97_capture.gd重拍并另做默认场景startup84-check。最终渲染、截图、启动日志无脚本/着色器错误或警告。首次地形/树根冷构建约89秒，后续同版命中缓存约24秒；这不是FPS数据。缓存签名补入park_layout97.gd，确保后改布局不会误用旧地形缓存。

实际画面在docs/captures/world_restart/woodland97_*.png；park_day、overlook_day、swing_day、play_day为正常视角。park_overview_day是同俯角拉远10m的检查镜头，关闭景深，仅用于展示整体构图，未改变游戏默认跟随镜头。
