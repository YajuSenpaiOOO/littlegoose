# 57 夜幕舞台：日月交接、萤火虫、柔光聚光与远景空气

统一入口仍为根目录play.cmd，默认world57.tscn。地形、完整房屋楼梯、25°镜头、Compatibility、每波选卡及55时间/睡觉规则保留。

## 试玩

Alt+4夜晚，F3小屋，Ctrl+F4林路。Alt+F开关萤火虫，Alt+L开关舞台聚光，Alt+H开关远景柔化，均默认开。白天两种夜间点缀自动关闭，18:48至20:48之间渐入。Alt+3之后按Alt+T可看落日到夜晚的连续变化，Alt+0回正常流速，Alt+1/2/3/4仍为定点时段预览。

## 影子倒退的原因和修正

56把18点落日方位65°直接插值到19:30的15°、22点的-32°月光方向，仍可见的长影因此向回转。

57增加交接节点：落日继续到19点的75°，同时原生与人物影淡至0；19:00—20:30保持无投射阴影，仅保留接触暗部；只有在这段区间内把方向换到月光；20:30之后在固定月光方向淡入轻微月影。不是把同一条可见长影倒转成月影。

太阳方向差小于0.06°时跳过变换，角度不变/停表不反复写入太阳变换；阴影透明度也按变化更新，0端点精确归零。颜色与环境仍沿同一时间轴平滑更新。没有按秒重建树林或烘焙地表贴图。树影绘制本身仍有成本，尤其树多、可见范围大时；角度计算本身不是主要开销。

## 发光复用

`warm_glow_preset57.gd`资源区分光芯强度、照明能量、范围、颜色，以及昼夜两端；`warm_emitter57.gd`绑定已有灯和/或材质，灯可为空，不会自动给每个发光点创建灯。预设在`assets/lighting55/`：cottage57、lantern57、stage57、firefly57。

小屋和路灯已接入组件，夜间范围/能量保持56；舞台光也接入。新增物件可选同类预设并绑定一次。萤火虫用32槽MultiMesh，只发光，不给每只分配点光源。今后烛火、灯笼等是否照亮周围，按它在画面中的作用和灯光数量预算决定；当前没有无限多局部灯的自动预算调度器。

## 夜间点缀和朦胧感

32只萤火虫分布在玩家附近的林下/路边，慢漂且错相明灭；距离远时淡出再复用，没有每只灯、阴影贴图或粒子节点。它们靠自身柔软光芯和光晕可见。

主角上方6m放一盏跟随的SpotLight3D，无阴影；一个软边、深度测试的透明光束网格表现空中的光路，不增加体积雾。人物是绘制式Sprite3D，增加轻微暖色反馈，并在已有后处理中为主角附近、相近深度的区域减弱部分蓝色分级，使舞台光能读出来；受伤颜色保留，关闭聚光时同步取消该响应。保留56的基础人物补光，Alt+L与Ctrl+U分别控制这两项。

没有加大景深半径。已有后处理只对焦点后7—32m逐渐混入少量空气色（白天3.5%、夜间8.5%上限），不增加新模糊采样；玻璃周围的既有柔晕半径从16扩大到21像素，采样数仍为13。主角、近处道路和台阶不施加整屏额外模糊，Alt+H可对照新增空气层。

## 验证

`day_cycle57_probe.gd`：45项检查，覆盖昼夜、暂停、深夜停留、跨日、战斗、日月交接时原生/人物影同步消失、影轨迹、32槽无逐只灯、舞台光/人物响应、远景柔化实际渲染与缓存复用。结果`docs/day57-validation.json`，截图`docs/captures/world_restart/day57_*.png`。

`night57_performance_probe.gd`：同一镜头240帧/档，交错固定日影/自然移动日影，以及夜间新增效果全关/全开；保留风摆、原有阴影与基础灯。结果`docs/night57-performance.json`。它测的是当前设备和固定镜头的短时对照，不能证明全部设备零开销，或此前偶发卡顿已解决；启动加载与首次编译也不在稳定段统计内。

最终配置在本机Compatibility/NVIDIA RTX 5060 Laptop的两轮结果（每档帧耗时中位数）：固定日影12.16—12.81ms，自然移动12.10—12.32ms；夜间新增效果全关12.11—13.63ms，全开12.88—13.54ms。区间有重叠，未测到稳定的日影转动增幅；新增夜景有少量开销，前一组开关对照约增加2次绘制。八段共1920帧无超过33.3ms的帧，最大21.91ms。以上是短时结果，不作长期无卡顿保证。
