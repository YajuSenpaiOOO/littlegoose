# 120：打倒后概率掉落与更长的林间聚会

2026-10-23，按用户澄清“打倒而非命中掉落”实施。沿用119进度 `user://tuantuan119.cfg`，不重置材料、弹弓与已装配记忆。

## 掉落

- 每位演员退场时只判定一次，25%概率产生一颗B款星光软弹珠。普通命中不判定，不因高射速/分裂/伤害次数多获得更多机会，重复退场回调不重复掷骰。
- 全场15位，理论期望3.75份；弹弓仍消耗3份。没有散场固定3份礼包，也没有暗中保底，所以单场可能多于或少于一把所需。
- 生成后有抛出轨迹、两次回弹、触地压扁复原和轻微浮动；小范围靠近吸附，附窄接地影。素材加入共享昼夜受光管线，所有拾取物共用同一材质。
- 不用RigidBody或每颗碰撞体，每物件仅简单运动更新；本场最多15件，暂停时冻结。
- 拾取一颗即保存一颗，保存失败不销毁物件、不增加库存，间隔一秒重试。主动退场保留已拾取材料，未拾取的场景对象清理。
- 完成后余下已生成物件飞向主角，拾取完成才打开结算；这是收拢地面已有掉落，不额外制造奖励。结束标记仍保留防重入逻辑，不调用119固定礼包发放。

## 战斗节奏

- 三位开场，后续四组、每组三位从附近加入，总数15位。每次预告后依次跑入，场上交手上限5位，不显示波数。
- 每组加入完后至少间隔6秒，并在场上存活者不超过2位时准备下一组。最后一组完成后不再刷新。
- 普通团团生命从119的4暂调至6；主要通过更多参与者与加入节奏拉长演出，不使用45秒强制终止，也不单纯堆出长血条。
- 休息演员停止物理行为，保留可见姿态，不无限追加AI。剧情邀请仍待后续，用F5快速验证。
- 参数集中在 `outing120_balance.gd`，都可随实测调整，不承诺所有构筑时长相同。
