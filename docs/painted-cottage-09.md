# 09 · 生成小屋与草叶的实际对照

用户认为 08 的几何房屋、草形和模糊大地面仍有廉价早期 3D 感。本轮以真实生成的绘制资产替换视觉占位，继续保留实际三维移动、镜头与碰撞。仍是单处效果小样，没有宣布全地图或 HD-2D 美术完成。

## 资产

使用内置 imagegen，不使用 CLI/API fallback：

- `assets/perspective09/cottage.png`：完整透明小屋，红棕瓦、木构、灰蓝石基、暖窗。先生成一次，再修订一次透明画布边距，保留完整檐口和烟囱。
- `assets/perspective09/grass_sheet.png`：4×2 共八种短/较高草叶，暗橄榄/苔绿、小暖色叶尖，无花或圆灌木。
- 生成完整提示与修边提示记录：`art/source/perspective09-prompts.md`。
- `cottage_profile.json`、`grass_profile.json` 描述 alpha≥0.5 可见边界、脚点、每格 UV 与宽高比。`scripts/build_perspective09_profiles.gd` 只读 alpha 与写元数据，不改生成图片像素。

均已复制进项目，运行时不依赖生成缓存目录。

## 看实际效果

`preview_world_3d_art.cmd` 以较近镜头开始看小屋局部；原 `preview_world_3d.cmd` 继续查看同场景的较宽视野。B 切生成房屋/旧体块房屋，J 切生成草/临时图集草，V 切旧地皮与修订地面，G 隐藏植物，F1 隐藏说明。保持原有透视、移动、射击、坡面行走和遮挡淡出。

生成房屋目前是完整竖直贴片，放在原房屋前缘；旧体块只提供碰撞与粗略方向影，B 可恢复显示。它不是可以包裹模型的 UV 贴图。图里的右侧墙为已绘制侧面：镜头平移不会改变它的可见宽度，不能从任意方向自动生成侧面。生成图的 25°是候选观察方向，未通过精确建筑投影标定。未来若要求近距离绕行一致，应拆正/侧墙与屋顶纹理，或把绘制材质用在合适的简单壳体上。

## 画面修订及诊断

本轮判断 08 的主要问题是：被大幅低频化的地面失去材质，廉价免费图集草和树/角色/房屋的像素尺度不同，均匀撒草铺满场地，以及过度偏黄的全局照明缺乏重点。

修订地面采样由过度模糊改为保留较细材质、像素采样与 mipmap；不把长草全部烘进地皮。原图中少量地面形状依然存在，不宣称已经生成无草地皮。土路降低偏黄高亮，日光减弱黄偏。草改为 4200 株共享实例、八个图案、按实际长宽比和短/高草分尺寸，密度随空间变化，不再均匀撒同一种荧绿草。参考柱维持隐藏并禁用碰撞，坡边几何标记方块本轮也撤下。树位保留。

这些解决的是材质与构成问题，未靠大面积景深/泛光遮住低质量资产。与八方旅人仍有差距：树的风格尚未与新屋统一；缺少前/中/后景的完整关卡构图；立体草的尺寸和色彩仍是候选；贴片主要保留自带明暗，真实地表受光与贴片尚未完全统一；阴影是粗略代理形状。

Square Enix 官方对 HD-2D 的介绍是复古二维角色与三维世界的结合，不是所有物件都必须变为立牌。参考：https://www.square-enix.com/asia/newsportal/en/sg/octopathii/ 。本项目以温馨、有材质厚度为目标，不直接复制其色调。
