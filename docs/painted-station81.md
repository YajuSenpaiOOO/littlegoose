# 81：候车厅、雨棚和静态车厢

2026-10-19。基于80连续石阶和干净地表，开始把车站从地形结构稿补成可体验的小站组合。当前为外观与通行初版，待用户判断体量与画风。

## 本轮内容

- 前广场7级短阶、岔路9级侧阶保留封闭挤出网格与原碰撞坡面。改用`station_brick73.gdshader`，与广场同一砖石颜色、砖缝和世界坐标尺寸；底下地表的局部隐藏保持。
- 候车厅偏左，红瓦钟楼、青灰砖墙与暖窗；雨棚位于右后方，后面停一节蓝灰静态客车。前广场与候车厅东侧保持绕行空间。
- 站台高0.39m，主顶18×5.2m，两端各1.5m缓坡；顶、斜坡、立面和底面是一个闭合网格。列车20m长，沿现有直轨摆放，轮底锚点位于轨顶附近。
- 候车厅与车厢有独立实体阻挡；雨棚只有四个柱碰撞，中央可以走通。站台用真实坡面/平台碰撞，不用角色瞬移模拟登台。
- 使用现有暖光绑定器：候车厅两处窗光、雨棚一盏檐灯、车厢一处窗光，共4个小范围Omni，不新增灯光阴影贴图。接入现有主角灯影源选择器；它仍只保留一个主要灯影并交叉淡入淡出。发光核心限制在玻璃纵向范围及暖色像素，屋顶和木棚不自发光。
- 候车厅和车厢复用已有贴图轮廓落地投影；大件遮挡复用67的实际不透明像素检测，整件平滑隐藏，带0.35秒保持。碰撞不会随淡出消失。初轮12%残留在近处形成大面积噪点，已改为完全隐去，仅过渡阶段保留抖动渐隐。

## 体验与验证

入口仍为根目录`play.cmd`，`preview_world_garden.cmd`同入口。窗口标题为「小白鹅 · 车站81」。Ctrl+5到候车厅前，5到原前阶，8到铁路；Alt+1/2/3/4看晨/昼/昏/夜，Alt+0恢复自然时间。默认仍从原岔路进入。

专项`station81_probe.gd`检查闭合阶梯/站台、同款砖石、四灯无新增阴影贴图、实际角色绕厅/登台/棚下通行、厅墙与车厢阻挡、夜间光级及灯影源、窗光遮罩和建筑整件隐去。结果见`station81-validation.json`与`station81-probe.log`；截图为`docs/captures/world_restart/station81_*.png`。

最终12项专项检查全部通过。实走站台脚下高度3.7908m，设计顶高3.79m；背厅遮挡复测完全隐去。白天、夜间、棚下、背厅和全图截图已目检。素材导入与最终运行日志未发现脚本或着色器错误。短暂截图测试不代表全场景/忙战性能基准。

这轮没有行车、上下车、售票交互、候车厅室内；这些后续另做。全图砖地、绿化、墙脚收边、站牌与站区灯杆可在体量确认后继续精修。51宏观林荫仍是旧树位烘焙，战斗忙时掉帧问题尚未做完整性能归因，本轮不能算已解决。
