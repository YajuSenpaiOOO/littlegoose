# 149：地面标记，高空三投

## 操作与规则

- 选择纸飞机后，左键点击实际地面放下固定标记并放飞，按住连续呼叫。地面射线忽略敌人的辅助瞄准，最远12米；坐标保持固定，敌人走开后不会自动追着敌人改标记。
- 冷却期间的点击显示淡色待发标记，保留最近一次请求，冷却结束后放飞。蓄力组合按原按住/松手操作，在松手时确定地面标记。装配切换、清场、回院、死亡清除请求与标记。
- 飞机快速爬到标记上方约4—6米，随机侧弧进入。进入高空直线掠过段时，曲线位置与切线连续，必定通过标记正上方；随机性来自入场侧向、控制点、高度、时长和出场弧线，不影响目标点。
- 每架飞机固定3次投弹，中间一次位于标记正上方，另外两次略在前后；三枚都落向同一标记。下落0.6—0.78秒后触发半径1.4米的落地冲击，可影响该圈上方3.5米内敌人，并检查地形遮挡。圈上三点表示未落地投弹数，三次全部落地后圈消失。不会在飞机碰到敌人时结算伤害。
- 当前载荷的伤害预算分为三份，蓄力也不会复制成3倍重弹；多弹道将本轮弹丸伤害合入载荷，分裂按既有命中管线生成次级弹丸，水柱将短束伤害合入三枚水色载荷。追踪组合提升射速，固定地面轰炸不自动追踪怪物。
- 保留课堂笔记：一次放飞记录一页，三次落地不递归记录；Q重放45%载荷，允许和已有机群同时在空，不等待飞机名额。
- 为高飞飞机保留画幅，纸飞机战斗时镜头平滑后退14%、视线整体抬高1.1米；离开该玩法恢复。

## 三架是基准，不是上限

飞机在空3.6秒，初始放飞间隔3.6÷3＝1.2秒，常态约3架。射速按比例缩短放飞间隔，当前两级眼保健操约0.64秒/架，常态约6架。三人小游戏保留射速惩罚。没有3架或其他固定在空飞机上限；原有按键/装备能达到的射速仍决定增量。技术性最小放飞间隔0.05秒，有限生命周期自然清理。

## 表现与开销

复用原纸飞机素材；标记、下落纸包和落地光圈为程序形状，没有新生成位图。飞机无物理体，纸包使用确定时长轨迹；仅落地时遍历存活敌人并通过已有受击管线结算范围伤害。投弹不中途碰怪、不提前消耗，保证三次落到标记。

次级分裂弹限制512枚在场，历史调试记录保留96条；飞机数量不受该限制，落地冲击不会因为次级弹幕满额而丢失。每物理帧每架至多补齐其固定3次投弹，不产生无限追赶队列。大机群的目标硬件帧率未作保证。
