# 204：纸飞机辅助圈贴地

2026-10-27。用户反馈203中辅助圈盖在树干、紫布与摆件前面。定位为paper_flyby150.ring150：世界坐标环点经camera.unproject_position转换后，由CanvasLayer上的Node2D.draw_polyline叠画，没有场景深度测试；并非标记点被放到了树干高度。

## 修改范围

world204继承203，专用paper_ground204继承paper_squad169，仍用原飞机发射、按鹅分组、覆盖半径2.4米、六连投/九发模式和选敌/伤害。仅更换显示工厂，不写回169/173/203，不改瞄准落点/碰撞/主角角度/前景树避让。独立forest204_preview.cfg。

旧屏幕圆圈停止绘制；待投标记、飞机落点大圈、中心圈、尚未投下的覆盖扇区小圈，改成世界空间窄带网格，沿原world.floor_height逐顶点采样，离地0.035米，窄带宽0.026米。正常GPU深度测试，接受地形/角色/树/摆件遮挡；材质透明、不受灯光、不投影、不发实际光，保留辅助标记可读性。透明绘制优先级-10，让布景透明层正常盖住地面标记。每段两侧高差超过0.20米则断开，不画跨崖竖墙。相同中心/半径标记取较强alpha，避免多鹅同一圈反复叠亮。

保留笔记页UI和HUD在空飞机/模式统计；移除落点下方原屏幕小计数点，避免与地面圈产生悬浮感。该显示变更不改变投射数量或时序。取消、重开、结束试演同步清空网格。

## 验证

Compatibility实机11项检查通过，报告forest204-validation.json。GPU同位置有/无圆圈对照：前景实体遮挡下颜色差0，移开实体后颜色差约0.239，证明圆圈不是被整体隐藏；所有圈顶点均为地形高度+0.035，检查无大高差跨面三角形；实际多鹅飞机仍生成中心/覆盖点，调用drop150后历史与原落点保持，退出清理。树根日夜、台阶和GPU对照截图见docs/captures/world_restart/forest204_*。

树根截图可见圈前半段贴地、树干和根片上没有覆盖线。台阶/近树仍受已有200前景避让问题影响，本轮不重新调树。整个地图的其它Canvas特效、旧笔记UI或其它敌人预警未批量迁移，不宣称全局世界空间特效统一完成。
