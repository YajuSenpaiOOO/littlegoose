# 西侧纸张山顶：第一轮概念

## 已确认的方向

- 用户希望前期允许可爱、有一点伤害、偏狩猎收集和组合试玩的敌人，不要求所有普通敌人都高压。
- 纸怪拟安排在现有左侧山顶，形成视野开阔的空地。
- 左方希望用远海等远景表现高度；是否采用背景贴图及具体层数待实机确定。
- 纸怪外观沿用C撕页与现有轻摆、鼓风动画。
- 既有材料草案将纸张来源指向纸怪，候选用途为纸赛车、纸杯电话，正式配方未定。

## 本轮建议，待体验和选择

主景为一块开阔草地，入口在右下接林间山路/石阶，树与较高植物集中在右侧和入口，左缘用岩头、矮草和少量白花衬托海景，不用密树挡住视线。中央保留充分可移动空间，让纸怪的飘动本身形成场景活动。

远景按近崖、低处林冠、远海湾与海岸、雾中岛影组织。海岸需显著低于山顶，远处降低对比和饱和度；海面不应与草地同高。概念中的天空和水平线是气氛目标，现有游戏镜头能露出多少需在地形原型阶段确认，不能直接把概念当成镜头已经实现。

先从6张分散飘动的常驻纸怪体验起；数量、补充条件和离区重访节奏另调。保留入口的喘息空间，避免站在上山口就连续被撞。此处不引入团团混合遭遇、精英或Boss。

普通材料建议直接叫“纸张”，地面表现为两三片无表情的小纸页叠在一起，和仍有表情的倒地纸怪区分。击败后材料轻轻飘落、短暂回旋再接地，靠近拾取；先试每只1份的稳定收获，让第一轮收集容易判断。这个掉落初值、正式用途和配方消耗均未确认，尚未接入存档或奖励系统。

首轮落地只需验证：上山路径可读；当前镜头下确实看得出海岸在下方；纸怪与材料清楚可见；一次短收集有明确收获。普通遭遇可以轻松，但随后仍需检查不同搭配是否能改变效率与操作感。
