# 139：从136重新局部扩建

用户要求以136为基线，撤下137/138的地形重构。139直接继承136，不继承137/138；原版本文件保留，方便独立比较。

- 地图范围、网格起点、站台楼梯、山脚树林、原地形材质均沿用136。没有扩大整个世界边界、降低大片山地或增加地表剔除着色器。
- 山顶在原网格余量内扩大为约18×16米的草坪，并往西伸出小岬角。只开放对应的短段西侧隐形边界，其他边界不动。保留136原有远处矩形地表外沿，未用全局挖空方式去除；后续需要逐段补造自然崖缘。
- 山脚入口和上山两段转阶加转台共四处封闭石质基础，补足侧面和底面。撤掉这些装饰台阶的独立碰撞，以连续地形缓坡承载移动；上段楼梯通道独立保持平滑，避免草坪填高造成陡坎。站台楼梯维持136。
- 使用136的原始完整海景图，海面与岛屿一起作低幅视差，加轻微模糊与雾色。画面随相机铺满，取消136山顶附近突变隐藏边界，远离山顶后渐隐，不把海景铺到站台下面。
- 纸怪、团团怪、存档与掉落规则不改。
