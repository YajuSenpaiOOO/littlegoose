# 141：山树围坪、苔石观景口与世界空间远海

沿140局部改造，不扩大世界总边界，不回到137/138地形重构。保留140可独立启动对照。

## 参考《八方旅人》的查证与本项目判断

[Epic Games对《八方旅人II》开发团队的官方访谈](https://www.unrealengine.com/developer-interviews/octopath-traveler-ii-builds-a-bigger-bolder-world-in-its-stunning-hd-2d-style?lang=en-US)明确提到：背景几乎全用3D渲染，旅行时保持固定视角，部分事件使用3D运镜；团队用Sequencer编排事件镜头。其空间感有真实三维场景、灯光与镜头调度共同支撑。

以下是针对本项目的设计判断：令人印象深刻的观景过程需要近景遮挡、可辨别的中景、远景尺度与接近时的揭示节奏。仅让一张远景画在屏幕上小幅滑动，难以给出这些深度线索。剧情场景还可结合停步、环境声与音乐进入；这些不作为本轮已完成内容。

140海图每帧重新面向相机、跟随相机并按FOV缩放，相当于把图固定在屏幕构图中。141把整张图固定在约360米外的世界空间，位置、朝向、物理尺寸保持不变，投影移动来自实际相机运动。海与岛仍共用同一张图，没有独立漂移。向上/向下扩展绘制平面并连续延伸原图边缘颜色，避免观景抬头露出图片边框。依然不是能绕行的三维群岛；这一步是修正屏幕固定布景的行为。

## 山顶组织

- 取消围成一整圈的栏杆，留下三组短木栏作点缀；有碰撞的低石肩、东侧隆起山体、入口与边缘的树形成交替边界。
- 东北侧山肩局部抬高约3米，北侧偏西形成12.55米左右的可达苔石高点。中央活动草坪和既有台阶通道保留。
- 添加入口框景树、东侧山肩树与稍远处树，保持主海景开口。只在明确的边界点新增，不清理整片原树林。
- 高点由草地渐变为苔色和裸石，草簇逐渐缩短并从中心消失，材质使用现有手绘岩石。没有栏杆横在视线正前方。
- 140原先依赖整圈栅栏挡住视觉裁掉的远处余地；141拆掉大部分栅栏后，沿实际崖缘轮廓补阻挡碰撞，避免走到栅栏外保留的不可见旧地形上。阻挡跟随崖缘，不横穿观景台或中央草坪。
- `park99.sit_point141` / `FutureSitAndSeaView141` 预留以后坐下看海的叙事位置，当前不自动坐下、不锁控制、不接剧情。
- 靠近高点时镜头平缓后退、轻抬视角4.5度；射击或5米内有活敌人时渐退。离开后恢复正常相机，避免角度累积。

## 针对验证

`paper_hill141_probe.gd` 检查区域外高度/地图范围、短栏数量、观景开口、边界树、山肩高度、保留的封底阶梯、八方向完整上下山、从草坪走到观景点、落地、观景镜头稳定与射击退出、站台背景/相机。

最终17项针对检查通过，日志无脚本/着色器错误。远景运动用同一横移测试，对比固定近处坐标和远处坐标的屏幕位移：本轮近处约82.84像素、远处约4.89像素；同时确认海图世界变换与物理尺寸完全不变。保留14根木柱、11段短栏，新增6个明确边界树位。射击能平滑退回常规镜头，实际崖缘有阻挡碰撞。

结果写入 `paper-hill141-validation.json`，截图位于 `captures/world_restart/paper_hill141_*.png`；已核对中央草坪、接近高点、观景点、山脚与站台。树林后方右侧仍保留少量旧地表边角，需要后续美术收尾；这是新的空间与镜头原型，未把主观的震撼感当成检查通过项。检查本轮相关区域，不跑历史全量。

启动根目录 `preview_paper_hill141.cmd` 从山脚上山，F4直达纸坪；观景点在草坪北侧，沿草地走上苔石高点。F6六/十张纸，F5团团，F3回院。
