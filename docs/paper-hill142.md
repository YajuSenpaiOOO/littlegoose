# 142：山树分区、泥土观景口与草甸疏密

按用户三张141截图修正摆放、楼梯显示贴合和场景层次。仍保持原世界边界与网格起点，141入口保留对照。

## 具体修正

- 清理上山阶梯周围的树位，并撤掉141新增的入口/岩峰树。树移动到右后方独立的平土台地，三棵成组，小石头安排在树根附近；不再把树种在山峰上。
- 左下原树与低坑改为真实地形形成的较高岩石山肩，目标高度约13.6米；移除山肩上不自然的方石装饰，保留正常岩壁材质。
- 观景点恢复140的原有缓坡地形，取消141单独抬到12.55米的石台。地表改为泥土渐退到草地，接一条不完全裸露的踩踏土路。保留141走近时的平缓后退、抬镜头与射击退出。
- 楼梯物理仍由连续缓坡承载。`hero142.gd`仅在封底阶梯上按真实可见踏面调整角色显示高度（上限0.24米），避免脚踩进装饰台阶；不增加阻挡台阶碰撞或抬升物理身体。
- 新角色脚本继承原128角色，保留弹弓蓄力期间60%移动速度等既有规则。
- 原始楼梯、站台、山脚树林、远海世界空间定位与崖缘阻挡继续保留。

## 丰富度

单调来自多个尺度都太均匀。当前处理包含：大面积冷暖绿变化；中尺度草甸疏密；一条草间踩踏痕迹连接观景空地；六处边缘植物组，采用现有草簇、蕨类贴图与接地/受光效果。中央不堆大体积遮挡物。

树冠、山肩与土路分别构成背景轮廓、侧边体块和行走方向。颜色变化只作用于山顶范围，泥土使用已有手绘土壤素材，去除141的苔石刷面。
