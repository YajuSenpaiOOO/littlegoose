# 329 城堡受击纸屑

实现：`scripts/art/paper_hit329.gd`，运行时生成三种暖纸色的短小 QuadMesh 纸屑，无新增位图。城堡和炮台使用独立受击入口，原326默认仍用旧效果，327当前预览覆写为纸屑。

粒子根节点放在实际世界命中点，不挂城堡动画骨架；命中后独立飞散、下落，1.4秒清理。纸片尺寸约0.07–0.11×0.14米，以XY小平面和双面材质显示，随机旋转及纵向收展表现翻面。普通命中9片，破坏18片；同位置50毫秒内合并，最多12组。

这是短时视觉特效，无碰撞、不挡路、不发光、不投影，接受环境光。脚锚点/角色朝向不适用，不改城墙、炮台的既有占地和受击形状。不用于持久落地纸片或可交互摆件。

城堡试验血量48→72；炮台仍各5血，击破仍扣城堡8血。数值需实玩继续调。
