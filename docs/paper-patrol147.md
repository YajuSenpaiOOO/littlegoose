# 147：随机巡航与向下投弹的对照试验

2026-10-24。独立入口preview_paper_patrol147.cmd，默认三架巡航试验；F8随时切换146的瞄准投递。1—6仍切换原六套组合，6是直接弹弓，无飞机。Q仍翻阅课堂笔记。切换模式清理临时飞机、弹丸和笔记，不改地图、正式装配、配方或存档格式；常规默认入口暂保留146。

## 当前规则

- 左键放飞，蓄力组合仍按住再松手。初始飞出方向来自放飞时指向，之后在放飞点约5米内随机转弯、变速滑翔，不跟随玩家或自动锁敌；引怪到飞行区内是保留的站位操作。
- 放飞间隔1.1秒，所有直接与笔记重放的飞机合计最多3架，包括下降阶段。飞行3.8—4.8秒后停止投弹，0.75秒失速下落，贴近地面淡出并释放空位。不同飞机独立转向/高度/寿命，避免齐刷刷列队。
- 沿途从飞机当前位置附近向下投弹，随机小偏移，不按敌人位置修正。属性从当前装备重新取样：普通弹按基础0.34秒/射速，水柱按基础0.04秒/射速与决心加成；最低发射间隔0.05秒，每架每物理帧最多一次，不积压补发。
- 三架各用1/3当前弹丸伤害，满编合计约一份直接火力预算，未考虑随机命中损失、启动与补位空窗。蓄力飞机保留放飞时蓄力比例，周期至少1.1秒，避免把满蓄重弹按普通弹射速无限复制；实际威力仍采样当前增益。
- 原有穿透、分裂、音符与水柱标记进入原弹丸碰撞管线；多弹道形成小向下扇锥。未实现敌人追踪专属的三维下落转向，追踪行为沿用原管线，不能保证能补救随机覆盖的空射。
- 笔记只记录成功放飞，不记录沿途投弹。重放仍45%且共用3架上限；满额时排队等待，不丢弃重放、不强行替换原飞机。准备/暂停/切场/死亡使用原清理逻辑。

## 开销控制与局限

复用原弹丸对象池及原生碰撞，最多3架Sprite3D，无独立飞机物理体；新飞机无需新增位图。直接投弹与分裂共用256枚在场上限；高负载下跳过新的投弹、截断待生成分裂，不对所有玩家/敌人物理重复遍历。载荷寿命最多0.9秒；机上火力由当前攻击管线取样，暂时会先生成并回收取样弹丸，属于原型开销，后续若保留机制再抽离纯数据构建。

数量上限用于防止无界增长，不代表已保证目标硬件帧率。验证记录中的帧耗时包含整张场景、渲染与等待，不是独立微基准。未跑历史地图套件。

## 设计上要观察的事

1. 无额外主动键时，放飞方向、选投放位置、把怪引进随机覆盖区是否已经有操作乐趣。
2. 普通与高射速的覆盖差异是否自然；不预设快攻是唯一能搭配的弹幕，蓄力、穿透与分裂仍分别对照。
3. 若站桩放满后明显无事可做，再单独试“按住攻击指定大致巡航区”或召回；本版不自动加入这些操作，避免改变完全放手试验的前提。
4. 若火力明显不足，先区分覆盖命中率、三架空窗与伤害预算，再调数值。不能用最终Boss材料门槛替代机制是否好玩的验证。
