# 130：随风漂流与阵风弧线掠过

2026-10-23。沿用129独立纸怪试演与固定团团点，不做混合遭遇、正式材料或新地图。

## 纸怪

- 取消固定“追逐—落地站稳—直线扑击”，改为持续漂流、绷直预告、弧线掠过、余势滑行。
- 连续风场由缓慢变化的方向与风强构成，全场共享；每张纸有不同相位的局部涡流和上下浮动。速度按加速度渐变，保留惯性，不逐帧随机换方向；弱风/转向时自然减速舒展，不必落地。
- 飘浮目标高度约0.22—0.96m，低频摆动与轻翻面、速度相关侧倾；受击仍沿用短暂翻卷与有间隔的有限吹动。
- 每只按自身间隔等阵风。约0.65秒绷直预告时锁定玩家所在位置，随后约0.95秒沿二次曲线快速掠过，途中不追踪；结束后约1.1秒余势滑行，回到漂流。靠掠过造成一次纸边刮擦，漂流时贴近本身不扣血；可闪避、可弹反。
- 物理根节点仍沿真实地形移动并受障碍阻挡；地盘外缘有渐进回流、前方障碍引导转向，避免穿房屋或瞬移。没有扩展飞越所有障碍的导航。
- 命中区域和辅助瞄准中心随可见高度移动；追踪目标快照补上浮空高度。纸怪不再出现“图在高处而受击体还在地面”的错位。
