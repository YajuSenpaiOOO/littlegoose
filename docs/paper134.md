# 134：C撕页轻摆与鼓风攻击

2026-10-23。用户选定133的C撕页基础，B的弯曲程度用于动态；补充攻击应像降落伞一样被风兜住，中央向前鼓起，脸为`>ω<`。

## 素材与动画

- 使用内置image_gen，严格参考C，生成4个轻摆关键姿态，以及4个攻击/恢复关键姿态。保留左撕边、右上折角、下方折痕、淡蓝横线和粉色边线；不加手脚或伞绳。
- 轻摆使用0→1→2→3→2→1往返，每步约0.34秒，加上原有连续漂流/升降/侧倾。以局部卷边、纸面弯曲表现柔软。
- 蓄风：先绷直并换`>ω<`，后段开始鼓起。掠过：中央纸面明显凸出、横线随之弯曲、四周纸边后收，使用专门绘制的充气姿态。恢复：松风展开、恢复小圆眼微笑，再接轻摆。
- 充气使用实际绘制的纸面形变，攻击帧与预备帧像素比例相同，不通过全身放大冒充鼓起。保留动画中的轻微惯性侧倾与受击翻卷。
- 原C保存在base_C.png，用作形态基准与当前倒地静态图；本轮未扩产专门战败动画。

## 接入

`assets/paper134/animation.json`记录每帧纹理、像素比例、可见尺寸和中心对应脚点。每组用首帧统一像素比例，视觉中心共享固定基准，避免卷曲时因逐帧缩放/脚点变化跳动。原软体/昼夜/透明渐隐与轮廓影采样当前动画纹理。

保持132纸片无友军硬碰撞与软避让、131气流侧翻/可靠掠过/高处判定和六十张对照。团团仍128，无新增材料、配方和地图。

入口`play.cmd`确认134；F4纸怪/F5团团、1—4换打法、F6六/十张。`preview_paper134.cmd`直接纸怪。
