# 135：左右鼓风与纸张落地

默认 world135；preview_paper135.cmd 直接打开独立纸怪试演。沿用 1—4 组合切换、F6 六/十张、F5 团团和 F3 回院。没有增加混合遭遇或正式材料奖励。

攻击按相机画面左右选择两组四帧姿态。右向图重新绘制纸面鼓起方向，保留左撕边、粉色边线与右上折角，没有整张镜像。蓄势开始锁朝向，弧线掠过和松风时不突然翻转；近乎垂直的攻击保留上一朝向，暂不做上下方向素材。

击倒后换为扁平的 >口< 纸张，沿原落地计时下降，轻微摇摆逐渐停止，随后继承 2.8 秒停留与 1.25 秒淡出。摊平透视绘制在图片中，未用额外缩放把纸压成线。非死亡轻摆、受击命中和纸张相互穿越逻辑保留。

素材由内置 imagegen 生成。来源与提示词见 art/paper135/；运行素材与锚点在 assets/paper135/。原134版保留。
