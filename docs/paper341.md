# 341：角度反弹与分裂光束连续性

入口89/boss314，world314继承341；169与历史预览不动。未改144/16耐久、技能伤害、射速、分裂数量和寿命。纸飞机对城堡的适用范围按用户确认保持。

## 用户确认的反弹规则

弹力球碰撞时按真实法线反射，取消275敌人/地面与340结构的即时选目标。保持原弹、原速度、一次70%伤害、结束贯穿与反弹后不再分裂。眼保健操使反弹后的弹幕按原2.5/4弧度每秒逐渐转向，沿用前方视锥与距离限制，支持纸偶、炮台和城墙；遮挡与同结构Area/StaticBody忽略保留。不从背后瞬间折向目标。城墙卡片受击盒朝相机倾25°，墙面反射使用XZ玩法法线，避免因贴图朝向把弹幕弹上天；地面法线保留上下反弹。

## 连续分裂光束

旧234对每一个分裂采样点都分配全新generation、sequence=0。263绘制器只能将其当作独立短线，手电连续命中产生大量分散短光束。

341给分裂队列保存父光束代号、原序号及分支序号。相同父光束的相同方向共享generation，保留采样序列，子分裂追加路径；不同方向/不同父光束隔离。每条分支从真实分裂点接出，仍由263现有折线、间距断开、24点采样与批量三角带绘制。停止、换装、重开清理映射；伤害、物理采样和射线照旧。
