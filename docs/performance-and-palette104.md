# world104 瞄准缓存、阴影预算与林荫色层

2026-10-21。以 world103 为底，不改地形、台阶或物件数量。旧版本和入口保留。

## 实际改动

- 地面瞄准原来每次做18次完整地形公式求值，鹅朝向和准星重复请求。现在用已有碰撞网格的三角形插值高度，并按鼠标位置、相机变换/FOV、视口、地形开关和地面网格身份复用结果。敌人身体命中仍逐次查询。缓存未就绪时走原实现。
- 太阳原70m四级阴影改为42m两级，保留近景树影、根部影、植物受影。Ctrl+Alt+Q 切回原阴影预算对照。没有关闭全图阴影或移除远景。
- 继承原89材质、受影与光照场，在林地范围内压低黄绿、略降饱和；林缘与前景偏冷暗，空地保留暖亮；局部裸花茎白花偏淡紫。纯材质计算，没有新增灯、网格或逐帧贴图上传。夜晚自动退回原色层。Ctrl+Alt+B 开关对照。
- 近身草声继续默认关闭，鸟鸣等保留。

## 验证

默认入口启动通过（约30.4秒），最终回归、A/B性能、昼夜渲染与默认启动日志均无错误/警告。65项原场地及新增瞄准回归全部通过。包括2670个施工区外高度对照（差值0）、原车站和小院高差、实际走台阶、秋千碰撞/摆动/衰减、松果、拨叶以及三波战斗。九个地面投影目标最大瞄准误差0.000041m；鼠标/相机变化会重新求解。详见 woodland104-validation.json 和 woodland104-validation.log。

性能对照记录在 woodland104-ab.json 和 woodland104-ab.log；脚本为 scripts/world/woodland104_ab.gd。单进程、2560×1494、Compatibility、RTX5060 Laptop、关闭垂直同步，鼠标放屏幕中央。模式0为旧瞄准/原70m四级阴影/色层关；模式1只改瞄准；模式2为104默认。静止180帧、来回移动240帧，旧/新顺序重复，再进行战斗旧/新重复。短样本不代表整图长时间最低帧率，战斗AI位置和系统负载也会影响结果。

## 后续美术方向

这次先改善大面积相近黄绿造成的平铺感。参考图仍有更高的俯视角、更明确的多层地形和建筑/水面等叙事焦点；颜色调整不能代替这些结构。下一步应围绕既有观景台、树下秋千和入口的三段空间分别深化，避免把战斗留白全部填满。需要继续观察实际游玩时的偶发长帧。

play.cmd 或 preview_woodland104.cmd；Ctrl+Alt+F2 游园、F3 秋千、F6 林缘入口。关闭旧游戏窗口后重新启动。
