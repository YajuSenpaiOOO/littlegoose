# 25°透视 · 三维底座试验 07

用户明确原本想象的是 25°透视镜头，因此新建独立可玩场景 `scenes/sandbox/perspective_playground.tscn`，根目录 `preview_world_3d.cmd` 启动。主世界入口仍保留二维版本，06 的正交投影样板也保留对照。

## 已实现

- 真正 Node3D 世界、Camera3D 透视投影，光轴向下 25°，垂直视野 42°，默认跟随距离 22 单位。镜头跟随人物及其实际高度，使用物理帧更新与插值；滚轮沿光轴移动镜头，自然产生近大远小与不同深度的相对移动。
- P 可切正交：在人物所在的观察平面上匹配参考尺度。相机角度固定，不支持自由旋转，不假定所有平面素材能适应任意视角。
- 二维人物动画转为鞋底锚定的 Sprite3D；保留四方向动画。人物使用 CharacterBody3D 胶囊与重力、地面吸附，沿真实地形移动，不通过手动设定地形高度伪造上坡。
- 地面是含右侧 1.6 单位高台/缓坡的三角网格，纹理来自旧版详细地皮和土路。三角面碰撞与摆放植被所用高度一致。
- 房屋为有厚度、屋顶与侧面的简单三维模型；树使用既有二维试验树，实际树干碰撞。人物、树、目标使用简单隐藏体块提供方向投影，另加人物薄接触影。不是整张贴片直接压成影子。
- 900 株草使用一个 MultiMeshInstance3D、一个材质、四个图集变体。风动和局部接触/八条短期轨迹在顶点 shader 中实现；无每株脚本、物理体或逐株 CPU 查询。范围外仍有绘制和简单顶点计算，不宣称全图铺满无成本。
- 鼠标从相机发射实际三维射线选取目标/地面/障碍。子弹在三维中飞行，每物理帧用线段扫掠检查目标、房屋和地面，不使用屏幕二维距离判伤。
- 遮挡树贴片用屏幕网格抖动淡出；房屋通过实际相机至人物的障碍射线判断后淡出。实体碰撞保留。
- 相同尺寸的三根参考柱位于右侧不同深度，专门展示透视差异，未按距离手调缩放。

## 操作

WASD/方向键移动，Shift 快走，左键射击团团，滚轮调整镜头距离 13–34，中键恢复 22。P 透视/正交，C 跟随/冻结，F 遮挡淡出，G 草，O 方向影，F1 隐藏说明。

1/R 回小屋路口，2 到右侧坡脚（往上走上坡），3 到草地，4 到远近参考区域。Esc 退出。

## 验证与边界

`scripts/perspective_probe.gd` 实际 OpenGL 运行 14 项通过：三维角色/镜头、25°、真实落地、参考柱透视差异/正交等大、屏幕射线选中目标、子弹命中、长步长墙体拦截、真实上坡与下坡、跟随高度、900 株批量草、遮挡淡出恢复。

`scripts/perspective_grass_probe.gd` 固定镜头/风相位、隐藏人物，以实际渲染比较局部接触：最终光照下 130×130 区域变化 621 像素，移走后恢复差异 0。保存 rest/pressed 图像。此数值描述变形验证，不是性能基准。

截图在 `docs/captures/world_restart/perspective07_home.png`、`perspective07_orthographic.png`、`perspective07_slope.png`。结构与体验试验，不是最终美术：树和小草仍来自此前样板，房屋是简单模型，颜色/纹理密度/贴片与实体的光照一致性仍需调校。旧版完整战斗、技能、存档、剧情未迁移；未经全地图规模性能测试。

当前方向允许三维空间管理坡面、碰撞、射线和镜头，继续使用二维绘制资产。大房屋/岩岸可用简单模型承载二维材质，不能指望一张带透视的整图从任意位置看都正确。正式生成资产前应以本场景的透视镜头截图作构图与比例参考，而非继续只用 25°正交标尺。
