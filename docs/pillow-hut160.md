# 枕头搭的小屋 · 160 三秒可返回据点

按试玩反馈，取消30耐久和70%减伤，改为在开口内完全免伤，提供确定的反击时间。

占1格，试玩免费开放一份。静止右键蹲防0.45秒搭建，提前松开取消。完成后固定存在3秒；松开可射击、蓄力、Q笔记。图像宽从2.55米放大至3.6米，保护区为相机水平朝向的椭圆，半宽0.60米、半深0.42米，即整图中间约1/3。淡地圈表示真实保护范围，两侧枕头不算安全区。

窝内通过真实hurt_player入口完全拦截伤害，不进入旧的受伤、击退、短暂无敌或死亡流程，不消耗耐久。命中触发左右阻尼摇晃及轻微挤压。避免在高频受击时频繁重置动画，视觉触发最短间隔0.08秒；伤害仍逐次拦截。原本完美弹反仍先于受伤入口处理。

离开开口或闪避不会收起；窝外不受保护，回来重新生效。倒计时从搭建完成起连续运行，进出、受击均不刷新；被击倒或时间到收起，从收起时开始冷却10秒。期间不能重搭，且需松开过防御才能再次搭建。暂停冻结计时；切换组合、重开和清场清除小屋。搭建阶段依旧是原蹲防，没有提前无敌。没有物理墙、回血或敌人伤害。

最后0.6秒小窝渐渐压低、向两侧松开，地圈变暖色并提示准备离开；最后0.12秒快速淡出。保护持续到3秒结束，计时结束立即隐藏小窝并停止免伤，无额外的失效后残留影像。结束提示不受相机位置或往返影响。
