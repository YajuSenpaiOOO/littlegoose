# 49：小屋门口体积与林荫暖院样板

2026-10-18。基于 world48，玩法仍继承 world40。用户认可暖院光照方向；认为浅体积楼梯诡异，该处理已撤销。后续不要恢复此楼梯切片方案。

入口：根目录 `preview_world_garden.cmd` 或 `preview_world_garden49.cmd`。窗口标题“小白鹅 · 暖院样板49”。

- Ctrl+7：48 原版（含48已存在的近景层次与窗灯柔光）。
- Ctrl+8：屋檐/横梁下与墙根暗部。
- Ctrl+9：林荫暖院，当前默认；暖亮区域集中于门口与院内，周围草地、树木、木柴和矮墙进入更深的带颜色的阴影。
- Ctrl+F3 仍近看菜园；其余操作沿用原版。

房屋使用完整的 `assets/house16/slate.png`，源 PNG 未修改。已删除门阶浅浮雕网格与对应 shader 裁切，保留原图楼梯透视和形状；新增墙根暗部避开楼梯区域。房屋主体和屋顶仍为原立牌。

庭院明暗使用世界坐标计算的固定树冠开口，是手工美术布光近似，不是真实动态树冠遮光。相同函数作用于地面、草、树和旧摆件，强度在家附近淡出；不加全屏雾。材质包装复用原 shader 的风动、透明淡出和参数，缓存 shader，按淡出状态切换；未增加灯光阴影贴图。

主角只有轻微暖色适配，保留受伤红闪；没有改轮廓、贴图或动作，也没有重复叠加脚底影。沿用 Compatibility、原石板、2.65m灯和已认可景深。

检查：`scripts/world/porch49_probe.gd` 使用真实 OpenGL 渲染，验证同机位对照/恢复、完整房屋贴片且不创建门阶几何、院口通行、第一波战斗和受伤反馈；渲染正面、侧移与门前机位。截图在 `docs/captures/world_restart/porch49_*.png`，结果见 `porch49-validation.json`。这些检查确认运行与画面发生变化，美术是否改善仍由用户验收。
