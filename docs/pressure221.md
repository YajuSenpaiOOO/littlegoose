# 221 · 肥猫晚锁定与有限追滚

用户认为220滚不中、肥猫像活靶子，询问是否应取消预告。核对220代码：可在7m范围开始滚，却只有4.6m/s×.96s≈4.42m行程；起手即锁死方向，并等待.8s，主角正常4.1m/s移动就能离开。220单轮还包含2.8s追逐等待和1.35s恢复，追逐只有.78m/s。

221为独立试验，不覆盖220。world221复制220场景控制，只换fat_cat_boss221继承220显示/受击/修补接口并覆盖移动逻辑；沿用素材、207光照/199脚点深度、105影子、.95m半径物理占地、主角192、血量120/蝙蝠32及接触12/滚动22伤害，不增加血量、霸体或伤害减免。

- 首段.5s蓄力，前.32s仍可瞄准；末.18s锁定方向，地面带只在承诺后显示。速度预测使用实际主角位移的低通估计，最多提前.75m，瞬移剔除，滚动开始后不改变方向。
- 速度9.5m/s，按晚锁定时的距离+3m取行程，限制4.5—9.975m，时长约.47—1.05s。追逐时8.5m内可发起，而不是近战才能启动。
- 首滚正常走完且落空、实际行进>1.5m、主角距离1.6—8m时可再滚一次，补段.32s蓄力，仍末.18s锁定。最多两段；碰墙/断面/主角实体/弹反会停止，不无限追踪。
- 恢复1.1s，追逐间隔1.35s，慢追1.1m/s。仍明显慢于主角步行，主要通过滚动缩短距离。
- 锁定时用真实物理胶囊的cast_motion探测地图可走距离，只在0/±.35/±.65弧度中选较通畅的接近方向。查询不改变任何碰撞；实际移动仍是move_and_collide，不能穿地形、树根或摆件。贴地预告截到碰撞距离，遇高差断开，不重开树避让。
- F8切换地面预告显示，完全不改时序、锁定、速度或伤害，身体蓄力保留。根据用户实玩反馈，默认预告关；F8可重新打开对照。

猪猪/姐姐/修补/蝙蝠与原生武器沿用220流程；本轮只做威胁节奏，不重画动画或扩大正式进度。滚动还是217六个关键姿势，非真正纵轴滚动/四向定稿；原型朝向与前景遮挡的限制见plush-boss220.md。新预告更短且有第二段，强度是否合适需用户实玩，不能由命中测试决定。
