05 最新要求取代此前“环境跟随主角简化”的目标：旧版细节地皮 + 从地表长出的可穿行短草/高草 + 有对比厚度的光照，人物保留立牌画法。先核对统一视角（35° 是试验候选，不是已执行的全图摄像机设置），再做一组草叶/高草及少量花；用一棵树与房屋白模同步核对比例，不先制作全套草花，也不继续扩产树。详见 direction-and-view-05.md、asset-view-contract.md。

1. 在同一坐标系按全景参考重建小屋、林地、湖岸、桥与车站的布局。正式角色检验距离、道路和镜头。目前已完成可运行草稿，五条路线通过碰撞检查；空间比例仍可修改。
2. 在全图中重做小屋—北侧路—中央岔路，统一地表、物件尺度与林缘层次。美术样板 03 已生成草地、土路和阔叶树，在小屋周边六个可编辑树实例中验证脚点与真实树根碰撞；尚未通过美术验收。先评审这一组材质与树的方向，再制作不同轮廓的变体和道路组景。
3. 使用固定实机镜头对照参考，先评审大色块、房屋/树/角色尺度、开阔与围合比例，再补生活细节。参考改稿以实机位置为约束，不任意重排道路和岸线。
4. 第一段通过后，再扩展西侧林地、东侧湖岸及北侧车站的精修。自然高差、石壁、台阶、岸边植被、水面与局部灯光按同一风格完成。
5. 战斗/剧情按区域逐项迁移，保留接口语义并重新安排地理触发，不沿用旧地图坐标。进行正式玩法空间与性能验证。

保留 departure 已验证的光照、脚点和排序组件。免费 tile 与生成资源都可采用，以实机材质尺度和整体一致性决定；不把免费素材作为必须遵守的风格。新生成资源先小范围验证，不在尚未认可时批量生产。
