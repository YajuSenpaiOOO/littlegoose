# 232 连续剑雨与气球剑合批

用户反馈：气球剑+眼+三鹅比再加飞机更好，飞机纯负收益，后半段仍卡。以231真实原生对照确认：直射猫4.72DPS、六秒主蝙蝠28.35；飞机猫4.37DPS、主蝙蝠16.32/另一只7.50、首击约1.3秒。不是简单漏继承，多出的1槽主要换来了延迟/分摊/更贵显示。

## 当前试验

- 新paper_rain232继承230，单鹅仍六投、总范围2.4m、保留区域分配/直落不横追/全部载荷属性。三个内圈样点表达标记核心，三个外圈样点保留范围；重复分配惩罚.5→.1（230默认仍.5，新232覆盖），不强制均分两只蝙蝠、不把六发锁死同一只。命中点按真实半径内小幅散布，上限.28m，仅改变物理落点，不加小体型伤害。每架约1.25秒退出，快速到场后沿标记区扫过，六投间隔固定.09秒，约.45秒铺开；各鹅错开.025秒。旧版约.15秒内投完后等待，不能形成连贯剑雨。
- 给纸飞机本身明确的1槽收益：投递载荷伤害乘1.25，包含普通/蓄力/光束/分裂/气球剑及笔记回放，六份总预算只乘一次，不增加放飞频率或弹数。这是公开的临时平衡试验，不把设计改动称继承bug修复。C说明与记录rain232均载明25%。
- 新balloon_sword232保留原生shot/trace/hit/三秒附着/五层40%减速/胶垫/回弹/黏附随动/淡出/投影/反馈音；把显示换成刀身、胶垫、刀影、胶垫影四个MultiMesh。飞剑和残留仍逐项变形、位姿和生命周期，160残留上限不变；768容量覆盖512 shot+160残留，不丢物理更新或为显示数降伤害。普通直剑也用该批次显示，伤害数值保持。
- 刀身保留原4x28细分，投影用与旧版相同的九点网格，复用227地形三角形/桥/支撑采样与143海岸裁切。没有去掉胶垫/影子/场景摆件。世界效果分级沿159全局色。
- GPU验收暴露附着点被肥猫脚点深度代理遮掉：对已有attachment_frame154且带199材质的猫/蝙蝠，把附着点沿视线映到同一脚点深度平面，再前移.025m；刀/胶片元只在该标记下使用接触点竖直代理深度。飞剑/普通地面剑保留原深度，始终保留场景深度测试，不是盖在所有图层上。真实日/夜截图与去掉命中点特效后的710个青色刀身像素验证可见。
- coastal_breeze143仅补识别marker_terrain227 include：Shader.code未展开include，旧检测误以为未声明terrain而再注入同名uniform。先前初版重复声明导致投影编译失败，已修且最终日志无shader错误；初版数据不能作性能验收。
