# 姐姐战逐场记录（227入口，226统计基类）

C选择碎片和血量，然后点击「开始记录 · 用草稿重开」。每一场独立JSON自动保存到user://boss_records，面板「打开记录目录」直达。普通重开归档当前采样，下一场需要再按开始记录；中途应用按中止保存旧样本，不拼接新组合。取消草稿继续原样本。

## 统计口径

- 计时是未暂停的游戏时间，不含敲门/空运入场。猫阶段包括追逐/蓄力/滚动/恢复，蝙蝠阶段仅低空repair窗口；降床/升空计整场时间但不计阶段分母。
- 伤害是实际扣血（上限为剩余HP），不计溢出；猫会多轮满血修复所以总伤害可能高于一轮HP。猫和蝙蝠分别除各自可攻击阶段时间；整场DPS同时包含升降等待。
- rounds保存完成的每轮猫，current_cat_round_*保存未完成轮；windows保存完成窗口，current_window保存进行中窗口。每轮/窗附dps。
- attack_input_seconds是攻击输入成立时间（含蓄力/冷却），不是命中或成功出手时间。mode只是用户标签，「站桩对照」不会自动操作、无敌或停猫。
- 命中事件计数不代表弹丸数；手电持续多段、飞机投递、穿透等分母尚未统一，accuracy明确为null。没有宣称记录可靠命中率。
- 记录移动、闪避次数、防御时长、伤害来源、自动开火时长、猪开关变化与帧质量，供解释DPS差异。超50ms帧为粗指标，不是性能剖析。F9/F10伤害沿用排除和debug标记。
- 每5秒保存当前样本，结束/中止/重开/换装/正常关窗口归档。强制杀进程最多丢最后5秒有效游戏时间，进行中结果不伪装成完整结算。
