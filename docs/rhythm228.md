# 228两段节奏试验 · 2026-10-30

## 目标与入口

用户希望姐姐战保留高压与剑雨特点，同时经历清楚的变化，避免常驻输出11—22秒普遍结束。228独立继承227，统一启动器最新为228，菜单19保留227。没有强制第二轮/锁血/全局限伤或固定战斗秒数；爆发仍可第一次修补直接获胜。

本轮只实现战斗节奏。上一轮确认的飞机落点局部修正/弹幕追踪尚未实现，没有将投递改为集中锁死同一蝙蝠。

## 流程变化

- 第一轮：肥猫只单滚；蓄力.65秒，滚后恢复1.6秒，再追逐1.8秒才准备下一次。仍保留原晚锁方向、9.5滚速、碰撞、弹反和接触伤害。初次准备等待1.6秒。
- 修补：原1.3秒下降→6秒可攻击蝙蝠→1.2秒升空保留。原猪猪/棉絮清场之外，网垫与丝团也清；活着的小蜘蛛切回贴地idle、停物理和攻击、退出辅助瞄准/弹丸碰撞，给予瞄准蝙蝠的安静窗口。没有玩家回血或额外全局无敌。
- 第二轮：修好后2秒再允许叫一只8HP织网蜘蛛（原227是在第二次修补才叫来）；猪投放至少等4秒。肥猫可接第二滚，主蓄力.55秒/追加.4秒，恢复1.3秒、追逐间隔1.6秒，伤害不升。
- 错峰：猫已经蓄力/滚动，猪不新投、小蜘蛛不新起织网；织网/开心收尾时不开始新的猫滚动、不新投猪；猪在途/存活/棉絮未清时不新织网。已有攻击可自然结束，不能理解为所有危险绝对互斥。现存网垫保留走位压力，最多2块。
- 小蜘蛛被打倒不再补刷；后续猫倒下则再次清网/停手；复起恢复原存活小蜘蛛。重开/退出沿原227清干净所有支援与网。

## 试验数值和配置

猫100（沿人工测试），单蝙蝠80（原32）。调整的是短反击目标的总预算，使常驻输出通常有第二轮；不是把肥猫本体加厚。滚4/接触2/棉絮1、14决心、6槽和碎片数值均不变。低血手电/舞台等仍可更快，试验不强制等到第二轮。

独立user://boss_balance228.cfg与plush_boss228_preview.cfg。首次仅从旧boss_balance226.cfg读取已选碎片，不复制旧100/32HP；后续C保存只写228配置。原227与既有人工样本保持可对照。C开始记录沿原功能，报告新增rhythm228事件（首轮/猫倒下/反击窗/再出击/支援/织网/猪投放），便于分段观察；中途换装仍标partial并重置事件片段。
