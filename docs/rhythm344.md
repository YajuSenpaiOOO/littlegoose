# 344 城防错拍配合

入口89/boss314，world344继承343。只换攻击调度，144/16耐久、伤害、半径、速度、炮台重建时间、完美闪避/弹回与技能联动保持。无新美术/碰撞/角色改动。

## 时间线

开场仍单门蓄力重纸弹，完整1.15秒预警，教学/热身一次。之后循环“扫射＋逐发迫击 → 缺口环＋延后重弹 → 有序流星”。本轮用固定组合顺序建立可读节拍，替代336单招抽袋顺序；具体主攻炮由原公平轮换和可用炮决定，不随机改速度/落点/预警。

- 扫射为主：沿原固定扇区往返，25发/.16秒、.8秒预警，不追踪。副炮在扫射开始后的.9/1.75/2.6秒各发一发迫击，每发出膛才标定当前主角位置，飞行1.65秒，已发不追。预计落地与往返扫射中段/回扫相交；副炮没有额外散射。
- 缺口环为主：单次21纸屑/留3槽缺口，原.5秒提示。副炮在开始后1.3秒才开始蓄力，完整蓄力1.15秒，因此重弹出膛距环发出约1.95秒；保留弹回规则。取消旧散射阶段连续多轮小花样，优先让这次配合可辨认。
- 流星继续4枚/1.45秒间隔，飞行1.4秒，不叠其他炮击。
- 阶段最短预算4.8/6.4/5.8/6.8秒，预算结束还要等本组炮弹/光效散去，再留.85秒喘息。只看炮击队列，不承诺纸偶也静止。城堡始终可打，喘息不提供额外增伤或无敌。

## 压炮收益与生命周期

副炮瘫痪取消它未出膛的迫击/未开始的重弹任务；主炮瘫痪取消主扫射/待发环，也取消尚未发出的配合任务。已经飞出的副炮弹不凭空消失，沿用原规则。只剩一门时只做主招，存活炮不继承副炮工作。原7秒回收/折纸重建保持。清场、击败纸偶、重开通过原interrupt/clear流程清理待发任务，避免切阶段后幽灵出招。
