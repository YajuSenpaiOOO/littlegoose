# 50：沿道路自动生成林荫与暖亮开口

2026-10-18。小院到中央岔路的第一段样板，等待用户视觉验收；49认可的暖院与完整楼梯保留，玩法继承40，保持Compatibility。

## 试玩

根目录 `preview_world_lighting50.cmd`，Ctrl+F4 直达林路，Ctrl+F3 看菜园，F3 回小院。

- Ctrl+7：49暖院原版，林路新增光照关闭。
- Ctrl+8：林路柔和，新增光照强度0.6。
- Ctrl+9：林路明暗交替，默认强度1。

沿小院道路往林口和中央岔路行走，人物、草地和树干共同经过亮区和林荫；光区固定在世界中，不跟随镜头。没有恢复已拒绝的门阶网格、灰雾或光束薄片。

## 复用方式

`assets/lighting50/warm_woodland.tres` 是可复制的美术预设。指定道路名、随机种子、亮区间距、长短半径、横向偏移、林荫颜色、阳光颜色和人物响应强度；不用逐个给树/草/石头设置光。可选 `accents` 为重点位置添加亮区，四个数依次为世界X/Z、长短半径。

`route_light_baker50.gd` 读取道路曲线，沿距离布置大小和位置稍有差异的开口，并预生成320×320的数值纹理。当前自动生成4个开口，小院附近通过遮罩淡出，保持暖院方案。相同预设和道路可复现相同布局。

运行根目录 `bake_world_lighting.cmd` 重新生成并导入默认图。道路改动或预设改变后重烘焙即可；没有在游戏启动或每帧重新生成。复制预设后，可通过以下参数生成另一条道路的图：

```
bake_world_lighting.cmd --palette=res://assets/lighting50/another_palette.tres --output=res://assets/lighting50/another_route
```

控制组件 `route_light_controller50.gd` 的 `palette_path` 与 `atlas_path` 可替换为新的预设和图。当前世界接入一张林路图，尚未给全森林所有道路批量布置；大范围多道路可扩展合并到同一图。

运行时，接入的表面每片元在作用区域内多采样一次纹理，不新增点光源、阴影贴图或逐植物CPU更新。人物用同一分布图的双线性采样保持明暗一致，保留受伤红闪。shader继续缓存并沿用风动/遮挡淡出；未做跨设备性能保证。

这是可控的手工美术布光近似。自动生成负责基础节奏，不分析真实树冠是否遮光；移动树木后不会自动重算太阳遮挡。原有真实投影继续存在，重要地点仍需少量人工查看与调节。颜色、强弱和重点亮区属于需要美术判断的部分。

## 验证

`scripts/world/route_light50_probe.gd`：15项检查通过，包含固定种子复现、不同种子产生不同布局、同机位开关/恢复、房屋中心不变、人物明暗响应、小院到林路实际行走、首波战斗及受伤红闪。结果 `route50-validation.json`，截图 `docs/captures/world_restart/route50_*.png`。
