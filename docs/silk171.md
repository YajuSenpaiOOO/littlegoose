# 171：小蜘蛛搓丝团、推球与屁股墩

2026-10-25。用户试玩170反馈：小跳可爱，但远距离大跳仍引起真实蜘蛛扑食联想，且与团团重复。用户认可丝团方向并授权实施。本版不再有蜘蛛身体扑击，保留小跳换位，主要威胁来自可打散的丝团。

独立入口 `preview_silk171.cmd` / world171；普通play默认仍world169，170保留作为对照。不改森林地形、解锁或正式经济。

## 动作

在7米内、同高度且无遮挡时申请错峰出手：1.15秒搓丝团→0.30秒推球（推球开始0.08秒后放出一次）→1.35秒坐倒恢复→短暂停顿并至少小跳换一次位置。准备时锁定方向，之后不追踪；身体无接触伤害、不发动大跳，无旧落点圈。普通小跳仍受气球剑减速，不增加逐弹闪避。每只24血，默认3只，F6切换1/3只。

搓球、推球、坐倒和独立丝团由内置image_gen基于用户选中的B形象制作；常态/小跳沿用170。原始透明sheet、拆帧、元数据和完整提示词在 assets/spider171/，制作脚本 prepare_spider171.gd。程序只补搓球摆动、推球倾斜、坐倒回弹和轨迹，未制作逐腿骨骼。

## 丝团

- 从蜘蛛前方0.85米放出，固定方向直线滚动，速度2.25米/秒，最长4.6秒；碰墙/阻塞提前松散。外观宽约0.82米，不跟踪。
- 一次有效弹丸命中即可打散，仍通过真实Area3D与原生弹丸追踪结算。按用户反馈补普通方向辅助：指针指向丝团或位于其方向附近时纳入该次辅助查询，获取锥0.22弧度、保留0.34弧度，沿用原有遮挡/距离/命中高度/提前量；不把球永久加入enemies，因此不改变场次/飞机自动选敌/追踪弹列表。指向偏离的蜘蛛时球不抢目标，破坏/移除球释放锁定。飞机仍保留原地面标记操作。
- 碰到玩家走正常hurt_player，10伤害，每球最多一次；已有闪避/小窝等免伤流程保留。弹反窗口碰球可拆散，无新增弹反连击奖励。
- 失效后0.45秒缩扁淡出并散出短丝线，无爆炸、范围伤害、束缚或落地蛛网。
- 最多8个在场丝团（含松散中的），超过时回收最旧。换装、重开、切纸/团团、散场、失败和回院清理。丝团不增加蜘蛛击倒数、材料、场次或击杀统计。
