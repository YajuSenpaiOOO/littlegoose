# 58 纯聚光对照与氛围阶段收束

入口仍是根目录play.cmd，默认world58。Alt+4看夜景，Alt+B循环“仅舞台聚光”（默认）、“仅随身补光”、“两者叠加”。Alt+L仍单独切换聚光，Ctrl+U仍切换随身补光；右侧文字显示实际状态。Alt+F/H的萤火虫/远景空气、昼夜和睡觉规则不变，地形、桥和水面本轮未修改。

## 聚光分离

默认关闭52/54留下的随身OmniLight、fill_strength和额外人物增亮。也移除57叠加的人物stage乘色增亮。保留舞台聚光的实际地面照明和同一聚光开启时的人物受光分级响应，关闭聚光时这些响应一起取消。人物不另行自发光，三个灯组共用同一镜头、色彩与环境。

上一版以斜放透明片模拟光路，遇到树、房屋及其深度时容易出现单侧细边。本版停画旧光束片，在既有后处理中计算局部锥形空气光：从视点沿深度方向，在光锥包围范围内取10个样本，按与光轴的距离软衰减，并在场景表面停止积分。上下渐淡，无硬边线，不额外增加全屏绘制通道，也不增加阴影灯。灯移到主角正上方略靠前，聚光范围仍为21°，能量5、范围10m。

这是兼容渲染器里的局部空气光近似，不是全场景体积雾。粗采样和前景透明物的渲染顺序仍是其限制；后续只在具体画面发现问题时再修，不借此无限扩大氛围系统。

## 近景景深

现有后处理已分别计算near_focus与far_focus，按距离焦平面的远近决定模糊，而非按屏幕上下半区。58没有提高景深半径；只增加测试参数near_blur58以隔离验证近景支路，默认1。相同镜头下关闭它，实际前景像素变化278312个，主角中心20×20像素区域保持清晰。透明树冠的个别边缘还可能受渲染顺序影响，不能据此保证每一片树叶都采用相同模糊。

贴镜头的框景树叶可以更虚，脚边可通行的草、台阶和战斗提示仍应清楚。当前已有近/中/远层次，暂不增加全屏模糊。

## 验证与后续优先级

`spot58_probe.gd`的15项检查通过：默认纯聚光、旧随身光能量0且不可见、旧光束片不绘制、光锥左右均改变实际像素（三种灯组保持同镜头）、人物受伤反馈、白天无随身光、近景景深及焦点清晰度、固定32槽萤火虫和原人物投影。结果`spot58-validation.json`。截图`docs/captures/world_restart/spot58_*.png`。

`spot58_performance_probe.gd`按同镜头、夜晚、240帧/档比较纯聚光/随身补光/叠加/纯聚光，结果`spot58-performance.json`。局部光锥增加着色计算，不能因没有新增绘制通道就称为零成本。

本机两段纯聚光中位帧耗时12.43/11.82ms，P95为16.30/15.19ms；四档共960帧未出现超过33.3ms的帧，最大23.10ms。各档有运行顺序/热身噪声，不把叠加档较快解释为叠加成本更低，也不作为所有机器或长期无卡顿的保证。

氛围现可作为阶段基线冻结，待用户选择灯组。下一步建议先打磨桥的轮廓、桥板/栏杆材质与落脚关系，再做湖岸过渡、水深颜色、简化倒影及低频波纹；比继续加滤镜更能解决场景风格不统一。当前桥还是world19的网格桥面和方柱横杆；水面shader主要是双色混合及正弦波纹。后续可保留已有通行/碰撞骨架，独立替换视觉，并在既有四时段中验收。此处是优先级建议，本轮未开始桥水改造。
