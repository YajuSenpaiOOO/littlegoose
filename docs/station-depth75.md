# 75 站区纵深、短前阶与侧向石阶

2026-10-19。根据用户反馈：轨道到地图边缘即可；广场宽度够、纵深不足；前楼梯过长；裸露断面突兀，考虑石墙与侧向楼梯。

## 本轮结构

- 站区宽度保持40m，铁路向北移12m，前广场保持原前缘。可铺装纵深约15.6→27.6m；连铁路肩的站区预留由约22.8→34.8m。没有再抬一块独立地形，后方仍接同层铁路高地。
- 候车厅预留20×9m、站台预留36×4.5m，两者之间保留约2.15m通道，候车厅前仍有约12.2m前广场。仅记录空间，不生成建筑或伪装成已完成车站。
- 正面楼梯进深6.75→3.4m、9→7级，爬升仍1.3m（2.1m主台地到3.4m站区），宽度约4.5m；真实碰撞为同高度函数的平顺坡。
- 轨道实体顶点限制在世界左右边界内，删除边界外48m轨道/土地/路基延伸。枕木末端也按边界截停，铁路带与净空同步改到新位置。
- 岔路→车站的主台地前缘局部收整为石砌挡土段，新增沿墙东向西上行的5.2m侧向石阶，从0.2m低地升至2.1m原主台地，顶部转弯继续向北。不是新增闭合台座。主路线改经此处，0键可直接观察。
- 苔石墙仅用于这段人工维护的路边。林地自然前缘坡肩宽由约1.7m过渡到约5.6m、后林台断面过渡由约2.8m放缓到约7.6m；古树低地周围的局部整平渐变扩大，减少生硬切面。湖岸旧基准未重做；自然断面不全部围墙，后续可按场景补局部岩石/树根/植被接缝。

## 实现与回退

world75继承74，surface75统一计算新铁路、台缘、侧向石阶与上平台，rail_station75替换轨道构建并增加短石墙/侧阶。已有rail_station74新增楼梯长度/级数方法读取，surface74默认6.75m/9级，历史74行为不变；75覆盖3.4m/7级。所有台阶几何只作外观，共享地形承载碰撞，不用装饰掩盖路线物理断口。

侧阶早期上平台渐变比行进坡更陡，实走发现上行卡住；改为平台边缘与阶梯共享纵向高度，避免隐藏陡唇。正常路线与明确的侧阶往返均需复测。

仍沿用原Compatibility、25°/FOV42与景深、日夜、水波/波光、整树隐去、银柳/小屋素材、69灯影和战斗。未新增实时灯或投影贴图。
