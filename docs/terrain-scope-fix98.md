# 98地形范围修复

2026-10-20。用户发现其它区域地势变平、车站苔石侧梯埋入地面。

## 原因及修复

问题始于97版林地观景台。平台西侧连接地形的apron权重在施工范围外为0，但仍执行 `max(h, lerp(2.1, 4.35, 0))`，把整张地图低于2.1m的地面、低台地及湖底都抬到了2.1m。它不是只改变颜色或楼梯贴图，而是同时影响地形网格和碰撞。

当前98版改为只在apron权重大于0时执行高度覆盖。继续使用原有分区高度，不移动车站或抬高楼梯来掩盖问题。高度源变更自动更新启动缓存签名，地面、草和树根缓存随之重新生成，无需用户手动清缓存。97历史场景保留为问题定位参照。

代表位置的修复前后高度：

| 位置 | 原96高度 | 问题97/98 | 修复98 |
| --- | ---: | ---: | ---: |
| 小院附近(0,0) | .138m | 2.1m | .138m |
| 车站低地(7,-42.7) | .200m | 2.1m | .200m |
| 苔石侧梯底(10,-45.9) | .213m | 2.1m | .213m |
| 苔石侧梯顶(4.8,-45.9) | 2.100m | 2.1m | 2.100m |
| 湖岸采样(50,-20) | -.064m | 2.1m | -.064m |

## 回归证据

- `terrain_scope98_probe.gd`对施工区外全图以3m网格采样2220点。修复前1487点被异常改变；修复后在保留当前游园入口道路的对照下，差异点为0、最大高度差为0。道路会影响原地形的坡肩，为此对照基准使用96的地形算法和98的道路布局；若直接使用96旧路形，有3个入口附近采样点保留至多.118m的既有道路调整。
- `terrain_world98_probe.gd`在当前完整场景中验证车站真实低地、侧梯下口、侧墙阻挡、上下阶及转弯、整个车站入口道路、站前台阶和小院落地，然后运行原24项游园实走/战斗流程检查。合计32项全部通过，最终渲染日志无错误警告。
- 数学采样结果：`terrain-scope98-validation.json`，问题前后日志：`terrain-scope98-before.log` / `terrain-scope98-after.log`。完整场景结果：`woodland98-validation.json`，运行日志：`terrain-world98-render.log`。
- 实景截图：`captures/world_restart/woodland98_restored_moss_stairs.png`、`woodland98_restored_station_terrace.png`、`woodland98_restored_home.png`、`woodland98_restored_shore.png`。

默认仍为world98。已运行的独立游戏进程需要关闭后用play.cmd重新打开，才能加载本次修复。
