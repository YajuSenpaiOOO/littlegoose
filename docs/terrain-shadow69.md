# 69 林路与站台：功能地形草稿与灯影修正

2026-10-19。当前入口play.cmd、preview_world_garden.cmd，主场景world69.tscn。普通入口在林地入口正午停表预览；Alt+0恢复自然时间。3林地、5车站、Tab路线图。F3回家后Alt+4看夜景，Alt+S切换局部人物影。战斗入口仍接原流程。

## 灯影

68直接压扁人物贴片，因此侧向光可能让影子只有一条线；小屋统一补光点也不能代表左右窗的实际位置。69按绘图窗中心经_pixel_world取得锚点，稳定选择一个主灯源，10Hz评分与88%滞回；两个预建轮廓槽只用于交叉淡入淡出，避免在一个影子上突然改方向。评分仍按亮度、范围、遮挡，排除发光物自身的碰撞体。默认房屋0号支持左右下窗，其它候选关闭虚拟窗源。

人物轮廓朝背光方向展开，横轴始终有宽度，最小纵轴比例0.32，最大1.45。灯正下方保留短小的轮廓，不模拟二维纸片的零厚度；这是舞台风格近似，不是真实三维体积投影。复用68柔边材质与20Hz姿态缓存，无新增灯、无实时点光源阴影图。原日月影随局部影权重减弱，接触暗部保留。

## 地形与路径

林地中央为0.62m低缓台地，边缘渐变过渡。主路在林缘接入较窄绕行路，另一路返回中央岔路；中央留战斗移动空间，移除直插中央的土路死端。车站上平台1.25m、前广场0.55m，以缓坡及弯折路线衔接；路旁低坡先试空间开合。此阶段未补候车棚、铁路、完整建筑或室内。原古树环岛、房屋和桥水衔接高度保留。

实现：world_surface69继承63地表，修改命名路线并重建路线索引；高度函数同时供地面、碰撞、导航、摆件接地与人物轮廓使用。Compatibility、25度镜头/FOV42、景深、水波/波光、整树隐去、原40战斗与时间系统保留。
