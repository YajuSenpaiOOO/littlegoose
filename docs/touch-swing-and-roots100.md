# 100：树层错开、长根贴地与碰撞秋千

2026-10-20。对应99版截图反馈：相邻树枝闪烁、秋千大树根部浮空、秋千缺少碰撞。

## 修复

林地树卡按实际贴图宽高检查相同深度平面的重叠。对两组冲突调整树根的前后位置，检查新落点坡度和道路净空，再重建贴地、碰撞及树影。调整不逐帧运行，也不随相机移动改变树层顺序。复查用截图邻近位置grove+(16,-6)，避免把帧率面板记录的“最近慢帧位置”当成截图中的当前主角位置。

秋千树的根系在原画中延伸得比普通树高、宽，普通树5.2%的贴地带不足以覆盖它。100通过独立profile将该树贴地带改为15%，保留原树木默认参数。源码grounding84新增可选root_ratio，缓存键含完整profile和ratio。长根继续使用实际地形高度，并补一份只投影的贴地根系几何，以及按原根部alpha轮廓采样的窄幅柔和接触影；主体仍使用原独立树影。世界地形高度保持99修复后的结果。

秋千座板增加AnimatableBody3D和实际BoxShape3D，使用环境碰撞层2。座板和绳索随同一个物理摆角移动；物理帧直接更新，避免空闲动画的同步机制让碰撞留在旧位置。主角实际碰到座板且仍在移动时，给摆角一个方向性冲量，限制最大约24°，随后阻尼回落；不再持续假摆动。木座的Marker3D保留未来坐姿的挂点，当前无坐下按钮或角色坐姿动画。

## 验证

`terrain_world100_probe.gd`运行原有32项车站/游园通行与三波战斗流程，增加8项树卡深度、贴地根系误差、根系投影、原生座板碰撞查询、实际主角阻挡、碰触摆动、摆动中碰撞位置和阻尼回落验证。40项全部通过，贴地采样最大误差约2.17cm；座板显示与物理位置差为0；6秒后摆动能量低于原来的0.006%。最终渲染日志与补拍日志无错误警告。最终结果见 `woodland100-validation.json`、`swing100-validation.json`，日志 `woodland100-render.log`。截图位于 `docs/captures/world_restart/woodland100_*.png`。

## 下一步画面内容建议（本版未添加）

优先补树根和倒木脚下少量蘑菇、静态落叶、苔藓与松果，形成物件接地的细节积累；其次在道路边缘做不连续碎石与草势过渡；再加少量蝴蝶、小鸟和对应局部声音。中央空地继续留通行。坐秋千可在此物理基础上接专门坐姿、上/下座过渡和退出动作，避免用站立贴图假坐。

默认入口world100；关闭旧窗口后用play.cmd或preview_woodland100.cmd重开，Ctrl+Alt+F3到秋千。
