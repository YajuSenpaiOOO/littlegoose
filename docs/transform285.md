# 285 手电变身演出预览

用户接受284肤色小差异作为短帧底稿，授权继续变身特效。285继承当前276战斗场景，不使用早期被子披风草案，按后续金色光带方案实现。

## 演出与操作

进入林间空地后自动播放一次；F2重播，Esc结束当前演出。凝神站稳0–.52秒，睁眼举灯.52秒，开灯.68秒，白芯暖边光柱快速冲出，.95秒起两条光带从灯侧展开至背后，1.02–1.7秒角色逐渐覆亮，1.92秒覆光中切回原正面角色，2.4秒显形，3.15秒恢复移动。两条肩后光带随时间摆动，6.25–7秒淡出。小幅推近在演出结束恢复，无脚边光环，无整屏白闪。

演出开始暂时暂停战斗与角色输入；显示阶段隐藏原角色visual，保留原碰撞/影子，结束恢复此前控制/暂停/可见状态。F2不能穿过控制台/对话暂停开始。Esc、正常结束与场景退出均恢复状态；重复触发不覆盖恢复快照。变身结束后可移动观察光带跟随。

## 显示接入与性能边界

复用284两帧原PNG，不继续美术生成。新特效为独立Node2D程序绘制：两条27采样带状多边形、多层光柱、最多18个固定循环光点、一次胸前扩散弧。无每帧新建粒子节点、无随机宽度闪烁、无全屏后处理。角色覆亮使用保持原alpha的CanvasItem shader，不改原角色材质。

这是挂在世界投影脚点的CanvasLayer演出试验。根据原hero视觉pixel_size，投影世界RIGHT/UP得到屏幕比例，保留竖直主角的既有纵向投影，不倾斜/重做几何；新帧源脚点(587,1230)、相对原帧尺度.595，灯口本地(-126,-463)。显形原idle使用原600×800中间帧与脚点(300,749)。光带在演出肖像之后绘制，展开后伸出发型轮廓。

Canvas演出肖像暂不参加树木/场景深度遮挡或原生受光，光柱/光带不向环境投光/投影，也没有独立碰撞；是明确的第一轮显示策略，不能宣称通用世界效果接入完成。原碰撞、影子、材质均保持，但新姿态与旧影子轮廓并非逐帧一致。森林内遮挡、转向/高速移动、音效和性能压测尚未完成。
