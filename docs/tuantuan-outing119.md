# 119：有限的团团约玩与真实弹弓制作

2026-10-23。119使用独立进度 `user://tuantuan119.cfg`，不迁移/删除118的赠送装备；旧入口仍保留。新进度初始无装备、无液滴，只有弹弓配方开放，基础射击/蹲防/闪避仍可使用。其他13项留目录，不再允许通过旧免费试制接口制造。

## 一场有结束的约玩

- 初始化时，林间已有三只不攻击、不可被射击选中的团团，近处轻轻弹动、远处停止姿态更新。F5邀请它们开始，原三只对象复用，不在开演瞬间换掉。
- 开演时预先安排两位旁观者，暂不参加攻击、不进入辅助目标列表。首位团团休息且演出至少经过1.4秒后，显示“我们也来！”并预告加入。
- 预告1.2秒后第一位沿导航路径跑入，间隔0.65秒第二位加入；入场阶段不攻击。路径完成后开始正常行为；超时后在当前位置转交原有追逐AI，不传送。
- 参与者合计五位，不无限补充、不显示波数、不使用原45秒结束条件。所有人休息后约0.9秒结算。保留暂停和主动退场；未完成五位不奖励材料。
- 原身体击败喷散效果在最后一击改成轻碰反馈。休息的团团保留落地姿势，不执行旧尸体淡出删除逻辑。
- 剧情对话、正式鼠标/交互邀请入口、复杂追逐玩耍待后续；当前用F5快速开演。正常材料场不自动追加Boss，也不发时光沙。

## 真正的材料闭环

成功散场保证得到3份“蓝色弹性液滴”，回院F打开笔记本，以3份液滴制作一把弹弓，逐份装配。第二次成功可再制作一份，使用已有二级效果。

这两个3仅为调试初值，统一在 `encounter119_balance.gd`，不是最终爆率/配方平衡。使用正式来源关系：液滴是团团喜欢收集并分享的收藏品，不是身体组织。

界面显示实际材料拥有/所需、已制作/拥有/装配数量；材料消耗与制作暂存，点“收好”一起保存，取消则全部撤回。材料不足不能制作；旧免费制作方法已关闭。119只接这一条真实配方，没有临时编造剩余碎片的材料。

## 保存与重演

开始一场时先持久化递增场次号，成功奖励与已领取场次号一起写入同一份配置。相同场次重复结算/领取不重复给材料，退场或失败不发奖。保存失败回滚内存数量，散场页显示重试按钮；待领材料没存好前不能覆盖为新场次或回院。

配置版本3保存装备、库存、制作数、解锁、材料数、下个场次号和最后已领取号。新进度独立，118的赠送弹弓不会绕过首次制作，118原进度也不受影响。当前仍固定4格，决心/年龄成长不在本轮接入。
