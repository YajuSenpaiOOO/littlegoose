# 植被层次 43：混合高草、高灌木、独立花茎

2026-10-17。用户认可 42 的景深方向、认可全部四种石子；仍不认可低花和矮灌木。当前入口 world43 继承 world42 → world40，保留 Compatibility 和既有玩法。

## 试玩与对照

根目录 `preview_world_vegetation.cmd` 直接进入小院。默认显示高低草＋高灌木＋独立花，景深为“浓”。

- Ctrl+1：只看高低草混合，暂时隐藏新增灌木与花。
- Ctrl+2：在同一草地上加入较高灌木，隐藏独立花。
- Ctrl+3：再加入独立花茎。
- Alt+F12：景深循环“关→轻→浓→重”；当前默认“浓”。Ctrl+F2 提供分层/景深面板，Esc 收起。
- F12 整套氛围对照也会恢复/应用本轮高草，不会累积放大；Ctrl+F12 柔光继续默认关闭。
- F3 回小院，原滚轮、地图、射击、弹反、闪避、选卡、F5/F8 保留。

## 植被尺度：优先验证尺寸与底部结构

本轮没有重新定义树/房子/主角的画风，也没有重画地皮。

1. **草地**：在小院—林路走廊内，按固定种子与连续疏密斑块，将 1211 个原有草实例加高到原来的约 1.45–1.9 倍，并在这些点使用未压短的高草形态。其余保留短草，路心和紧邻路肩保持通透。没有增加草实例数，也没有新加每根草的 CPU 模拟；拨动/微风沿用原 shader。林地战斗区目前保留原草量与布局。
2. **灌木**：先复用 42 的野枝/蓝果素材，以约 0.90–1.20 米高度沿林缘摆放，对照此前约 0.4–0.62 米的矮小观感。沿用接地裙边；不增加角色碰撞。重点是检验高度，不能据此声称画风已获认可。
3. **花**：新增 4 种独立细茎花，底下不带草团或贴地花坛。少量 12 组分布，世界高度约 0.44–0.65 米。原始透明图集在 `assets/vegetation43/flower_stems.png`，内置 image_gen 生成，完整提示词与锚点在同目录。42 的旧低花保留在旧入口，当前不铺。
4. **石子**：四种已获认可，按固定随机种子混合 8 颗，四种各两颗。沿用踢动、落地、接触阴影和非阻挡规则，不再要求从四种里选一种统一铺满。

这些只是小院—入林路的层次验证，不是全地图密铺。用户可逐层判断：违和来自高度、根部草裙，还是素材本身。

## 景深

保留角色附近的清晰带，加重近景和远景虚化。半径三档约 3.4 / 6.2 / 9 像素；“浓”默认开启，“重”供对照。

43 使用显式 25 点高斯圆盘采样，减少大半径下原九采样的重影感。曾试图只提高屏幕纹理 mip LOD，但当前 Compatibility 实机截图没有产生预期模糊，因此改为明确采样，并验证实际画面差异；不是仅修改参数后就视为效果已生效。

镜头 FOV、距离、跟随和滚轮不变。战斗时远侧清晰带从人物之后约 2.8 米扩大到约 7.5 米，避免直接把远处团团怪和弹道也糊掉。没有动态模糊，没有 Forward+ 或原生体积雾。

## 验证与接手

`scripts/world/vegetation43_probe.gd` 检查分层实际渲染、四种石子、高草真实高度、独立花数量、景深实际变糊、F12 恢复不累积缩放、战斗入口与清晰带。记录 `docs/vegetation43-validation.json`；同机位图片在 `docs/captures/world_restart/vegetation43_*.png`。

`vegetation43_performance.gd` 单独测量无氛围、植被无景深、浓景深和重景深，输出 `docs/vegetation43-performance.json`。不将截图比较的 CPU 停顿当成帧率，也不把本机结果当成其他玩家机器的性能保证。

本轮 16 项检查通过，当前走廊加高 1211 个已有草实例、8 株高灌木、12 组独立花茎、4 种混合石子。本机顺序采样四种模式均可运行；该轮帧率随采样过程有明显波动，不据此宣称景深能提高性能。

模块：`world43.gd` → `woodland_atmosphere43.gd` → `decorations43.gd`。42 仅新增可覆盖的 `_decor_script()` 接口；旧 42 的默认素材不变。玩法仍由 world40 继承，继续 buff 时不要回退已确认的每波选卡和镜头逻辑。
