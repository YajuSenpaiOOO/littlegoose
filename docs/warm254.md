# 254 森林暖灯：灯芯发光 / 小光池 / 去叠加硬影

2026-10-31。用户在253白色基底受光对照下指出小灯不亮、周围过亮过白及下方三角形异常，期望温馨的夜晚party暖光。本版独立覆写森林灯光工厂，不通过压暗演员解决。

## 确认的管线路径

森林191实际地方点光替代旧lights181/hanging_lights184；192减能，193扩大范围1.35倍并改舞台能量1.65，201另加摆件灯。原灯大多5—7m范围，存在多灯叠加；舞台灯持续追随主角并叠加，不对应某个可见灯具。点光不会自动让贴图灯芯自亮。201小树桩灯仅有暗色modulate及真实点光，没有统一局部自发光接入；post/hanging则混用无受光深度卡片与原生Sprite材质。

191按附近灯选择启用本地硬阴影，遮挡体为简化圆柱/盒子；还遗留舞台beam三角形网格。这些都可能造成与小灯不相符的硬边，不能仅凭用户截图把所有三角形唯一归因到某一项。254停止装饰点光的硬阴影，并关闭旧beam片；日月阴影/物体轮廓影与场景实体碰撞不改。

## 调整

forest_lighting254继承201，只由world254覆写工厂使用。保留现有灯数，灯点关联到实际可见bulb UV，移动/相机变化时统一从该挂点取位置；相机深度偏置由旧.35/.4缩到.12m。

地方灯改琥珀ffb56b，主灯约.12—.18能量、3—3.5m范围；小树桩灯.065/2.3m，201微型装饰灯约.072/2.47m；范围和能量按现有角色原生受光检查，不改主角/姐姐共享材质。衰减1.6，避免多个7m光池整片照白。跟随舞台默认stage_enabled=false，手动F11打开时仅.28×stage_level，保留诊断能力，beam片始终不绘制。F12仍是地方灯组总开关。

只对灯芯选择性自发光：运行时从既有透明源图、明确bulb椭圆区域和暖色亮像素生成mask，不生成或覆盖原画。hanging和树桩灯用原生StandardMaterial3D的局部emission_texture；post深度卡片保留relations199持有的实际材质对象/DEPTH参数，局部派生shader增加EMISSION。局部发光不照亮环境，实际照明仍由绑定的OmniLight产生。灯组开关同步真实点光及灯芯emission，保留普通材质的木杆/绳结明暗。

后处理light_relief上传范围同步缩小后的真实光池，避免物理灯收小而后处理仍用旧7m保亮范围。原森林区域调色文件未改。
