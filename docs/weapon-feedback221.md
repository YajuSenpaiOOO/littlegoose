# 221 · 玩偶命中反馈接口补齐

用户发现弹幕击中肥猫时缺少旧普通弹幕破碎反馈，并询问气球剑是否需要逐怪适配。

## 原因与修复

现在并非完全按弹丸属性独立派发：普通弹丸命中在world24写入impact_contact、调用敌人receive_hit；旧敌人在受击中转到world.on_legacy_contact，才由武器上下文决定普通碎糖或气球剑附着反馈。肥猫与蝙蝠为避开旧果冻受击/死亡/奖励重写receive_hit，漏掉通用命中通知。两者现补回一次on_legacy_contact并清掉impact_contact，juice=false，不喷旧怪的蓝色体液；HP、Boss阶段与碰撞不变。

气球剑的飞行、命中识别、胶垫/剑体、叠层、3秒独立寿命和清场仍全部由已有武器管理器负责。但旧frame154以团团怪poses计算附着面，无法自动知道新肥猫图集的尺寸。现在增加可选attachment_frame154接口，由玩偶提供当前Sprite3D的实际纹理区域尺寸、pixel_size、offset、global_basis和世界位置。共用plush_surface221只计算附着显示面，不改变角色几何、脚锚、物理占地、材质、光照、阴影或主角192；不把此面当实体体积。没有该接口的旧敌人仍走原来的映射。

221慢追此前也未读取既有locomotion_scale153，现接上每剑8%/最多5层40%的既有减速。主动滚击仍保持原速度，与普通敌人主动突进不受行走减速的既有区分一致；不延长蓄力或改变攻击行程。220保留旧追逐数值，但同样恢复命中通知/正确附着面。

此修复提供通用入口，不代表项目已完成全部武器/受击解耦。新敌人需要正确转发命中通知，特殊显示需提供附着面，特殊移动需消费适用的控制属性；不需要复制一份碎裂、气球剑或胶垫系统。
