# 64 银柳根部接地与树下停留空间（待验收）

2026-10-19。用户喜欢63银柳，仍认为影子和树有悬浮感，询问树下布置。保留银柳画风与设计，默认银柳；本轮不生图，复用当前木凳、42版石子和原地表贴图。

## 悬浮原因与处理

63的投影网格虽然顶点贴地，但可视树的接地带只有0.20m。银柳两侧根尖在原图上高于最底根尖约0.5—1m，仍画在竖立片上；因此仅改影子并不能让根尖落地。64改为将完整根部下段映射到地形：1.55m源高度的根带折向地面，保留0.35m的树干过渡。6个采样根尖原来只有1个进入贴地带，现在6个都进入；树影复用63完整轮廓与折根映射，随相同日照方向/透明度变化。

本轮还修复实机截图发现的黑带：地面影/接触暗部曾高于铺开的根片，画到根片表面。根片地面部分调整至地表+0.055m，投影仍+0.024m，接触暗部+0.035m，根部遮住底下的影子。根部范围内剔除原草批次，避免草穿过木质根面；根边缘草保留。局部景深清晰区扩到根带，周围森林景深不变。

树冠素材不改，但立片整体随根带下沉，实际冠顶比63低约1.35m；18m是源图缩放高度，当前可见冠顶约16.45m，仍明显高于普通树。不是增加黑色光晕来掩盖悬浮。Alt+Y在63窄根带与64完整接地间对照，方便用户评判，不能把数值检查等同于视觉已验收。
