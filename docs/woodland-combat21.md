# 平地林地战斗21

## 用户修正与地形

地形意图：整片林地（包括围住战场的树林）属于同一片缓缓抬升的高地，只需轻微高差。不是在平地树林中放置孤立椭圆擂台，且不希望玩家战斗中跌落边缘。

高地方案暂停。当前恢复19版林地地面高度与原入场路线，保留20版房屋30%放大、世界树环路。20版试验单独保留在 `preview_world_terrain20.cmd`，19版在 `preview_world_continuous19.cmd`。旧 godot_yard 战斗不做修改。

## 入口与操作

- `preview_world_combat.cmd`：直接到林地，开始六只普通团团怪试战。
- `preview_world_continuous.cmd`：从小院探索，走进林地9m范围后原地触发战斗，首次触发不传送玩家。
- WASD/方向键移动，Shift跑，鼠标左键按住连射，滚轮缩放。
- F5：重置怪物、血量、弹丸和计数，并回到林地南侧；F7：暂停怪物和弹丸（玩家仍可走动）。
- 1小院、2世界树、3原林地、4湖岸、5车站、6码头；Tab路线图。旧F6石阶快捷键暂指向原林地。

## 这轮接入范围

六只普通怪，每只12血，单发4伤，间隔0.18s；玩家100血、接触受伤10，0.85s无敌。清场/倒下后F5重开。这些是试验数值，不是完成的游戏平衡。

沿用旧版 tuantuan_v2 的六种姿态、脚底锚点、约0.5秒跳跃节奏，视觉起跳与物理地面分开。native CharacterBody3D 碰撞处理树干和地形；局部0.75m网格从真实树干碰撞烘焙路径，约0.4s更新追踪。离林地超过23m时怪物返回林地附近。怪物间有分散方向与物理碰撞。

瞄准首先查询真实地面/障碍/怪物受击区；地面目标上移0.65m作为身体高度，子弹使用连续线段检测，树干和房屋挡弹，已死亡受击区关闭。怪物受击闪亮、血条、位移击退、倒地消失；玩家受击变色、无敌时间、真实胶囊击退与生命条。暂停禁止发弹并冻结已有弹丸。

当前是普通怪战斗闭环的3D适配试验，不包含旧版完整武器技能、包抄/闪避/协同策略、精英/Boss、掉落升级、音效与剧情流程。精英与Boss需先确认当前走位/瞄准/遮挡感受，再移植旧状态机与攻击效果。

## 验证

`scripts/combat/combat21_probe.gd` 检查恢复原高度、保留布局、自然入场不跳位置、真实输入走到林地、屏幕瞄准、真实弹道伤害/击退/死亡、树干挡弹、实际绕树追逐、接触伤害/无敌、玩家击退、死亡与F5重开、F7暂停和清场状态。报告为 `docs/combat21-validation.json`。

`scripts/combat/combat21_capture.gd` 使用实际OpenGL截图 `docs/captures/world_restart/combat21_grove.png`，检查角色与怪物比例、跳跃姿态、接地及树林视线。截图为了定格动作使用F7暂停；启动器默认正常运行。
