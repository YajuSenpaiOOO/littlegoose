# 103 林缘入口、踩草过渡与手绘细土径

2026-10-21，延续102。运行play.cmd或preview_woodland103.cmd；Ctrl+Alt+F6到这次入口，Ctrl+Alt+F2到游园、F3到秋千。102与更早场景保留。

## 设计与实际改动

断头路不拉成一条等宽直土带。园内支径在林缘逐渐退成短草和不连续磨损斑块，经过一个小草地入口，再接外侧原有通路。地面材质的矩形覆盖边缘在这段加宽距离过渡，避免道路像被剪断。原路由/环路和战斗中心留白保持。

入口两侧做了0.50m、0.62m的两个低草坡；坡心是相对林地(14,14)和(22,8.1)，影响半径分别为(4.1,2.8)、(3.7,3.2)。采用紧支撑、局部加高，范围外返回99原高度，不对全世界取某个参考高度的最大值。场景中坡面/碰撞/树根/草的落点共用world_surface103。

增加3棵现有画风树、2组半埋苔岩、15簇可拨动灌木/蕨草，形成前景遮挡—林缘草坡—内部长凳/草坪的顺序。新摆件避开主通道，石头有原生环境碰撞并接旧贴地投影/范围更新，植物接现有受影和碰触材质。不增加全图粒子或灯光。

## 土径材质

新增assets/woodland103/painted_soil103.png，用内置image_gen参照原yard15树图笔触生成；不透明漫反射纹理，无烘焙地面阴影或草团，保留原文件。[生成方法及完整提示词](../assets/woodland103/GENERATION.md)。

纹理用世界坐标镜像平铺，Shader再降低饱和与对比，并混合暖灰褐底色，避免亮黄碎砾铺装感。继续使用现有路径距离/宽度/磨损场控制路中、草缘与露草空隙；不是把整块草坪覆盖成土。soil_strength103作为诊断对照开关，默认1；实景对比soil_old/new可检查效果。

## 声音
