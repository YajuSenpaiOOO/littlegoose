# 94 独立花茎与林下植被碰触

2026-10-20。默认world94，保留93。play.cmd或preview_woodland94.cmd进入；Ctrl+Alt+F2到主花丛，Ctrl+7西侧、Ctrl+6入口，Alt+1/2/3/4切时段。

## 改动

87–93新增灌木和蕨草原先使用没有vertex位移的forest_cutout17材质，因此不响应碰触。94仅替换plants87中的100簇植物材质，继承现有porch49/昼夜光照；岩石维持静态材质。人物靠近时植物向外让开并略压低，根部固定，进入时较快、离开时指数衰减回弹；加入小幅风摆。检查人物与植物高度差，避免上台地隔空推动下层植物。原草系统不变。

四处不规则花丛分布在西树石间、后侧林隙、西侧小开口和入口旁。复用vegetation43/flower_stems.png的裸茎素材，白花为主、少量蓝紫与淡黄；共182个独立花茎实例，四片分别52/46/38/46株，用3个MultiMesh批次。没有绘制或叠加附带草裙，周边草仍由原草系统独立提供。花丛边缘渐稀、内部留空，避开原路、树干、苔岩足迹、水域和陡坡，无新增硬碰撞。花茎用原草的walker/8段trail数据轻推与短暂余摆，不复制灌木草团贴图。
