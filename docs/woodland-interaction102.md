# 102 实阶碰撞、立体小物与可拨落叶

2026-10-20。preview_woodland102.cmd，Ctrl+Alt+F2游园/F3秋千；Ctrl+Alt+A控制新增环境音。旧101保留。

## 楼梯

原99/100/101的六阶石板只是显示网格，脚下仍是平滑坡，旧“能上下楼梯”检查没覆盖视觉脚底与踏面的相交。102为六块踏面和高台顶板生成真实凸碰撞（地面层1），并只在这段楼梯上做不足0.34m的小台阶跨步；角色实际站在踏面上。floor_height在七块石板多边形内返回实际顶面，原地形source99未变，外围高度不抬升。主角和敌人的跳行/冲刺都可用这段小台阶处理。

两侧球状石换棱角多边形石块，底部伸入实际地面，取消台顶孤立小块；高台、阶面及根部安全边距内剔除灌木/蕨草、花和短草。原100树层/长根/秋千物理保留。

## 蘑菇、松果、落叶

蘑菇换成原生三维网格：4簇×3株，独立菌柄和宽菌盖，最高约0.31m，哑光棕/米色、少量大色面变化。没有再用地面上的整幅蘑菇贴片。

松果替换整张“松果+枯枝”图：6颗独立鳞片网格、小质量RigidBody3D，主角靠近且正在走动时施加轻冲量，滚动后通过阻尼/摩擦停下。使用独立层32，与地面/环境/其它松果碰撞，不占用敌人层16；没有木棍。短距离触发有冷却，远处自然睡眠。

落叶复用101透明图集，在运行时按alpha连通区域分出6张单叶AtlasTexture，未离线改图。5处各24片，共120片，6个MultiMesh批次；每片有独立位置、速度、角度、短暂抬升、落地和层高。走过会向外拨散并留在新位置，不整片滑动/自动弹回。小幅层高差避免共面闪烁。附近30Hz更新活动叶片；主角24m且镜头外扩范围外停止更新，并将飞起的叶片落定，不留悬空状态。

## 合成声音

101鸟鸣并非录音或通用AI音频工具生成，而是44100Hz下写入PCM：短滑频正弦音调，少量二次泛音，sin²音量包络，合成三声啁啾，烘焙为AudioStreamWAV，再通过3D播放器距离衰减。绳索声为滤波噪声和低频共振。

102增加一个复用3D沙沙声声道：滤波噪声、短促不均匀包络，拨动落叶/移动穿过近身灌木蕨草时触发，0.23秒节流。环境音开关也会停止新声道。没有新增全图环境循环。项目原有CombatSfx22也已有shoot_soft、crack_soft、jelly_hit/heavy/down等合成配方，可以继续调材料感、力度和变体。复杂自然群落/长时间风林/真实声乐更适合录音或专门声音素材，本次未替换全图声景和战斗音效。
