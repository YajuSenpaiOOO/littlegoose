# world107 木枝挂灯与林下草带

2026-10-21。针对106灯太矮、林下露地过多与中央仍平的反馈。

灯具换为本版专用木枝挂灯：曲木杆、苔色小灯帽、常春藤和琥珀灯窗，高3.1m（106为1.8m），灯光中心2.04m。观景台与木座各一盏；保留3.3m范围、无局部阴影贴图、镜头外停用、昼弱暮夜强。两根灯柱有碰撞，图卡接原受影与太阳投影。只在灯窗范围发光，木杆不整体自发光。由内置 image_gen 生成的透明素材和完整提示词见 [GENERATION.md](../assets/woodland107/GENERATION.md)。

草量检查：原92草势把无组团区域高度压到约0.38倍，还随机隐藏一部分草；99又压低环路。106未删除整张草地，但静态叶数量改变会改变后续局部路缘装饰的随机序列。这次不恢复拨叶，通过107局部草势恢复非踏面直立草，并新增12段有缺口的草带，覆盖崖脚、外围树下、前景及后侧两处小组团；不将植物均匀撒满中央。

新增483簇原生草网格、54簇独立蕨草，复用现有素材，仅3个MultiMesh批次。蕨草高约0.55–1.15m，草与花仍独立。新草/蕨草接原受影、经过让开与风动，追加蕨草只更新2个批次材质参数；静叶及两种被否定的沙沙声继续关闭。新批次40m可见距离、远处停止角色影响参数更新。

中央偏后两处真实浅草丘：局部(-3.3,-2.9)抬0.34m、(3.2,-3.9)抬0.40m，半径2.2×1.8m；紧支撑函数只影响椭圆内。网格/碰撞/高度采样共用同一表面；中央横纵走位线、环路、高台及旧站区保留。新增植物筛除台阶、岩石足迹、桌座/倒木附近及道路与主走位线，避免再次在石板上长草。

Ctrl+Alt+F2 游园，F3 秋千，F6 林缘入口；F7暖灯开关，F8新增草带开关（不撤草势和地形）。Ctrl+Alt+M原有草势对照仍保留。关闭旧窗口后打开play.cmd或preview_woodland107.cmd。
