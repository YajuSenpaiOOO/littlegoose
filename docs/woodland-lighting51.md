# 51：树密度基础林荫＋独立阳光开口

2026-10-18。基于50，当前美术待用户验收；Compatibility和40玩法继续保留。

入口 `preview_world_lighting51.cmd` 直接到林路，窗口标题“森林光影51”。Ctrl+F4 林路，F3 小院；非选卡时3西侧林地、4湖岸。Ctrl+7 为50原版；Ctrl+8 为仅树密度林荫；Ctrl+9 为密度＋阳光开口（默认）。

## 如何生成

生成器启动项目当前主场景，从实际已生成树木中读取位置与高度，包括中央大树和框景树，共368棵。按高度估算树冠影响半径，用空间索引累积邻近树冠覆盖，得到平滑密度。疏林保留较亮底色，密林采用区域预设的冷色林荫。

阳光开口按道路独立生成，覆盖基础林荫，因此密林中仍然可以有亮区。开口不会因为密度高而被取消。原有真实太阳投影继续存在；这不是逐叶遮挡或实时全局光照，也没有增加体积光束。

`assets/lighting51/regions.json` 是统一配置：三套预设 forest、deep_forest、lakeside 分别用于普通森林、西侧深林、湖岸方向；5条道路批量生成14个开口。配置树冠影响半径、密度上限、预设阴影/阳光颜色、开口间距和大小。没有逐棵树调材质、逐个摆件加灯。

## 以后怎么复用

1. 新区域在配置中增加道路名并选择预设；已有五条路线已配好。
2. 修改树布局、道路或配置后运行根目录 `bake_woodland_lighting.cmd`，一次更新整张光照分布图并导入。
3. 试玩查看重点位置，必要时调预设；配置的 `accents` 列表可补手工亮区，如 `{"at":[12,-27],"radius":[2.5,1.8],"forward":[0,-1]}`。当前列表为空，14个开口全部由道路生成；手工亮区沿用所在区域色调。

运行时只选择并采样光照图，不扫描树木、不每帧生成地图，不新增灯光或阴影贴图。两张新增数值纹理均384×256，分别为“仅密度”和“密度＋开口”，对照时切换，不是同时叠乘两张图。原50图保留为Ctrl+7对照。

局限：树冠半径来自高度估算，树木增删/移动后需要重新生成；没有实时察觉布局变化。当前按道路选择预设，而不是自动推断一处是湖岸或剧情点。重要构图仍需美术判断。相邻区域当前按最近道路选择预设，后续若出现明显接色边界，可增加预设之间的混合。
