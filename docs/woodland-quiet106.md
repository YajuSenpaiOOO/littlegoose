# world106 静叶无声与两处树下暖灯

2026-10-21。

用户反馈落叶太碎、声效怪，走过时卡顿。106默认撤下叶堆拨动，改为五小片共60片独立静态落叶，原为120片。单叶宽度0.23–0.34m，原为0.12–0.20m。静态叶片只在建立场景时写入一次变换；经过时不做逐叶高度/法线求解、抛起或实例上传。草丛/灌木让开、可踢松果、秋千保留。

近身草声与落叶声都关闭；Ctrl+Alt+A开关环境音也不会重新启用这两种声音。鸟鸣、秋千声保留。叶声原为启动烘焙的短WAV，播放时不重新合成；逐叶拨动则会反复调用完整地形法线，因此先撤掉这项成本。woodland106_profile.gd以同样60片叶作静音拨动/静态对照，避免把静音和静态同时改变后混为一种原因；此对照是106内部参考，不能当作原105的精确帧率对照。

复用已有绘本路灯贴图，在观景台后侧、木座旁各放一盏暖灯。白天弱亮，黄昏/夜晚增强；每盏光照范围3.3m，无新的局部阴影贴图，最多2盏。每0.2秒检测一次镜头外扩与30m距离，范围外停用光照。小灯柱有实际碰撞；不改地形、路线或原太阳影。

Ctrl+Alt+F7暖灯对照，Ctrl+Alt+F2游园/F3秋千/F6入口。旧105保留，106沿用105物理与绘制优化。

## 战斗基础设施的安排

- 现在固定基本预算和可重复压测。现有碎片64、果冻48、残留48、短特效锚点144的数量上限与镜头范围调度继续保留；这次增加的局部暖灯上限2。弹丸本体没有因显示预算而截断伤害或数量。
- 下一轮战斗打磨的开头，结合武器/弹幕的生命周期完成弹丸数据池，先明确生成、命中、穿透、回收，再扩攻击花样；不等大量武器都堆完才处理生命周期。
- 空间分区以目标数量和实测枚举成本决定。当前四敌人测试里，隐形影子/地形求值/物理与画面上传更突出；现在先建复杂全图索引收益不明确。确定多敌人、分裂/追踪弹幕的规模后再加入，并保留简单实现对照。

当前105的900帧压力结果仍是约60发/秒、83个同屏弹丸时中位30ms附近，不能作为未来重弹幕稳60帧的保证。106重点是环境收尾，未宣称解决这一极限负载。
