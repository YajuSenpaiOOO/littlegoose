# 96 林间小憩与低花草甸

2026-10-20。默认world96，95保留。play.cmd或preview_woodland96.cmd进入；Ctrl+Alt+F2到小憩处，Ctrl+7西侧，Alt+1/2/3/4看时段。

用户认可小憩处方向，认为贴地野花草甸更适合当前林地。96沿西侧既有斜树与林缘做场景构图：原前伸苔石移到约(-10.7,-3.6)并换4.5m宽苔石，相对林地中心；下方补约0.58m真实草坡，形成略高的石树小景。没有增加岩石总数。该小景目前是环境布置，没有新增坐下交互。

95的较高密集花海改成529株13–28cm低花，以白花为主、少量蓝色，2个MultiMesh批次。仍集中在同一片相连草甸，沿树石边缘生长、保留绿地空隙和自然疏密；不是分散到全图。花茎与草为独立组件，继承95受影/投射、94碰触和95缓冲视野调度。现有素材缩小会呈细碎花点，花形精度与密度仍需用户体验。

从林地中心(0,3)经(-3,2.5)、(-5,1.5)、(-7,0.8)至(-9,0.9)设置浅踏草路径。真实草叶降低，花不占据草径；最终草顶材质只轻微变浅/收饱和，保持草色。CPU草势与地面Shader共用相同控制点与宽度，未加入棕色土路。新缓坡避开原道路中心。
