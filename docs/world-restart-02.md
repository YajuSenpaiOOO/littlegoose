# 草稿 02：镜头、移动与空间

2026-10-16。用户反馈画风混杂、画面抽动、需要滚轮缩放，以及区域/连接道路偏紧。本轮调整主工程现有连续世界；旧院子和旧 godot_yard 不变。

## 已修改

- 滚轮控制 0.35–4.5 倍镜头，平滑收敛；中键恢复 2.15 倍。滚轮在总览时可进入可移动模式，从当前总览倍率继续缩放；Tab 总览/实走不清除用户倍率。缩到视野大于地图时使用地图中心，避免反向 clamp 造成跳动。
- 场景单独启用物理插值，角色身体与 Camera2D 开启插值，摄像机在角色移动之后的物理回调更新。换帧时角色图像的原点/尺度不插值，避免不同 Atlas 帧尺寸混合。静态场景不插值。
- 镜头缓动由每帧固定 lerp(0.12) 改为按时间指数收敛；移除每个渲染帧强制重算相机滚动，阴影遮罩读取当前画布变换。
- 移除按任意键强制镜头瞬移的行为，只有总览切换和区域跳转立即定位。跳转/初始化时 reset_physics_interpolation，避免跨区拖影。
- 地形和位置间距扩大 1.3 倍，地图由 2400×1600 扩为 3120×2080。立体树/房屋/灯、角色尺寸和物件碰撞脚印保留；不通过放大角色和图片伪造空间变大。地表 UV 同步更新，避免砖纹尺寸随地理扩展变大。
- 北侧、林地连接路增加少量转折；本轮不加入长蛇形空路、迷宫或重复折返。数据仍按原基础坐标书写，由 spacing_scale=1.3 统一转换，探针检查转换后的真实位置。
- 正式环境风格以主角为基准，具体约束单列 hero-style-baseline.md。当前占位素材尚未完成统一。

## 路程预算

下列是中心线长度除以速度的理论时间，不包含起步、转向、战斗、停留和探索。行走 115，快走 190 世界单位/秒。

| 路线 | 世界长度 | 行走秒 | 快走秒 |
| --- | ---: | ---: | ---: |
| 小屋门前到岔路 | 986.1 | 8.6 | 5.2 |
| 岔路到车站 | 563.1 | 4.9 | 3.0 |
| 岔路到林地 | 1103.0 | 9.6 | 5.8 |
| 岔路到湖岸 | 1219.1 | 10.6 | 6.4 |
| 小屋侧路到码头预留 | 372.0 | 3.2 | 2.0 |

小屋到林地约快走 11 秒，到湖岸约 11.6 秒。适合作为本轮试走距离，不代表最终赶路时长已锁定。增加层次优先使用林荫收窄—转折—小停留处—开阔目标的顺序；只有出现探索、战斗或叙事理由才继续延长。后续如重复返家频繁，再安排可解锁捷径，不预先制造无意义绕路。

## 抽动排查及验证

代码发现旧镜头在渲染帧读取未插值的物理位置、固定每帧缓动系数，并且所有按键都会瞬移摄像机；这是本轮修正的具体问题。不能仅凭短时平均帧率断言用户的全部抽动已经消除。

`world_motion_benchmark.gd` 在本机 OpenGL、120FPS 上限、关闭垂直同步，沿小屋路线移动，预热 60 帧后采样 360 帧：

| 指标 | 修改前 | 修改后（地图已扩大） |
| --- | ---: | ---: |
| 帧间隔中位数 ms | 8.327 | 8.335 |
| p95 ms | 8.417 | 8.437 |
| p99 ms | 8.450 | 8.555 |
| 最大 ms | 8.509 | 8.991 |
| 超 25ms 帧数 | 0 | 0 |

原始文件：captures/world_restart/motion-before.json、motion-after.json。该样本两版都没有复现长帧卡顿；结果只说明短样本帧间隔稳定，不是性能提升证明，不包含全地图、正式战斗、长时间运行或用户实际显示器环境。物理插值和相机时序修复针对的是稳定帧率下仍可能出现的移动抖动。

`world_restart_probe.gd`：1106 个半径 7 通道采样点全部无阻挡，实际角色沿五条路线往返到达端点，湖水阻挡/区域跳转通过。新增滚轮方向/上下限、极远镜头有限坐标、Tab 保留倍率、无关按键不跳镜头，以及 30/144 次调用的等时长镜头收敛一致性检查均通过。

实际 OpenGL 截图：captures/world_restart/home-v2-noon.png、overview-v2.png，已目视检查。单帧截图不能证明动态抽动彻底消失。若仍出现抽动，应区分整幅场景跳动、角色脚步换帧跳动，以及地面细纹随移动闪烁，分别继续定位。

实现依据：[Godot 4.7 插值使用说明](https://docs.godotengine.org/en/4.7/tutorials/physics/interpolation/using_physics_interpolation.html)、[Camera2D](https://docs.godotengine.org/en/4.7/classes/class_camera2d.html)。

本轮之前的构建脚本和布局数据保存在 docs/archive/world-restart-01-before-motion.gd.txt 与 world-restart-layout-01.json.txt。
