# 连续世界 25：帧率与角色接地

2026-10-16。常用启动器和项目默认场景已切到 world25；`preview_world_combat24.cmd` 保留上一轮攻击链对照。

## 本轮改动

- 调试 HUD 最多每秒刷新五次，避免每帧在多层继承中反复改写文字并重新排版。
- 没有有效脚印时跳过材质中的脚印循环及无意义的时间参数上传；有效脚印仍正常显示、淡出。
- 旧攻击星点拖尾改为一个 Canvas 渲染器，保留寿命、尺寸、阻尼和随机分布。上限 160 个装饰粒子，不影响伤害与弹速。
- 离玩家 40 米外、原本已不显示投影的家具，不再每次镜头移动都重建接地投影网格。
- 树木只为可能遮住人物的方向计算屏幕包围框，淡出值未改变时不上传。
- 主角、小黑鹅、团团怪使用当前姿态贴图的透明轮廓投影，随光照方向和起跳高度移动；主角 AtlasTexture 帧会解开 atlas 区域，翻转随当前姿态。
- 投影使用九个顶点贴合缓坡，地形高度缓存与真实碰撞网格使用相同三角形插值；修正脚底接触影的坡面法线方向。没有添加额外灯光或每角色阴影图。
- 普通每发命中的 12 毫秒全局微顿默认关闭；击杀、连击里程碑、主角受击仍保留重反馈。

`Y`：新角色投影开关。`X`：普通命中微顿开关。左上角生命值下方显示 FPS 和开关状态。其余战斗按键沿用 world24。

## 验证

实际 OpenGL Compatibility 渲染，RTX 5060 Laptop，1440×900，无垂直同步，每个阶段 3.5 秒；固定三只怪，测定连续射击与连续命中。此结果不是全地图或大量怪的帧率保证，温度与其他运行程序也会影响数值。

| 场景 | 修改前 FPS | 加入新投影并优化后 FPS |
|---|---:|---:|
| 原地空场 | 79.9 | 172.6 |
| 持续射空 | 67.6 | 149.6 |
| 持续命中 | 71.4 | 155.9 |

原始数据：`perf25-before.json`、`perf25-after.json`。`ablate25_probe.gd` 是定位过程中的消融测试，不代表最终优化结果。

`combat25_probe.gd` 的 16 项检查已全部通过，覆盖角色投影数量、真实地形射线与缓存高度、脚印生效及过期、原生三维命中、微顿开关、跳跃投影、接触法线和实际 GPU 输出。角色阴影是位置线索；瞄准是否舒服仍需实际游玩判断。当前只支持既定固定水平朝向和 25° 镜头，未实现任意旋转镜头的完整体积投影。
