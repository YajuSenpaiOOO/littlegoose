# 连续世界 26：单层角色投影与鼠标身体射线对照

2026-10-17。默认项目和常用启动器已切到 world26，`preview_world_combat25.cmd` 保留上轮完整对照。

## 实际发现与修改

world25 加了角色轮廓投影，但保留了 hero_contact 以及 goose.shadow 等老椭圆。这会在近处叠黑，使小黑鹅的小尺寸轮廓难辨。world26 隐藏老椭圆，三类角色只保留当前姿态的轮廓投影。

world24/25 的子弹已经有直下方的弱椭圆影，不是完全没有影子。world26 改为沿场景太阳方向投到实际地形，坡面法线、离地偏移和高度变化同步，阴影浓度略提高。

world23/25 在鼠标位于怪物画面时，会自动改瞄怪物中心并加入最多 0.14 秒预判。进入和离开怪物轮廓时，自由瞄准与中心辅助发生切换。这是需要实玩对照的手感因素，不足以断言它是所有瞄准问题的根源。

world26 默认用相机鼠标射线取得实际受击体表面，目标略向受击体内推进 3.5 厘米，仍在同一条鼠标射线上，不自动跳中心或加移动预判。只在射线命中受击体且鼠标覆盖怪物可见像素时启用；墙和树干挡住射线时不选择后方敌人。空处沿用离地 0.85 米的原自由瞄准。子弹仍是原生三维碰撞、原弹速与散布，没有改成点击即命中。

`F6` 在新直接身体射线与旧辅助之间切换并清理在途弹道。`F9` 的旧轻辅助开关作用于旧模式；`F10` 显示受击体；`F11` 的原平面判定对照仍保留。`Y` 对照新轮廓投影，`X` 对照普通命中微顿。

透视鼠标拾取采用引擎提供的相机射线方法，见 [Godot 射线拾取文档](https://docs.godotengine.org/en/stable/tutorials/physics/ray-casting.html)。准星选取射线与子弹从小黑鹅出发的飞行线是两回事：子弹依然可能被中间障碍挡住，移动目标也可能躲开飞行中的子弹。怪物的跳跃贴片与固定受击胶囊尚未完全同形；点到受击体以外的发梢等像素仍可能不命中，这不是本轮承诺修好的范围。

## 验证

`combat26_probe.gd` 实际 GPU 渲染 11 项检查通过：老椭圆隐藏、小黑鹅轮廓保留、鼠标覆盖实体像素、目标投影误差小于 0.02 像素、原生受击体射线一致、实际子弹一伤害命中、子弹地影随高度和光照方向移动、地影贴合地形、F6 双向模式切换。截图 `captures/world_restart/combat26_shadows.png` 已人工查看。

## 后续玩法判断

保留走位、使魔射击和弹幕试验。当前镜头下优先测试数量可读的中速弹幕、明显地影与预警、清晰的战斗空地。非常密集的擦弹需要另测更高俯角或更弱透视的战斗镜头；不应在基本指向关系尚未调顺时直接决定弃用射击或转近战。近战同样需要准确的距离、范围与命中线索。
