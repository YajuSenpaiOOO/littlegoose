# 连续世界 29：纸杯电话与细线辅助

2026-10-17。项目默认场景及常用启动器使用 world29；`preview_world_combat28.cmd` 保留上一轮。

## 试用

默认开启纸杯电话，用 `Backspace` 对照贴身跟随与自由飞行。`E` 继续切换枪口线、旧地影和关闭辅助，`Z` 切换精确直射／原散布。按 `F1` 展开或收起原调试说明和 FPS。右上角保留一张小的 buff 状态牌，底部大调试面板默认收起。

这次直接测试一个 buff 开关，尚未接入完整选卡和 run 结算流程；选卡内容仍参考旧版 `cards.gd` 的 `cup_phone`。

## 辅助线

保留真实三维枪口、射程与碰撞预测，改用投影后的屏幕细线表现。2.7 像素半透明暗边增加亮草地上的对比，1.05 像素暖色内线保持克制；中段较淡，枪口及末端更清楚。未开火时淡一些，按住射击时稍清楚。不再显示发光球或密集虚线，命中处只留小点与小弧，受阻处用暖橙色短横表示。

屏幕描线没有改变子弹碰撞，也不穿过预测到的实际墙体、树干和地形。原散布仍可开关，打开时保留很淡的两侧范围线。光照方向上的子弹地影独立保留。

## 纸杯电话移植范围

依据旧版 `godot_yard/scripts/black_goose.gd`：

- 弹簧参数 26 / 6.5，活动目标半径 110 个旧世界像素，按当前 PPM 换算约 5.76 米；未启用时仍使用原贴身范围。
- 自由飞行跟随鼠标目标，移动与后坐都作用于小黑鹅自己的偏移弹簧。关闭 buff 后先收回，进入贴身范围后恢复原跟随；没有瞬间把远处的小鹅拉回。
- 在已有缓坡上按小鹅当前位置的实际地形高度保持悬浮，保留轮廓投影和枪口朝向动画。
- 接触伤害为当前普通弹伤害的 0.5 倍，每只怪独立冷却 0.5 游戏秒。不计入子弹命中数和连击，不触发普通弹的糖屑／果汁效果；保留敌人的受击动作及击退，击杀照常结算。
- 暂停、角色倒下、战斗未开始或已结束时不触发接触伤害。重开清空接触冷却，保留当前试用开关。
- 飞行沿用旧版魔法使魔的无移动碰撞处理，尚未增加绕墙寻路；子弹照常受墙体阻挡。

适应三维的新处理：到达鼠标附近 0.32 米内时保留最后稳定射击方向，给出有限的前向目标，避免枪口与鼠标重合时停射或左右翻转。瞬间归位／重开会重新取得朝向。弹道射线支持从受击体内部开始，避免鹅飞入怪物后子弹反而漏检。
