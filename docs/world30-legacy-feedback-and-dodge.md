# 连续世界 30：虚线、旧版反馈和 Shift 闪避

2026-10-17。默认项目及常用启动器使用 world30，`preview_world_combat29.cmd` 保留上一轮。

## 本轮取舍

辅助线恢复 world28 的真实三维虚线，去掉 world29 的连续纸线；`E` 仍可比较地影和关闭辅助。纸杯电话的活动范围、自由飞行路径规则不在本轮继续修改，仍可 Backspace 开关。

Shift 直接闪避，取消 6.5 米/秒的持续跑步，保留普通 4.1 米/秒步速。按下沿立即响应；按住不会自动连闪，也不会转为跑步。没有短按／长按复用，也没有恢复探索专用跑步动画。这是本轮手感测试选择，不代表敌人追击和长期闪避收益已经平衡完成。

## 对照旧项目的迁移

来源是 `godot_yard/scripts/main.gd`、`player.gd` 及已有 `hero_pixel/dash_choices/directions_v1.json`。只迁移当前试战已有事件，不包括尚未接入的弹反、Boss 攻击和选卡回报。

- 普通命中：恢复默认 12ms 微顿，保留原 120ms 安静间隔。`X` 可以继续关闭普通微顿对照；连击 10/20/30 的独立重拍沿用原实现。
- 普通击杀：旧版每杀本来就有 40ms 短顿、0.35 创伤震动、+0.32 微变焦，保留全部触发。变焦从旧默认地图基础 4.0 换算到透视 FOV，战斗另加 1.2；不再用上一轮猜定的 3.0 作分母。镜头倍率按原 `min(1,8*游戏delta)` 平滑。
- 最后一杀：按旧版 `CLOSEUP_CHANCE=1.0` 必触发清场特写。立即指定尸体焦点和地图基础 +2.2 的目标倍率、震动 +0.3；真实 0.4 秒时开始 0.25 倍慢动作持续 0.5 秒、再震 +0.45；1.1 秒时解除焦点和特写倍率，再平滑恢复当前上下文。移除上一轮自行添加的焦点混合和 0.95 秒提前拉回。保持相机水平朝向和 25° 俯角。
- 完美闪避：当前近身敌人的闪避轨迹检测触发一次 0.3 倍、0.22 真实秒慢动作，+1.0 推近、0.1 震动、原版蝴蝶动画、温暖音效及 0.5 秒保护。蝴蝶直接复制原 PNG 和动画脚本，移除替代枪口闪光。每次闪避只奖励一次；受击无敌期内起跳不再白拿奖励。尚未接敌方弹幕的擦弹判定。
- 主角倒下：0.25 倍、0.6 真实秒慢动作，保留倒下图；不会再切回普通站立图。

临时变速已改回旧 `set_temp_time_scale` 的实际规则：后写倍率覆盖前写倍率、真实截止时间只延长；不再自行添加“顿帧后恢复前一个慢动作”的优先级规则。重开、暂停、退出仍取消待触发事件，避免旧异步回调污染新一轮。

普通受击继续使用旧版 90/PPM 击退、0.8 秒无敌、30ms 强制顿帧、0.2 秒红闪与 hurt 音效；补回生命 HUD 的 0.25 秒受击抖动。试验生命值仍为 100，20 点接触伤按旧版 2 点换算反馈强度，没有改成旧版完整“决心／硬撑”玩法。真正死亡补回 over 音效和 0.5 震动。

相机跟随接回速度 ×0.22 秒前瞻、48/PPM 上限、4*delta 前瞻平滑与 7*delta 跟随；特写期间前瞻归零。震屏恢复旧版逐帧 0.45 插值和 2.2*游戏delta 衰减。鼠标身体瞄准、原生三维碰撞和滚轮距离保留。

## 主角动作

原有行走帧之外，接回脚底锚定的程序动势：步伐起伏、±0.013 倾斜、1.8%／2.8% 行走挤压拉伸、±0.8% 待机呼吸。固定水平镜头下使用真实立牌旋转，避免 billboard 覆盖倾斜；GPU 已检查同一行走图的左右倾斜确有像素差异。

直接复制旧版已经采用的四向闪避 PNG 与元数据，未重新生图。闪避使用这些姿势和正确脚底锚点，不额外拉伸；左向镜像与残影保持一致。旧参数换算：260/PPM 米/秒，0.16 秒，约 2.18 米；0.55 秒单段冷却、0.2 秒基础无敌，结束保留 70/PPM 的短收势惯性。残影约 0.22 游戏秒淡出，总数有上限；启动处预热极淡透明贴片以减少首次透明材质管线开销。实际三维 `move_and_slide` 负责墙体阻挡，不是直接改坐标穿墙。

倒地纹理仅由明确的 `knocked_down`、`story_knocked` 或生命归零触发。移除 `combat_impulse>30/PPM` 的错误姿势判断；普通受击 90/PPM 和闪避收势 70/PPM 都不会再显示倒地图。重新开战清理这两个状态。

补回闪避起步原版三粒方块尘土，复制 `fx.gd` 并适配投影锚点局部坐标。粒子预算在节点退出时归还，确保重开提前清理特效也不会永久耗尽预算。团团怪果汁飞溅节流接回原来的真实 110ms；鞭尸补回旧 hit 音效。糖弹与材质特效脚本已逐行对照，仅保留三维锚点坐标适配；星形拖尾继续用批绘制维持性能。

旧 main.gd 的 +0.32 衰减行实际误缩进在 aura_count 分支下，普通状态会卡住推近量。本版保留其写明的“每杀咬一口再弹回”及 9*delta 衰减，不复制该缩进缺陷。受击体偏离与贴地投影的已有修正也保留。弹反、重弹硬直、Boss 运镜、卡牌专属效果与决心经济需要对应玩法接入后触发；本轮没有把它们错接到普通攻击。

左上生命条旁增加一个很小的 Shift 冷却菱形。其它简洁 HUD、F1 调试说明、F5 重开、F7 暂停保持。

为让清场后的低位身体能继续被鼠标击中，当前身体射线模式也接受尚可见的尸体受击胶囊，不再强制落回 0.85 米瞄准平面。原生子弹鞭尸已验证。团团怪原有落地弧线和轻转身保留，未添加额外长时间尸体抽搐。
