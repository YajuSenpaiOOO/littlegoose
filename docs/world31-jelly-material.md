# 连续世界31：团团怪材质与连续射击反馈

默认入口、连续世界和战斗启动器改为 world31。world30 源码保留，独立入口为根目录 `preview_world_combat30.cmd`。

## 体验与对照

- 默认普通命中不再触发全局 12ms 微顿；连击 10/20/30 的重拍、击杀短顿、最后一杀特写仍沿用 world30。
- Insert 切换“新材质反馈／30版反馈”，并重开一轮。旧模式恢复普通微顿、旧屏幕汁液、旧音效和旧受击姿态。
- X 仍独立切换普通全局微顿，方便只比较停顿。F5 重开；F1 显示调试说明。F4 原有脚印开关保留。
- 开始默认纸杯电话状态沿用前一轮；Backspace 可切回贴身跟随再判断基础射击。

## 身体与接触

新 `tuantuan31.gd` 使用有阻尼的视觉弹簧；命中在原受击图上额外产生有限压缩、略微定向歪斜和回弹。深度方向命中同样有可读的轮廓压缩。以小步长积分以避免卡帧时弹簧发散。

视觉每帧从原姿态重建，附加位移有界；受击胶囊不受弹簧影响，继续以地面为锚点。主角普通受击／闪避的倒地帧修正继承自30版。

命中亮点在最初约90ms贴着怪物身体移动；糖碎片保留原样，独立的汁液不跟随被击退的怪。击杀和连击里程碑才增加一次140ms有界定向镜头轻推，普通连射不逐发震屏。

## 三维汁液

`jelly_fx31.gd` 管理真正的三维坐标、高度、重力和地形接触。普通命中两滴，击杀五滴，受原真实110ms飞溅节流控制。外观为临时薄荷色小液滴几何形状，用于先判断飞行和落地节奏，并非最终绘制的粒子素材。

液滴下方有弱接触影子；与地形相交后转为贴地、不规则像素边缘的薄痕，停留1.6～2.6秒后清理。痕迹按所在地形高度和法线摆放，不能无限堆积。

飞行液滴最多48个、接触影子最多48个、地面痕迹最多48个，分别使用三个 MultiMesh 批次。没有逐滴建立物理刚体、碰撞体或实时灯。暂停冻结特效，重开清理粒子、痕迹、声音与镜头轻推。

## 声音

团团怪命中单独合成短促接触、高低频软体压缩及弹性尾声；不再直接复用旧轻响。落地使用更轻的独立湿点声，100ms节流。死亡保留下沉提示。

按画面左／中／右选择三档轻立体声声像；按主角到接触点的距离作轻度音量衰减，最多5dB。镜头滚轮拉远不会让命中声因相机距离而突然变小。最多8个轮转音轨，立体声变体启动时一次性烘焙。

## 验证与范围

`scripts/combat/material31_probe.gd` 23项通过，包含真实三维子弹伤害、普通命中无全局停顿、身体弹簧回弹、受击体稳定、真实地形落地、痕迹高度／过期／预算、音轨、击杀／连击重拍、重开和新旧切换。日志 `material31-probe.log`。GPU截图为 `captures/world_restart/material31_hit.png` 和 `material31_residue.png`，已查看。

性能脚本支持 `--material`，独占测试日志 `material31-perf-solo.log` 与记录 `perf31.json`；固定机位、1440×900、三只靶、取消垂直同步，不能据此保证大量怪物和高倍率buff的帧率。

这一版先用于比较“不中断连射＋果冻身体反应＋三维落地收尾”。液滴造型、颜色、声量、弹簧幅度和痕迹密度仍需实玩选择，尚未重新平衡战斗数值。
