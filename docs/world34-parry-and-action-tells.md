# 连续世界34：弹反与无箭头读招

默认项目和常用启动器进入 world34；上一版可用根目录 `preview_world_combat33.cmd` 单独打开。

## 操作与读招

- 右键按下沿：弹反。按住不会自动重复；不要求鼠标指向怪物。
- 左键射击可与右键弹反同时使用，小黑鹅活动范围独立。
- Shift 闪避；F5 重开；Delete 开关33版地面弧线和方向箭头。
- 默认箭头关闭，渲染节点不处理。保留0.48秒蓄力、0.18秒后锁方向及起跳音；压身幅度略加强，锁定后的定向姿态保持到起跳。没有同时缩短攻击预警时间。
- End 的旧追逐模式没有新的扑跳接触钩子，主要用于旧AI对照；本轮近身弹反适用于默认蓄力扑跳模式。

## 旧版来源与参数

来源 `godot_yard/scripts/player.gd`、`main.gd::parry_success`、`scripts/art/parry_impact.gd`。直接复制四向 `hero_pixel/parry_crouch*.png`、`parry_directions_v1.json`、`parry_v1`图集和原接触／扫光动画；没有生图或替换成倒地图。

| 项目 | 旧值与本版 |
| --- | --- |
| 开窗 | 0.18游戏秒 |
| 空放冷却 | 1秒，空放音效 |
| 成功再次输入间隔 | 0.06秒 |
| 成功后收窗 | 0.03秒；同簇仍可接，后续攻击需要再次按键 |
| 收招动势 | 0.18秒口径，缩放偏离(0.26,-0.24)，弹簧K620/C11 |
| 截击范围 | 原30像素／PPM，约1.57米 |
| 连段窗口 | 1.2真实秒，三档 |
| 升档顿帧 | 90／120／140ms，0.05倍率 |
| 升档镜头推近 | +0.6／0.75／1.0，沿既有基础倍率换算 |
| 后续慢镜 | 前两档真实0.2秒后0.3倍持续0.22秒；第三档0.22秒后0.15倍持续0.35秒 |

同档追加只给轻震、闪光与音高提示，不重复重顿帧或第三档反击。升档取消上一档尚未开始的慢镜，重开／暂停／离场清理整个反馈时钟。普通射击微顿默认仍关闭。

姿势按原脚底坐标和身高元数据换算，成功与空放都不使用 `ko_knocked_v2.png`。右键支持四个现有朝向；旧版辅助Q键本轮未抢占，因为新项目Q仍用于准星对照。

## 近身适配

旧版这套弹反主要截击水弹／碎波环，普通团团怪原本没有这套新扑跳。本版在真实扑跳的扫掠路径进入女主截击范围时，先判断弹反再判断受伤。

成功取消该次扑跳伤害，怪物向外弹开并进入约0.75秒恢复，视觉腾空逐渐落下，可以用小黑鹅继续射击反击。不会因弹反第一下直接扣怪血；第三档照旧产生三发±20°金色反击糖弹，单发真实伤害1.5、寿命1.2秒。

射击链增加每弹伤害倍率读取，未标记的普通子弹仍为1。成功计连击一次；伤害无敌和闪避无敌期间不白拿弹反奖励，闪避中无法同时起手弹反。尚未接入的水弹、波环、卡牌反击、素描本和决心经济不在本轮生成替代玩法。
