# 扑跳36：起跳锁目标、最后按键朝向

默认入口切到 world36；preview_world_combat35.cmd 保留原版对照。

## 团团怪

蓄力全程更新目标，包含转入 lunge 的最后一个物理帧。扑跳方向指向这一刻的主角位置，正常距离下落点多越过 0.35 米。最大跳距 6.2 米，避免异常位移产生无限距离冲刺。离地后方向和距离固定，不跟踪闪避；落地恢复期、前一版的起跳小闪光和右键弹反保持不变。

旧版本仍使用原先的 0.18 秒锁方向策略，公用状态机只增加可覆盖的更新目标方法。

## 主角朝向

走路按最后按下、仍对当前移动方向有贡献的 WASD / 方向键选取四向动画；忽略系统按键连发，松开最新按键后回到其它仍按着的方向。停止时保持朝向，焦点离开窗口时清除按键优先级。

闪避开始前先取当前朝向，然后锁定整段闪避的动画与位移方向。闪避途中按下其它方向只影响之后走路，不翻转正在播放的闪避帧。移动速度和斜向归一化保持原样。

## 闪光与冒汗

本版保持起跳闪光，不替换成液滴。攻击命中已经有飙汁，另加短促飞散的汗滴容易混淆；汗滴更适合留作恢复阶段的疲惫表情。本项是设计建议，未加入新特效。
