# 林地遭遇37

常用预览入口和项目默认场景改为 world37；preview_world_combat36.cmd 保留上一版。

## 一场遭遇

- 依次为 1、2、3 只团团怪，共六只；保留上一轮剩余生命、射击、受击、连击、弹反和完美闪避统计。
- 轮间喘息 2.2 秒，清掉遗留弹丸。新敌人有约 0.8 秒起步延迟，在烘焙的可通行格内生成，避开主角脚下和其它新敌人。
- 前两轮最多一只怪同时蓄力或扑跳，最短起手间隔分别为 1.05 / 0.90 秒。最后一轮允许两次进攻交错，最短起手间隔 0.68 秒；不会三只同时起手。有另一只已经就位时，让上一个攻击者让出下一次机会。
- 保留起跳瞬间锁目标、越过目标 0.35 米、离地后不追踪的攻击，以及既有闪避、弹反和反击窗口。
- 仅第六只怪的击败触发原有最终敌人收尾镜头。清场后稍等镜头结束再出现结果，显示用时、击倒、弹反、完美闪避、最长连击、受击和射击命中次数。
- 结算可重试或继续探索；倒下后可重试或回小院。离开林地取消本次遭遇，回到林地可重新触发。继续探索按钮不会原地立即重开战斗。

这是一版用于体验和比较的压力梯度，尚不能据此认定射击、闪避、弹反三种策略已经平衡。

## HUD

复用 godot_yard 原有 gems_bar.gd、ui_art.gd、gem_tint.gdshader 和 gems_atlas_v1.png。文件位于 scripts/combat/hud37 与 assets/ui37，未修改旧项目。atlas 区域只保留宝石、空槽、裂纹和碎片。

生命继续是 100 点，五颗宝石每颗代表 20 点；并未把旧项目的决心玩法一起移植。淡青宝石表示闪避冷却，金宝石表示弹反冷却，自下而上回充。旧版生命条、试战大段统计和重复技能指示隐藏。受伤、弹反、完美闪避有简短文字与淡角框提示；受击宝石沿用碎裂效果。结果中的宝石直接对齐实际剩余生命，避免死亡慢镜头让抽干动画仍显得有血。

F5 重试，F7 暂停；结算时 Esc 继续探索 / 回小院。PageDown 起跳闪光、E 瞄准辅助、Backspace 纸杯电话对照仍保留。F1 显示原调试说明。F12 的前期敌人实现对照留在 world36，避免混入新遭遇流程。

暂停只清理正在播放的时间效果，不重置本局统计、技能冷却或轮间倒计时。退出、重试均清理弹丸、时间效果和旧敌人投影引用。
