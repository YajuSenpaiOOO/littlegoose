默认项目和预览入口为 world38，preview_world_combat37.cmd 保留上一版。camera38_probe.gd 的 14 项检查通过，并检查了同机位战斗 / 探索截图。

## 旧版 buff 检查结论

检查了 godot_yard/scripts/cards.gd、main.gd 的 _pick_draft_cards / _apply_card / _on_draft_chosen，以及 black_goose.gd 的效果状态。

不需要全部重写。应保留旧卡牌的名称、描述、效果规则和组合语义，把执行效果接到新的角色、弹丸、敌人接口上。

| 部分 | 迁移方式 |
| --- | --- |
| 卡牌表、层数上限、互斥与候选筛选规则 | 大部分沿用；年龄、剧情、毕业等条件要连接新的进程，不能直接搬 main.gd 的全局依赖 |
| 三选一卡面与选择流程 | 复用旧视觉和交互；暂停、选择后恢复、下一轮推进接到新遭遇状态机；飞入主角的特效锚点改为 3D 投影 |
| 伤害、射速、移速、技能冷却倍率 | 接现有 projectile_damage / attack_cooldown / 角色移动接口，沿用倍率和叠层规则 |
| 追踪、穿透、弹射、分裂、波形弹道 | 保留玩法规则；在地面 XZ 平面复用方向与角度算法，适配独立高度、原生扫掠碰撞与命中去重 |
| 多只小黑鹅、环绕、纸杯电话 | 保留站位和触发语义；改为原生 3D 位置、地形采样和接触判定。纸杯电话目前已有原型，仍需正式接入获取与持有状态 |
| 弹反 / 完美闪避联动 | 新版已经有成功事件入口，效果应接事件，避免复制一套额外判定 |

建议下一步先接一小组旧版三选一，打通清场→选卡→下一场保留效果的循环，再分批迁其余卡。第一批可选纸杯电话（自由飞行）、橡皮筋弹弓（蓄力重弹）、眼保健操（射速与轻追踪），先比较实际玩法差异。要先明确“重新尝试本场”和“重新开始一局”的效果保留范围，避免 F5 重试意外丢掉已经选的卡。

本次代码改动仅包括镜头策略及其验证，以上为基于旧代码的后续迁移方案。
