# 记忆碎片39

默认场景和常用预览入口改到 world39；preview_world_combat38.cmd 保留旧版对照。

## 镜头

探索基础 gain 从 1.55 收到 1.4，战斗仍是已确认的 1.3。同机位的探索人物比战斗约大 7.7%，而非上版的 19.2%。基础构图用 0.85 秒真实时间的五次缓动处理，可在途中平滑反向；命中、弹反、闪避和收尾镜头继续独立叠加。

自动走入林地时保留行走速度和镜头前瞻，消除原试战重置清零移动造成的停顿。F5 的传送重试仍会重置人物运动；滚轮距离继续保留。轮间喘息和选卡均保持战斗构图。

## 清场、选卡与下一场

打完原来的 1→2→3 只三轮遭遇后，等待收尾镜头完成，再打开旧版卡面样式的记忆碎片选择。选卡时暂停战斗，隐藏战斗 HUD；鼠标点击或按 1 / 2 / 3 选择，立即带着效果进入下一场三轮遭遇。

- F5：重试本场，保留已选碎片。
- F8：清空碎片，开始新的一局。
- 正常探索、回小院和区域旅行保留本局碎片；未实现跨应用退出的存档。
- 未选纸杯电话时默认贴身跟随。选到后启用当前自由飞行原型与接触伤害；其飞行范围与可达性仍沿用之前的原型，未额外扩展远距离导航。
- 选卡按钮与数字键只有一次领取机会。关卡切换要求先松开射击，避免选卡鼠标输入进入下一场时误开火。
- 按旧卡表限制层数：一次性卡退出候选，升级卡满级退出。当前小卡池可能剩两张、一张；全部收齐后回到正常结果界面，仍能继续试战或用 F8 开新局。

名称、描述、台词、数值和升级语义来自 godot_yard/scripts/cards.gd、main.gd 与 black_goose.gd；卡面来自 assets/school_buffs_v1/card_v1.png，按旧区域裁切使用，旧项目文件未改。

| 卡牌 | 原玩法在当前世界的实现 |
| --- | --- |
| 纸杯电话 | 解锁现有自由飞行和每怪接触伤害冷却；一次性 |
| 橡皮筋弹弓 | 按住蓄力、松手发射；第一档满蓄 0.72 秒、12×伤害；第二档 14×且蓄力时间×0.85。射后冷却 0.25 秒。重弹速度按旧 320～750 像素/秒换算，生命 1.2 秒；强化击退和后坐、旧重炮音效、短出膛顿帧；小黑鹅憋红与小读条 |
