# 每波选卡40

用户澄清：应沿用旧版“每波清完就选卡”的节奏。world39 把三波六只怪合成一次奖励，是迁移时的理解错误。

## 修正后的流程

第一波一只怪 → 三选一 → 第二波两只怪 → 三选一 → 第三波三只怪 → 三选一 → 下一场。

前两次选择直接推进下一波，保留生命、累计击倒、射击、受击、弹反、完美闪避和最长连击统计，效果立即生效。第三波沿用原有结束演出，选完进入新的一场；新场生命与单场计数重置，记忆碎片保留。

第一、二波清完约 0.55 秒后出卡。自动刷下一波的旧轮间计时在等待选卡时暂停，阅读卡牌多久都不会先刷怪。卡面文字标明完成的是第几波，HUD 也改用“波”并显示当前存活数量。

修复清完后在收尾时间内越过林地边界会取消奖励的边界情况。已获得的奖励优先结算；继续下一波时如果人物已出界，会回到林地安全点。F5 / F8 和离开清理均重置等待选卡状态。卡池全满时不强行弹出空卡，继续已有试战流程。

日志新增 WAVE40_START、WAVE40_CLEAR、WAVE40_DRAFT_OPEN、WAVE40_PICK，方便区分是否真的清波以及卡牌是否打开，不再只记录场景启动。
