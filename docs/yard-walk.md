# 小屋门外：地皮与跟随镜头

2026-10-15。场景 `scenes/sandbox/yard_walk_study.tscn`，设为工程默认入口。工作目录 `preview_world_props.cmd` 也启动此场景。

## 本轮变化

镜头默认平滑跟随，保留约 160 屏幕单位的向前构图偏移。固定 35° 正交投影，不改变摆件大小，不旋转镜头。根据视口尺寸和已铺设地面边界限制取景，四角不露底。

通过内置 image_gen 新生成两张垂直俯视的手绘材质原图：`assets/environment/angle35/grass_ground_v1.png`、`dirt_ground_v1.png`。完整提示词及参考说明在 `art/source/ground35-prompts.md`，未修改原图像素。

地面覆盖二维地面坐标 (-1400,-1400) 至 (1400,1400)，按 sin(35°) 压缩纵深。材质使用稳定的地面坐标采样，不绑定屏幕坐标。通过镜像纹理采样避免直接平铺的硬接缝；当前草簇依然可能显示重复或镜像规律，留待实走评审后决定是否改成多纹理混合。

土路从门口向外延伸，渐变混合草地，边缘加入少量低频变化；小屋周边铺浅土面，树根和石头附近增加很弱的接触暗部。没有加入独立灌木/花丛或扩大地图内容，本轮集中比较地表和移动时的空间关系。

阴影仍为上一版的简化体积投影；未声称已完成太阳系统与屋檐投影。角色、团团仍是旧外观，团团不攻击；阻挡仍为视角样板的二维范围规则。

## 操作

- WASD：移动；Shift：快走。
- C：跟随/固定镜头；T：手绘地皮/原纯色地面对比。
- B：摆件/几何白模；G：网格；O：简化体积投影。
- R：角色复位；F1：面板开关；Esc：退出。
